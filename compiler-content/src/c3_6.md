## 3.6 只有加减

石板被岩舟放在石台上以后，厅里的光暗了一档。

"它是拿来**算**的。"星泠说，"而且它只认一种东西：**加法和减法**。"

岩舟把石板上的表情念了一遍："`1+2-3+4`。这不就是四个数吗？"

"对，但它要的不是四个数，是**一个数**：这一串算下来等于几。"星泠把刻笔在方板上画了三下，"而且我要你记住一件事——**这一关的机器读法，和你看它的读法是一样的：从左往右，一边走一边算。**"

她画的是这样一行：

```
走法：  1  +2  -3  +4
手上：  1   3   0   4
```

"每遇到一个数，就把它**按当时的符号**并到手上的结果里。遇到加号记'下一个是加'，遇到减号记'下一个是减'。手上永远只有一个数——**你不需要记住刚才读过什么。**"

岩舟愣了一下："不用记住？那前面几关我干嘛要把字符存起来……"

"因为我们那时候还不知道会出现什么。"星泠说，"而这一关的输入**只有数字和加减号**，没有括号，不用考虑'先乘除后加减'。这就是为什么它敢叫我们一次走过去——**输入的结构决定了你能不能用一次性扫描。**"

她在这句话下面补了一行小字：

> **编译器里最省的做法，永远来自'我事先知道输入长什么样'。**

---

**现在必须解决的麻烦**：石板不认"差不多"。

它只认一个数。而且它给出的一行里**没有空格**——`+` 号直接顶在数字后面，`-` 号也是。

"最难的不是算法。"星泠把刻笔塞进岩舟手里，"是**字符和数的区别**：你读回来的 `'1'` 不是 1，是编码 49；读回来的不是减号本身，是 45。这些数我在第二章最后一关跟你算过一遍，这一关要你自己写出来。"

这一关的做事顺序：

1. 三个变量：`x18` = 手上的总和（先清 0）、`x9` = 正在拼的这个数（先清 0）、`x10` = 当前符号（先设 1）；
2. 循环读字符：
   - 读到 `0`（队列空了）：**先把手上的数按旧符号结算一次**，然后去输出——最后那个数还没结过，这是最容易漏的一步；
   - 读到 `'+'`（43）：把 `x9` 按旧符号并进 `x18`，`x9` 清 0，符号设 1；
   - 读到 `'-'`（45）：同样结算并清 0，但符号设 -1；
   - 别的字符（只可能是数字）：`x9 = x9 * 10 + (字符 - 48)`；
3. 把结果写进 `0x2000`，打印出来。**结果可能是负数**，打印的程序要自己处理那个负号。

```riscv
{
  "level": "3-6",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 40,
    "suggested": {
      "7": "读到 43 ('+') → 先结算 x9，再把符号设成 1",
      "11": "数字：x9 = x9 * 10 + (x5 - 48)"
    },
    "highlight": [10]
  }
}
---
li x19, 0xF0000004
addi x18, x0, 0
addi x9, x0, 0
addi x10, x0, 1
eval_loop:
lw x5, 0(x19)
beq x5, x0, eval_end
# ↓ 下面从这里开始写：先认 '+' 和 '-'（结算 + 换符号），剩下的都当成数字拼进 x9
j eval_loop
eval_end:
# 别忘了最后那个数还没结算：把 x9 按 x10 的符号并进 x18
li x12, 0x2000
sw x18, 0(x12)
addi x10, x18, 0
jal x1, print_dec
li x10, 0
li x11, 0
ecall

# ── 打印程序（已经写好，可以直接用）：把 x10 里的数按十进制打印出来 ──
print_dec:
li x3, 0x2020
addi x6, x3, 0
addi x14, x0, 0
bge x10, x0, pd_digits
li x14, 1
sub x10, x0, x10
pd_digits:
addi x4, x0, 10
pd_digit:
addi x11, x0, 0
pd_loop:
blt x10, x4, pd_take
sub x10, x10, x4
addi x11, x11, 1
j pd_loop
pd_take:
addi x11, x11, 48
addi x6, x6, -1
sb x11, 0(x6)
bne x10, x0, pd_digit
beq x14, x0, pd_emit
addi x6, x6, -1
li x12, 45
sb x12, 0(x6)
pd_emit:
li x7, 0xF0000000
li x13, 1
pd_out:
lb x12, 0(x6)
beq x12, x0, pd_done
addi x10, x12, 0
ecall
addi x6, x6, 1
j pd_out
pd_done:
li x10, 10
ecall
jalr x0, 0(x1)
```

三个容易踩的坑：

- **最后那个数要单独结算一次**。`1+2` 走在 `+` 上的时候结算的是 1；走到输入末尾时，手上的 2 还没并进去——忘了这一步，答案就会永远少最后一项。
- **拼数前必须先乘 10**。`123` 是 `1 → 12 → 123`；如果写成"先乘 10 再加"之外的任何顺序，`12+34` 会算出 4 和 3 这种数。
- **负号是字符 45，不是减号运算**。它只改变符号变量，不吃掉任何数字。

石板上的光水在答案对上的那一刻全部退了下去，露出石板本来的颜色——不是石头，是**玻璃**。玻璃后面排着密密麻麻的东西，一眼看不到头。

岩舟把手贴在上面，感到一阵很轻的震。

"伊塔尔留给我们的不是一台翻译机。"星泠说，"**是一个编译器。**我们刚才做的六件事——读字符、认字符、拼数、走状态、配结构、一次算完——就是编译器最底下的那一层。"

她顿了顿。

"而这只是第一层。"

（第三章完）
