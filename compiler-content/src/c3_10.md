## 3.10 输出格式化

小厅的尽头是一块读数屏。

屏上有一个数字在慢慢跳，跳得毫无规律：`1234`、`5`、`-50`。数字后面拖着一行更小的刻字：

**此数已乘百。示人须复原。**

岩舟盯着它看了半天："`1234`……乘了一百？那原来是 `12.34`？"

"小数点没了。"星泠说，"整块魔法阵里没有'小数点'这种东西——它是刻出来的，不是算出来的。所以遗迹的做法很土：**把数放大一百倍存起来**，`12.34` 存成 `1234`。谁要给人看，谁自己把点插回去。"

"那我们插回去就行？"

"你插一个给我看看。"星泠把屏幕转过来，"屏上现在是 `5`。"

岩舟张了张嘴，又闭上了。`5` 乘过一百，原来是 `0.05`——**不是 `0.5`**。

"这就是这关的麻烦。"星泠说，"数本身只是两个整数：整数部分、小数部分。难的是'打出来像人写的'。"

---

### 拆成两半

"先算两个数："

```
整数部分 = |值| / 100        （用 div）
小数部分 = |值| % 100        （用 rem）
```

"`1234` → 整数 `12`、小数 `34`；`5` → 整数 `0`、小数 `5`；`-50` → 绝对值 `50` → 整数 `0`、小数 `50`。"

"然后按顺序打三样东西：**整数部分、小数点、小数部分**。"

"负号呢？"

"负号跟在小数点后面**没有**关系。"星泠在方板上画了个括号，"`-50` 是 `-0.50`，不是 `0.-50`。所以负号在**最前面**，而且算整数/小数之前就要把值取成绝对值——`div` 和 `rem` 会跟着符号走，`-50 / 100` 是 `0`、`-50 % 100` 是 `-50`，那样小数部分就会变成 `-50`，打出来是 `0.-5 0`，一塌糊涂。"

### 补零才是真功夫

"现在看两个最容易错的地方："

```
小数部分 = 5     → 必须打 "05"     不能只打 "5"
小数部分 = 0     → 必须打 "00"     不能什么都不打（3.00 的两个 0 都要）
```

"所以小数部分不能直接丢给打印整数的子程序。"星泠说，"它要**恰好两位**，不足两位就补 `'0'`。写成一个专门的 `print_two_digits`：小于 10 就先打一个 0，再打个位；否则打十位和个位。"

"那整数部分呢？"

"整数部分正常打。`0` 就打成 `0`——`0.05` 的整数位那个 0 也得在。"

### 顺手把"读一个整数"也写了

"还有件小事：输入现在是一个整数，可能带负号，可能好几位。"星泠说，"上一关你是从字符流里拼数的，这次也一样：跳过空白 → 看有没有 `-` → 一位一位拼 `值 = 值 * 10 + 这一位`。输入端口每次只给一个字符，没有人替你把 `1234` 变成 1234——这一关你要练的就是'字符到数字'的手艺。"

| 输入 | 整数部分 | 小数部分 | 输出 |
|------|---------|---------|------|
| `1234` | 12 | 34 | `12.34` |
| `300` | 3 | 0 | `3.00` |
| `5` | 0 | 5 | `0.05` |
| `-5` | 0 | 5（符号单独记） | `-0.05` |
| `-50` | 0 | 50 | `-0.50` |

```riscv
{
  "level": "3-10",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [4],
    "suggested": {
      "4": "jal ra, read_int",
      "5": "mv s0, a0",
      "6": "li t1, 100",
      "7": "div s1, s0, t1"
    }
  }
}
---
# 目标：输入是一个已经乘过 100 的整数（可能带负号），输出它的"定点"写法。
#   1234 → 12.34      300 → 3.00      5 → 0.05      -5 → -0.05
#
# 骨架现在什么也不做。要写的：
#   1. read_int：跳过空白、处理负号、一位一位拼成整数（读字符直到不是数字）
#   2. 记下符号 → 取绝对值 → 整数部分 = 值 / 100，小数部分 = 值 % 100
#   3. 负号先打 → 打整数部分 → 打 '.' → 打两位小数（不足两位补 '0'！）
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000

main:
        li      a4, INPUT
        li      a5, DISPLAY
        nop                             # ← 从这里开始写
        li      a0, 0
        li      a7, 0
        ecall
```

岩舟把 `5` 送进读数屏，屏上先闪了一下 `0.5`，然后被他自己按掉了。

第二次，`0.05`。

星泠没说话，只是把读数屏往旁边一推，露出了它后面一直贴着墙放的另一块方板——比前面所有方板都旧，边角被磨得发亮。

方板上刻的**不是**一个算式。

是一串字。
