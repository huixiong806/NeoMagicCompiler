## 2.6 墙上那个名字

走廊的墙壁从地面到穹顶刻满了名字。不是数字，是一串一串的字母——星泠认得这种字母，那是古人的名字写法。

岩舟举着火光照过去，念出最近的一个：

```
Sylas
```

刚念完，廊道尽头那道闸门"咔"地松了一格。

“它认名字。”岩舟乐了，“那我多念几个。”

他接着念。闸门毫无反应。

星泠把卷轴翻到下一句刻痕，上面写着：**把名字写到显示端口上**。

“它不是在听。它是在读。”她说，“闸门上有一块符石，只认从这里收到的名字。这个遗迹里所有会发光、会响、会开门的东西，本质都是同一件事：**往显示端口写字符**。”

“字符？”

“字母、数字、符号，一个字符就是一个字节。你把它写到显示端口，它就发一次光——写一串，就是一串光。`Sylas` 是五个字符：`S`、`y`、`l`、`a`、`s`。”

屏幕上跳出新的目标：

```
本关目标：让运行结果输出 Sylas 这五个字符（不要多、不要少、不要换行）
提示：这是程序模式，你写 int main()，不用写 solve
```

“这关没有参数了。”星泠说，“从 `main` 开始跑，跑到结束。”

---

**你要写的东西**

```c
int main() { ... }
```

输出 `Sylas`。

两种写法都行：

1. **一句话**：`print_str("Sylas");` —— 直接输出一整串（字符串末尾自动带一个 `\0`，这个结束标记不会被输出）；
2. **一个字符一个字符**：用 `putchar(c)` 输出单个字符，配合一个 `while` 循环，一直输出到遇到 `\0`（`\0` 在字符层面等于 `0`）：

```c
int i = 0;
while ("Sylas"[i] != 0) {
    putchar("Sylas"[i]);
    i = i + 1;
}
```

也可以先用指针接住字符串的首地址，再用 `*p` 读字符、`p = p + 1` 往前挪。

**内建函数**（不用声明，直接调用）：`putchar(c)`、`getchar()`、`print_int(n)`、`print_str(s)`、`exit(code)`。

判定是"只看输出"：判例会把显示端口上收到的字符和期望文本逐行比对，首尾空白与空行忽略；多一个字符都算错。

```riscv
{
  "level": "2-6",
  "language": "c"
}
---
// 2-6 字符串与 putchar：输出符文名 Sylas
// 提示：print_str("Sylas"); 一行就够；
// 也可以自己用 putchar 循环输出，逐个字符写到显示端口。
int main() {
    print_str("Sylas");
    return 0;
}
```
