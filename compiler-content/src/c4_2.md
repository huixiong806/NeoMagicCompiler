## 4.2 数字不止一种写法

第二天早上，星泠在圆厅的另一面墙上找到了一排**编号**。

每一格都刻着一个符号，旁边缀着一小段数字：`0x2A`、`0xFF`、`'A'`、`"eitar"`。

"这些不是普通的数。"她说，"`0x` 开头的是**十六进制**，`'A'` 是**字符字面量**，双引号里的是**字符串**。伊塔尔的编译器连这些都要认。"

岩舟凑过去看那个 `"eitar"`，觉得那大概是个名字。"那我们昨天写的那台切词机——"

"会在这里摔一跤。"星泠说，"它读到 `0` 就往前读到 `x` 停下，会输出 `NUM:0`，然后下一个字符 `x` 又变成一个名字的开头——`NUM:0`、`ID:x2A`，全错了。"

她把手按在石板上，退了半格：

"问题出在**'0' 这个字符有两种命运**。它可能只是个零，也可能是'接下来是十六进制'的信号。光看一个字符永远分不出来——必须**再看一眼**。"

这正是你昨天为了 `<=` 已经准备好的那件东西：回看缓冲。

**这一关要补上的四种 token**

| 写法 | 例子 | 输出 | 说明 |
|------|------|------|------|
| 十进制整数 | `42` | `NUM:42` | 和上一关一样 |
| 十六进制整数 | `0x2A`、`0xff`、`0X10` | `NUM:42`、`NUM:255`、`NUM:16` | 大小写 `x` 都认；**数值一律用十进制印出来** |
| 字符字面量 | `'A'` | `CHR:65` | 印的是**码值**，不是那个字符 |
| 字符串字面量 | `"hello"` | `STR:hello` | 内容**按原样**，不含两边的引号 |

转义照旧认：`\n`（换行，码值 10）、`\t`（制表，码值 9）、`\\`（反斜杠，92）、`\'`、`\"`。字符和字符串里都能用。

"顺序怎么定？"岩舟问，"我看到 `0x2A`，怎么知道不是 `0` 然后 `x2A`？"

"三步。"星泠在方板上画：

1. 首字符是数字（`0`–`9`）→ 这是个数字 token 的开头；
2. **多看一个字符**：如果第二个也是数字，那是十进制，两位一起算进去；
3. 如果第二个是 `x` 或 `X`，那说明这是十六进制——把 `0x` 两个字符都吞掉，然后一位一位读十六进制位（`0`–`9`、`a`–`f`、`A`–`F`），`值 = 值 * 16 + 这一位的值`。

"十六进制位怎么转成值？"岩舟皱眉，"`'A'` 是 65，但它代表 10。"

"`'A'` 减 55 就是 10。"星泠说，"字母分大小写两段，先判断落在哪一段，或者干脆把小写统一折成大写再减——`'a'` 和 `'A'` 正好差 32。"

"字符串呢？"

"字符串最省事：**一边读一边就往外印**。"她说，"先印 `STR:`，然后一直读、一直印，读到收尾的双引号为止。不需要先把内容攒进缓冲区——反正你也不打算记住它。"

"那单引号里的字符字面量为什么不能也这样？"

"因为它要把 `'A'` 变成 `65`，得先读进来算一下。"星泠说，"而且字符里可能是 `'\n'` 这种转义——读进来的是反斜杠加 `n` 两个字符，得把它折成一个 10。"

```riscv
{
  "level": "4-2",
  "language": "asm",
  "constraints": {
    "suggested": {
      "20": "jal x1, next_token",
      "21": "beq x10, x0, done"
    }
  }
}
---
# 4-2 词法分析：数字与字符串
#
# 在 4-1 的基础上再加四种 token：
#   NUM:十进制数值   十进制 42 与十六进制 0x2A / 0xff / 0X10（数值一律用十进制印）
#   CHR:码值         字符字面量 'A' → CHR:65；支持 '\n' '\t' '\\' '\'' 转义
#   STR:内容         字符串字面量 "hello" → STR:hello；内容按原样，不含两侧引号
#   KW: / ID: / OP:  和 4-1 完全一样，别改坏
# 这一关的输入里不会出现不认识的字符，所以不必写 ERR 那一段。
#
# 已经替你开好的东西：
#   sp 指向 0x3000；输入端口地址存在全局变量 inport 里（启动时填好）
#   getc / ungetc：一对，getc 先看回看缓冲，再去读端口；ungetc 把字符放回去
#   print_int：把 x10 里的非负整数按十进制印出来（印 CHR 的码值、NUM 的值都用它）
#   emit_str：把 x10 指向的字符串（0 结尾）原样印出来
#   kwtab 里 6 个槽已经填好六个关键字；buffer 是给你存一整个词的缓冲区
#
# 十六进制怎么认（关键在"多看一个字符"）：
#   读到首字符（数字）之后，再看一个：是 x / X 就是十六进制（把两个字符都吞掉），
#   否则把多看的那一个 ungetc 还回去，按十进制一位一位拼。

    .equ INPORT,  0xF0000004
    .equ DISPLAY, 0xF0000000

    .text
main:
    li   sp, 0x3000
    li   t0, INPORT
    la   t1, inport
    sw   t0, 0(t1)
    li   t0, kwtab
    la   t1, kw0
    sw   t1, 0(t0)
    la   t1, kw1
    sw   t1, 4(t0)
    la   t1, kw2
    sw   t1, 8(t0)
    la   t1, kw3
    sw   t1, 12(t0)
    la   t1, kw4
    sw   t1, 16(t0)
    la   t1, kw5
    sw   t1, 20(t0)
# ↓ 从这里开始是你的活：
#   skip_ws / next_token 现在是空壳，先照着 4-1 把它们填回来，再加新东西：
#     数字 → 多看一个字符：是 x/X 就按十六进制读（值 = 值 * 16 + 这一位，
#            十六进制位：'0'-'9' 减 48，'a'-'f' 折成大写后减 55），
#            否则把多看的那一个还回去，按十进制读（值 = 值 * 10 + 这一位）
#     双引号 → 印 "STR:"，然后一直读一直印，读到收尾的双引号；中途遇到 '\' 要转义
#     单引号 → 读一个字符（可能是 '\' 开头的转义）算出码值，印 "CHR:" + 码值
#   把主循环的注释去掉
# main_loop:
#     jal  x1, next_token
#     beq  x10, x0, done
#     j    main_loop

skip_ws:
    jalr x0, 0(x1)

next_token:
    addi x10, x0, 0
    jalr x0, 0(x1)

done:
    li   a0, 0
    li   a7, 0
    ecall

# ── 读一个字符：x10 = 字符（0 = 输入结束）──
getc:
    la   t0, lookahead
    lbu  t1, 0(t0)
    beq  t1, x0, getc_fetch
    sb   x0, 0(t0)
    addi x10, t1, 0
    jalr x0, 0(x1)
getc_fetch:
    la   t0, inport
    lw   t0, 0(t0)
    lbu  x10, 0(t0)
    jalr x0, 0(x1)

# ── 把 x10 里的字符还回回看缓冲 ──
ungetc:
    la   t0, lookahead
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 把 x10 指向的字符串（0 结尾）原样印出来 ──
emit_str:
    lbu  t1, 0(x10)
    beq  t1, x0, es_done
    li   t2, DISPLAY
    sb   t1, 0(t2)
    addi x10, x10, 1
    j    emit_str
es_done:
    jalr x0, 0(x1)

# ── 把 x10 里的非负整数按十进制印出来 ──
print_int:
    li   t0, 10
    blt  x10, t0, pi_last
    addi sp, sp, -8
    sw   x1, 0(sp)
    sw   x10, 4(sp)
    div  x10, x10, t0
    jal  x1, print_int
    li   t0, 10
    lw   x10, 4(sp)
    rem  x10, x10, t0
    lw   x1, 0(sp)
    addi sp, sp, 8
pi_last:
    addi x10, x10, 48
    li   t0, DISPLAY
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 数据 ──
    .data
s_colon:
    .asciz ":"
s_kw:
    .asciz "KW"
s_id:
    .asciz "ID"
s_num:
    .asciz "NUM"
s_op:
    .asciz "OP"
s_chr:
    .asciz "CHR"
s_str:
    .asciz "STR"
kw0:
    .asciz "if"
kw1:
    .asciz "else"
kw2:
    .asciz "while"
kw3:
    .asciz "return"
kw4:
    .asciz "int"
kw5:
    .asciz "void"
o_one:
    .asciz "+-*/=<>(){};,!&|"
o_slot:
    .word 0
lookahead:
    .word 0
kwtab:
    .word 0, 0, 0, 0, 0, 0
buffer:
    .space 512
inport:
    .word 0
```

两处最容易摔的地方：

- **`0` 后面那一眼一定要看得"浅"**：看清了下一个字符是 `x`，你就要把 `x` 吞掉；看清它不是 `x`，你就得把它**还回去**——还错了，`10` 会变成 `NUM:1` 加上一个空落落的 `0`，或者干脆整个数字变成 `0`。
- **字符串里的引号不一定是收尾**。`"a\"b"` 里那个 `\"` 是内容的一部分，收尾双引号在最后那个。所以读字符串时必须先看反斜杠，看到就得连着后面的字符一起消化掉。

判定会**丢掉每行首尾的空白、丢掉空行**再比对。所以 `STR:` 后面如果内容里有换行，那一行会断成两行——这是对的，不用想办法躲开。

墙上那一排编号切完了，岩舟忽然发现石板背面还刻着一件东西：一行只有数字和 `+ - * / ( )` 的算式，旁边写着"**先算谁**"。

"它连这个都要问。"他说。

星泠看了一眼，笑了一下："这台机器不知道什么叫优先级。它只会**排队**。"
