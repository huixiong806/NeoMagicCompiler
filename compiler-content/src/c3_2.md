## 3.2 字符分类

第一道刻痕对上之后，石台上的缝松了一格，光水从中间裂开。裂口后面不是新的字符，而是一块**只有三个格子**的小屏——三个格子从上到下排着，都是空的。

"三个数。"星泠把手贴在裂口上，"它把整条字符流分成了三堆，要每一堆的个数。"

岩舟凑近看了一遍那三行小字：

> 一：**数字**（`0` 到 `9`）
> 二：**字母**（`A` 到 `Z`，以及 `a` 到 `z`）
> 三：其余一切

"其余一切有点赖皮。"他说。

"不赖皮。"星泠说，"**分类的前提是'每一类都有明确规定'。**伊塔尔把话说死了：一个字符要么是数字、要么是字母、要么是'其余一切'——没有第四种，也没有一个字符能同时进两堆。你写代码的时候只要保证这一点，剩下就是算术。"

她拿刻笔在方板上画了一条数轴，把 ASCII 的几段标了出来：

```
48 '0' ...... 57 '9'      ← 数字
58 ... 64                 ← 中间的空档：: ; < = > ? @
65 'A' ...... 90 'Z'      ← 字母（大写）
91 ... 96                 ← 空档：[ \ ] ^ _ `
97 'a' ...... 122 'z'     ← 字母（小写）
```

"看见那些空档没有？**`'9'` 和 `'A'` 中间隔着 7 个字符，`'Z'` 和 `'a'` 中间隔着 6 个。**这就是为什么不能只判一次'它比 48 大'——你必须把下界和上界都问一遍。"

岩舟盯着数轴看了半天，忽然说："这不就是拿 `<` 问问题吗？"

"对。"星泠把刻笔往方板上一敲，"`blt x5, x6, 标签` 的意思是'x5 比 x6 小就跳过去'。反过来问'比某个数大'，就把两个寄存器调个个儿——`blt x6, x5, 标签` 问的是'x6 比 x5 小'，也就是'x5 比 x6 大'。星之语里只有'小于'和'大于等于'两个原始问题，别的比较都是它们变出来的。"

"所以这一关的判断可以全用一条规矩写：**先问下界、再问上界，两次都是'比谁小就走开'，剩下的就是我们要的那一类。**"

---

**现在必须解决的麻烦**：三行数字，一位都不能错。

第一行错了，机器不认；第二行错了，机器也不认。它只看三个格子**同时**对上——所以这一关真正要练的是"**每个字符只许进一个分支**"。

1. 三个计数器：x8 数数字、x9 数字母、x18 数其他（骨架里已经清零了）；
2. 在 `read_loop` 里判断：读到 0 就跳出；否则先问下界，再问上界，最后归类；
3. 数完把三个数分别写进 `0x2000`、`0x2004`、`0x2008`；
4. 用 `li a7, 2` 把三个数**按三行**打出来（每打完一个数，自己补一个换行符 `'\n'`）。

```riscv
{
  "level": "3-2",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 2,
    "suggested": {
      "4": "lw x5, 0(x1)；读到 0 就跳出循环",
      "5": "li x6, 48 / blt x5, x6, ...：先问下界"
    },
    "highlight": [10]
  }
}
---
li x1, 0xF0000004
addi x8, x0, 0
addi x9, x0, 0
addi x18, x0, 0
read_loop:
lw x5, 0(x1)
beq x5, x0, counts
# ↓ 下面从这里开始写：判断这个字符属于哪一堆，给对应计数器加一，再跳回 read_loop
j read_loop
counts:
# 三个计数要写进 0x2000（数字）、0x2004（字母）、0x2008（其他），
# 然后用 a7 = 2 逐行打印，每个数后面补一个 '\n'
li x10, 0
li x11, 0
ecall
```

两个容易踩的坑：

- **别把"其他"当成"没分类的兜底"就不管它**。每个字符都要落到某一堆里，落到哪一堆就加哪一个计数器，一个字符加两次是这一关最常见的错。
- **换行符也要数**。`ab12 cd!\n` 里最后那个换行不属于数字也不属于字母，它是"其他字符"——所以这一关的第三行往往不是 0。

三个格子同时亮起的时候，岩舟听到头顶传来石头挪动的声音：厅的穹顶上，一整圈刻痕正在自己重排。

"它在**拼数**了。"星泠说，"下一关不数个数了，它要我们把一串字符拼成一个真正的数——**多位数，还可能带负号**。"
