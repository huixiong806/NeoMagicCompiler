## 2.10 圆盘上的两种刻痕

机关圆盘有巴掌大，边缘一圈刻痕，每一道只有两种样子——凹下去，或者凸起来。

凹的是 0，凸的是 1。一共三十二道。

圆盘下面压着一行小字：

```
数出圆盘上凸起的刻痕有几道，就是这一层的钥匙齿数。
```

岩舟盯着圆盘转了一圈，伸手指着一道道点：“一、二、三……二十八、二十九……”

“你在用眼睛数。”星泠把他手按住，“这东西会自己转，你数到一半它转过去怎么办？”

“那就……再看一遍？”

“不用。”星泠把卷轴递给他看下一句刻痕，“古人在这里不用加法，用的是**位运算**。一个整数，本来就是一排 0 和 1。想检查最右边那一位是不是 1，就把它和 `1` 做一次**按位与**——”

她在沙地上写：

```
x & 1   ->  结果只看最后一位：是 1 就是 1，是 0 就是 0
x >> 1  ->  把整排刻痕往右推一格，刚看过的这一位就掉了
```

“所以你要做的只有两件事：看一眼最右边，然后把圆盘往右推一格。推三十二次，数够了就停。”

岩舟沉默了两秒：“……这比数三十二道快多了。”

屏幕上跳出新的目标：

```
本关目标：int solve(int x) 返回 x 的二进制表示里 1 的个数
注意：x 可能是 0，也可能是全 1 的 0xFFFFFFFF（三十二道全凸起）
```

“全凸起有多少道？”

“三十二。别少算。”

---

**你要写的东西**

```c
int solve(int x) { ... }
```

返回 `x` 的二进制里 1 的个数（也叫**汉明重量**）。

- `x & 1`：取出最低位（只看最后一道刻痕）；
- `x >> 1`：整体右移一位（把圆盘往右推一格）。对 `int` 而言这是算术右移，最高位会复制符号位——但由于我们固定数 32 轮、并且只关心低 32 位，这不影响结果；
- 坚持数满 32 轮（`for (i = 0; i < 32; i = i + 1)`），就不会漏掉最高位。

提醒：`0xFFFFFFFF` 当作有符号数读出来是 `-1`，它的三十二位**全是 1**，答案应该是 `32`。

```riscv
{
  "level": "2-10",
  "language": "c"
}
---
// 2-10 位运算：返回 x 的二进制里 1 的个数
int solve(int x) {
    int count = 0;
    int i;
    for (i = 0; i < 32; i = i + 1) {
        if ((x & 1) != 0) {
            count = count + 1;
        }
        x = x >> 1;
    }
    return count;
}
```
