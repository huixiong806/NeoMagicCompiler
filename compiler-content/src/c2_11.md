## 2.11 满墙的名字牌

通道两侧的墙上密密麻麻挂着名字牌，从 1 号一直排到几百号。岩舟用火光照过去，发现有些牌子上被划了一道，有些没有。

“划掉的是‘不算数的’？”

星泠蹲在最前面看了一会儿：“不。划掉的名字，是能被别人**整除**的。”

她指着牌子下方那行说明：

```
本层通行许可 = 1..n 之中没有被划掉的牌子数
规则：2 留着；2 的倍数全划掉。
      然后是下一个没被划掉的数，它的倍数也全划掉。
      一直做到没有数可划为止。
```

“又是要一块一块走？”岩舟皱眉，“几百个牌子，看一遍就花半天。”

“所以古人不会每次都看一遍。”星泠展开卷轴，“他会先在地面上画出一整排格子，**每划掉一个就在格子上做个记号**。等全部划完，再数一遍没做记号的格子。这一排格子，就是第 2-4 关那排石头的新用法。”

屏幕上跳出新的目标：

```
本关目标：int solve(int n) 返回不超过 n 的素数个数（1 不算素数）
做法：埃拉托斯特尼筛法——用一排标记格子记下哪些数已经被划掉
范围：0 <= n <= 200
```

“标记格子就是**数组**。”星泠补充，“在自己的函数里开一个够长的 `int` 数组，比如 256 个位置：位置 `i` 存 `1` 表示 `i` 被划掉了，存 `0` 表示还没被划掉。这次不需要别人给地址，格子是你自己造的一排。”

岩舟在键盘上敲了几下，又停下：“等下，那 0 号和 1 号牌子怎么办？”

“它们从来不是素数。直接把格子标成 1，或者干脆别去数它们。”

---

**你要写的东西**

```c
int solve(int n) { ... }
```

返回 `0..n` 之间素数的个数。`n = 0`、`n = 1` 时返回 `0`。

埃氏筛的步骤：

1. 开一个标记数组，例如 `int mark[256];`，先把所有位置清成 `0`（用一个循环）；
2. 把 `mark[0]` 和 `mark[1]` 标记成 `1`（它们不是素数）；
3. 从 `i = 2` 开始，如果 `mark[i]` 还是 `0`，说明 `i` 是素数，就把 `i` 的所有倍数（`2*i`、`3*i`……直到超过 `n`）标记成 `1`；
4. 循环结束后，统计 `2..n` 中 `mark[i] == 0` 的个数并返回。

**注意**：如果 `n < 2`，直接返回 `0`，别去访问超出范围的格子。

```riscv
{
  "level": "2-11",
  "language": "c"
}
---
// 2-11 素数筛：返回不超过 n 的素数个数（n <= 200，1 不算素数）
int solve(int n) {
    int mark[256];
    int i;
    int j;
    int count = 0;

    if (n < 2) {
        return 0;
    }

    for (i = 0; i <= n; i = i + 1) {
        mark[i] = 0;
    }
    mark[0] = 1;
    mark[1] = 1;

    for (i = 2; i <= n; i = i + 1) {
        if (mark[i] == 0) {
            for (j = i * 2; j <= n; j = j + i) {
                mark[j] = 1;
            }
        }
    }

    for (i = 2; i <= n; i = i + 1) {
        if (mark[i] == 0) {
            count = count + 1;
        }
    }
    return count;
}
```
