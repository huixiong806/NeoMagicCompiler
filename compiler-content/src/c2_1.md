## 2.1 一行刻痕，四行星之印

符文柱熄灭之后，走廊尽头露出一个被碎石半掩的凹室。

岩舟把碎石推开，里面是一块半人高的石台，台上立着两枚还亮着的魔力感应石——它们各含一个能量读数，等着被送到别处去。

“又是老规矩，”岩舟活动了一下手腕，“把两个数加起来，写进第三枚石头。四行星之印：`lw` 读蓝的，`lw` 读紫的，`add`，`sw` 写回去。”

星泠没有动手。她蹲在石台侧面，指尖拂过一片薄薄的、像水晶一样的卷轴。

“这次不用我们算。”她说。

卷轴表面刻着一行字。岩舟凑过去看——不是星之印那种短短两三笔的方块字；这行刻痕更长、更密，笔画之间连着细线，像谁把一整句咒语一口气刻完了。

“这是什么？咒文诗？”

“星之语把每一件事都拆开写：取一个数、取另一个数、相加、存回去。”星泠指着那行刻痕，“而这里，古人只写了一句——**两个数相加**。”

她把魔导核心贴到卷轴上。核心嗡了一声，屏幕上跳出一行新的信息：

```
魔导引擎：识别到「高阶语」卷轴
等级：星咒（C 子集）
本关目标：int solve(int a, int b) 返回 a + b
```

“他把抽象也刻下来了。”星泠轻声说，“他不是在教后来的法师怎么搬数，他是在教他们**怎么描述一件事**。你只要说清楚‘要什么’，‘怎么做’交给引擎——这是这里的第一种魔法：把重复的句子收成一句。”

“那我先拿它算个加法试试。”岩舟已经在编辑器里敲起来了。

---

**你要写的东西**

一个星咒函数：

```c
int solve(int a, int b) { ... }
```

`a`、`b` 是两个整数（就是上面两枚感应石里的读数），把它俩的和 `return` 回去。

星咒里常见的写法（和你在外面见过的 C 一样）：`int x = a + b;` 声明一个变量并赋值，`return x;` 把结果交还给调用者；`+ - * / %` 和 `( )` 的优先级都照常。编辑器的测例会把两个整数塞进参数里，再拿你返回的值和正确答案对一遍。

```riscv
{
  "level": "2-1",
  "language": "c"
}
---
// 2-1 变量与表达式：返回 a + b
int solve(int a, int b) {
    return a + b;
}
```
