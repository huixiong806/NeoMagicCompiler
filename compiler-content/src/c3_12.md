## 3.12 综合：咒文解析机

方板背面是一整页刻字，从上到下，一行一行：

```
let r = 12
let pi = 314
print r*r*pi/100
print (r+8)*2
3+4
print r-8
```

岩舟从头念到尾，越念越慢。

"这不是一句话。"星泠说，"这是一份**记录**。伊塔尔留下来的东西就是这个样子——每一行都是一句咒文，有的是在给东西起名，有的是在报一个数，有的一行只是留给自己的草稿。"

她指着倒数第二行 `3+4`：

"这一行算出来是 7，但**没有 `print`**。所以你什么都不要打。"

"空行呢？"

"跳过。空行不是咒文。"

"那我们上一关写的机器……"

"差一点。"星泠把刻笔递过去，"上一关你是一行一行读完就停——不，你没有停，你是**读到输入结束**。这台机器其实已经是一行一行读的了。你现在要做的，是把'每行可以是任何东西'这事补齐。"

---

### 一页咒文 = 一串语句

"回想 3-11 的语句层：它反复地问'下一条语句是什么'，跳过空白、换行、分号，看到 `0` 就结束。"

"注意到没有——它**根本没在乎'行'这个东西**。"星泠说，"换行、分号、空格，对它来说都只是'语句之间的空隙'。所以同一段代码，既能读 `let x = 3; print x;` 这种写成一行的小脚本，也能读一整页一行一句的记录。"

"你的语句层已经什么都有了："

| 输入行 | 语句层做的事 | 有没有输出 |
|--------|-------------|-----------|
| `let r = 12` | 走 `try_let`：算出 12，存进 `r` 的格子 | 没有 |
| `print r*r*pi/100` | 走 `try_print`：算出值，打一行 | 有 |
| `3+4` | 都不是 → 放回字符，当算式算完**丢掉** | 没有 |
| （空行） | `skip_filler` 直接跳过去 | 没有 |

"所以这一关真正要你确认的只有三件事："

1. **`print` 的结果每条占一行**——打完数还要打一个换行（`10`），不然所有结果会挤成一行；
2. **没有 `print` 的语句一个字符都不能输出**——`3+4` 算完就丢，`let` 存完就走；
3. **空行、行首空格、多余分号都要能跳过**——这份记录是人刻的，不是格式化出来的。

"还有第四件。"岩舟说，"变量要**跨行**记得住。"

"对。"星泠说，"`let r = 12` 在前，`print r-8` 在后，中间隔了两行。你的变量表在内存里，不在寄存器里——寄存器会被下一个算式覆盖，内存不会。这就是这一整章最后一句要你记住的话：**变量的命，是内存给的。**"

### 顺便看一下这台机器有多大

| 层 | 干什么 | 大致长度 |
|----|--------|---------|
| `get_char` / `unget_char` | 字符流 + 放回一个字符 | 十几行 |
| `skip_filler` / `skip_space` | 跳过空隙 | 十几行 |
| 语句层 | `let` / `print` / 光算式 | 四十来行 |
| 算式层 → 项层 → 因子层 | 3-9 那台机器（多了"变量"这一种因子） | 八十来行 |
| `print_int` / `print_uint` | 十进制输出 | 三十来行 |

"两百多行星之语。"星泠说，"这就是一台**解释器**的全貌：把字符流切开来、拼成有结构的句子、按结构算、把结果吐出去。第四章你要写的编译器，前一半和它一模一样——只是后半段不再是'算'，而是'生成星之印'。"

```riscv
{
  "level": "3-12",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [6],
    "suggested": {
      "6": "jal ra, skip_filler",
      "7": "beqz a0, prog_end",
      "8": "li t0, 'l'",
      "9": "beq a0, t0, try_let",
      "10": "li t0, 'p'",
      "11": "beq a0, t0, try_print"
    }
  }
}
---
# 目标：读入多行咒文，逐行处理并输出所有 print 的结果。
#   每一行是下面三种之一：
#     算式                 算完丢掉，不输出
#     let 名字 = 算式      存进变量（a..z，存在 0x2000 起，一个字母 4 字节）
#     print 算式           算出结果，输出一行
#   空行跳过；没有 print 的行不产生输出。
#
# 这台机器就是 3-11 的语句层（它对"换行/分号/空行"一视同仁）+ 3-9 的三层求值器
# + 因子层多认一种"小写字母 = 变量"。
# 别忘了：每条 print 结果后面要打一个换行（字符 10）。
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000
        .equ VARS, 0x2000

main:
        li      a4, INPUT
        li      a5, DISPLAY
        nop                             # ← 从这里开始写这台咒文解析机
        li      a0, 0
        li      a7, 0
        ecall
```

岩舟把整页刻字一行一行送进去。读数屏上跳出：

```
452
40
4
```

第一行是 `r*r*pi/100`：`12*12*314/100 = 452`。第二行 `(12+8)*2 = 40`。第三行 `12-8 = 4`。

`3+4` 那一行，什么也没出现。

"它读懂了。"星泠说，"你把一段**文字**变成了**结果**。"

她伸手把那块旧方板从墙上取下来，翻回正面。正面靠近边缘的地方，还有一小行字，前面几次都没被注意到——字很小，而且像是**没有刻完**：

**凡能读此咒文者，此门之后……**

后面的字被磨平了。门在方板离开墙的那一瞬开始往两边退。

（第三章完 · 门后是一整座需要**重新编译**的遗迹。）
