## 2.12 一排高矮不齐的符文柱

通道尽头立着一排符文柱。它们高低不一，底座上刻着同一句话：

```
从左到右，必须由矮到高。
```

岩舟伸手拍了拍最近那根柱子：“这个我熟。第一章里搬石头、摆格子，都是差不多的手艺。”

“这次的麻烦不一样。”星泠说，“柱子不是你的。它摆在记忆晶阵里，是**别人给你的地址上的一排东西**。你要在原处把它们调换位置，不能搬出去重摆。”

“对。古人管这个叫**冒泡排序**。”星泠在沙地上画了一排小圈，“从最左边开始，看相邻的两根：左边比右边高，就换一换；然后往右移一格，再比一次。走完一趟，最高的那根一定被顶到最右边——像气泡冒上来。”

“那走一趟不够吧？”

“不够。第二趟会把第二高的送到倒数第二个位置。走 `n - 1` 趟，整排就顺了。”星泠在沙地上把两趟的痕迹叠在一起，“每一趟要检查的范围可以比上一趟少一格——末尾那几根已经就位了。”

屏幕上跳出新的目标：

```
本关目标：void solve(int* a, int n) 把 a 上这 n 个整数原地排成升序
不需要返回值，测试会在运行结束后检查整排记忆晶阵
参数 a 是数组的起始地址（十进制数字写在测例里）
```

“**原地**。”星泠重复了一下，“排序结束后，同一个地址上的内容必须变成升序排列。测试会读整个数组。”

岩舟点点头，又想到一件事：“相等的那两根呢？”

“相等就不用换。别去做无意义的交换，那一趟会白花魔力。”

---

**你要写的东西**

```c
void solve(int* a, int n) { ... }
```

把 `a[0] .. a[n-1]` 原地排成**升序**（从小到大）。没有返回值。

冒泡排序：

```c
for (i = 0; i < n - 1; i = i + 1) {
    for (j = 0; j < n - 1 - i; j = j + 1) {
        if (a[j] > a[j + 1]) {
            int t = a[j];
            a[j] = a[j + 1];
            a[j + 1] = t;
        }
    }
}
```

交换这一步，用的正是第 2-5 关的指针技巧——`a[j]` 和 `a[j+1]` 本身就是地址上的两个位置。

`n` 可能是 0 或 1，这时什么都不用做（循环自然不执行）。

```riscv

// 2-12 排序：把 a 上 n 个整数原地排成升序（冒泡排序）
void solve(int* a, int n) {
    int i;
    int j;
    for (i = 0; i < n - 1; i = i + 1) {
        for (j = 0; j < n - 1 - i; j = j + 1) {
            if (a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
}
```
