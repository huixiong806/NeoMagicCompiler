## 2.7 一层套一层的厅

闸门后面不是走廊，是一间厅。厅的正中有一道向下的口子，口子下面又是一间厅，再下面还有。像有人把同一间屋子叠了十二层。

每层厅的墙上都刻着一个数字：12、11、10……一直减到 1。

岩舟探头往下看：“这是要我们一层层走下去？”

“走完，然后把每一步的数字乘起来。”星泠指着井口上方那行刻痕，“这是古人的另一个习惯——**他们不写循环，他们写自己**。”

“写自己？”

“卷轴上这一句刻痕，是**函数调用**。”星泠在沙地上画了一个方框，方框里又画了一个小一号的方框，“阶乘：`n!`。要算 12!，先算 11!；要算 11!，先算 10!……直到有人告诉你 1! 是 1。每一层都**问下一层同一个问题**，只是问题小了一点。”

“那不就等于我那口井的循环？”

“结果一样，问法不一样。”星泠说，“循环是你在原地转圈；递归是你往下走一层，让下一层的自己去解决更小的问题，再带着答案回来。有些结构天生就是嵌套的——这个遗迹就是。”

屏幕上跳出新的目标：

```
本关目标：int solve(int n) 返回 n 的阶乘（n * (n-1) * ... * 1）
约定：0 的阶乘是 1（边界）
```

“0 的阶乘为什么是 1？”

“因为没有东西可以乘的时候，你就得返回‘什么都不乘的那个数’。”星泠把核心放稳，“1 乘任何数都不变，所以它是这里的起点。这叫**基线条件**——递归必须有一个不再往下问的尽头，否则它会一直往下挖。”

岩舟顿了顿：“……那不就是我把循环写反了时候的下场。”

“一模一样。”

---

**你要写的东西**

```c
int solve(int n) { ... }
```

返回 `n!`。`n` 的范围是 `0` 到 `12`（`12! = 479001600`，刚好不超出 32 位）。

递归的两个要点：

1. **基线条件**：`n == 0` 时返回 `1`（也可以再补一句 `n == 1` 时返回 `1`）；
2. **递归分支**：`return n * solve(n - 1);`

```riscv
{
  "level": "2-7",
  "language": "c"
}
---
// 2-7 函数与递归：返回 n 的阶乘（0 的阶乘是 1）
int solve(int n) {
    if (n <= 1) {
        return 1;
    }
    return n * solve(n - 1);
}
```
