## 1.9 反转印：把一段刻痕整体绕过去

岩舟第一个把手伸进了墙缝。

那是一个从砖石里凸出来的圆形印记，表面是一层光滑的、像琥珀一样的东西。他的指尖刚碰到它，印记就亮了一下，一道细细的红光顺着墙里的纹路往房间深处爬走了。

"把手拿开。"星泠说。

"我没使劲。"他把手收回来，"这东西烫了我一下。"

星泠蹲下去看那道纹路，又抬头看房间尽头——那里挂着一块牌子，牌子上是一个数字。她掏出刻笔，在墙角的灰上把房间画成了一条线。

"正路只有一条，一块一块刻痕地往下走。"她点着线的中段，"反转印就埋在中间。**只要引擎的刻痕条滑过它，它就会改掉 x1 里的数**——你走到尽头的时候，x1 里已经是错的了。"

"那就绕过去。"岩舟说，"前几关那个'跳'不就是干这个的吗。"

"前几关的跳要条件：`beq`、`blt`，都是先比一句再决定跳不跳。"星泠直起身，"这次不用比。这块印没有条件，谁踩上去就中。你要的是**无条件跳转**："

```text
j 标签     # 不看任何寄存器，直接跳到标签那一行
```

"`j` 是星之语里最干脆的一条刻痕——它把引擎的读数条直接挪到标签处，中间那几行连看都不看。"

岩舟在灰上画了个弧线，从中间那块印的上方越过去。"那我就在印前面画一条线，标到尽头那边去。"

"对。"星泠把刻笔递给他，"注意一件事：**你要跳过的不是一行，是两块刻痕**。反转印把它想写的数分成两步写进 x1，中间任何一个都不能被执行。跳的时候直接跳到 `finish` 那个标签上，一步跨过一整片。"

```riscv
{
  "level": "1-9",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 3,
    "lockedRegion": [1, 4],
    "readonlySuffix": 1,
    "suggested": { "6": "j finish" }
  }
}
---
# 前三行是闸已经刻好的，改不动
li x1, 2
j ok
addi x1, x0, 99
ok:
# ↑ 上面那块 addi 就是反转印：读数条只要滑过它，x1 就变成 99
# 任务：在下面这一行补一条 j，跳过反转印，把 x1 留成正确的数
# （在这一行写 j finish）
finish:
addi x1, x0, 7
ecall
```

**别急着写。** 先把上面那块 `addi` 的位置看清楚：它在 `j ok` 后面、`ok:` 标签下面——`j ok` 正好把引擎的读数条送到它跟前，一踩就中。

你要做的是在 `# （在这一行写 j finish）` 那个位置补一条 `j finish`，让读数条从 `j ok` 出发就直奔尽头。别直接跑这一关的初始代码：不做任何事的时候，x1 里会留下 99，那是闸最不喜欢的答案。

顺便，把 `j` 和标签的关系记牢：**标签是路标，不是命令**。读到标签那一行，引擎什么也不做，继续往下走；只有跳转指令才会用它。

读数条从反转印上方划过的那一瞬间，房间尽头那块牌子翻了个面。背面也是一行字，比前面几行都长：

**要算的次数，由闸给你；算到哪儿停，由你自己数。**
