## 4.12 终章：封印程序

石门后面的空气是热的，而且有节奏——像什么东西在很深的地方呼吸。

星泠和岩舟把方板抬进最后的厅。厅是圆的，正中是一根贯穿上下的黑柱，柱身被一圈圈刻痕箍住，刻痕里的光已经暗到发灰。厅的四壁是整块石面，上面刻着一整段星咒，从左边第一行一直连到右边最后一行。

“三百年零几个月。”星泠读着柱脚那行小字，“伊塔尔自己记的。他算得出封印还剩多久，也算得出自己活不到那天。”

岩舟把手按在黑柱上，又很快缩回来：“它在抖。”

“因为封印环正在一个一个松掉。”星泠走到石墙前，把魔导核心的输出线接上厅角的触点，“他留下的不是咒语，是一段**程序**：三圈封印环，每圈都要重新注入‘核’的量。第二圈有共振，要多注四倍。”

她把墙上那段读了一遍：

```c
int core() { return 6; }
int main() {
  int total = 0;
  int ring = 1;
  while (ring <= 3) {
    total = total + core();
    if (ring == 2) { total = total + core() * 4; }
    ring = ring + 1;
  }
  return total;
}
```

“第一圈 6，第二圈 6 加 24，第三圈 6。”岩舟跟着算，“一共 42。”

“42 就是重启序列的编号。”星泠说，“`main` 返回 42，封印认这个数。”

---

### 这一关怎么判：和上一关一样，真跑

判定器会把**墙上那段程序**（就是上面这一段，一字不差）当作字符流喂给你的编译器，然后：

1. 把你的输出交给真汇编器；
2. 找到 `main`，`jalr` 跳进去；
3. 等它 `ret`，看 `a0` 里是不是 **42**。

要求也和上一关一样：输出里必须定义 `main`、必须能被汇编、`main` 必须用 `ret` 结束（**不要**在生成的目标代码里写 `ecall`）。

**这段和 4-11 那段不一样的地方**：它多了一个 `if`，而且这个 `if` 在 `while` 里、**没有 `else`**，条件用 `==`。如果你的编译器只做到 4-11，就再补上 `if`：条件不成立时跳到“if 之后”，成立时顺序执行 then 分支。

```c
if (条件) 语句        →        beqz a0, L<跳过>
                               …条件成立时做的事…
                             L<跳过>:
```

> 一个诚实的提醒：这一关喂进去的程序是固定的，所以**把 42 写死也能过这一关**。但那样你手里就没有机器了——你只是记住了伊塔尔的一个数字。这一关真正要交的东西，是一台能读、能算、能自己吐出星之语的**机器**。

### 如果你还差一点

- 4-11 那台编译器**原封不动搬过来**就行，只需要补 `if`；
- 变量、循环、比较、调用都跟前面一样：`la a1, 名字` / `lw a0, 0(a1)` / `sw a0, 0(a1)`，标签 `L<数字>` + `beqz`；
- `if` 的标签编号也要继续用你那台机器自己的计数器往下发。

```riscv
{
  "level": "4-12",
  "language": "asm"
}
---
# ── 4-12 起点：管道已经通了，缺的是"看懂" ───────────────────────
# 输入：墙上那段星咒，从 0xF0000004 逐字符读，读到 0 表示结束
# 输出：星之语文本，逐字符写到 0xF0000000
#
# 这里还是那个"空壳程序"：它定义了 main、用 ret 结束、返回 0，
# 所以判定会把话说得很明白 —— main 的返回值应为 42，实际 0。
.data
stub: .asciz ".text\nmain:\nli a0, 0\nret\n"

.text
li   t1, 0xF0000004
read_loop:
lw   t2, 0(t1)
beqz t2, put
j    read_loop

put:
la   t3, stub
put_loop:
lbu  a0, 0(t3)
beqz a0, done
li   a7, 1
ecall
addi t3, t3, 1
j    put_loop

done:
li   a0, 0
li   a7, 0
ecall
```

---

方板背面最后一次吐出印痕的时候，厅里安静得能听见石粉落地的声音。

岩舟看着魔力计上的指针从灰区一路爬回绿区，第一圈、第二圈、第三圈，一圈一圈亮起来。黑柱不再抖了。

“……成了？”

星泠没有立刻回答。她把手从触点上拿开，看了很久黑柱上那三圈重新亮起来的光。“成了。”她说，“三百年，重新开始算。”

岩舟靠着石壁坐下去，笑得有点难看：“所以我们两个是被古代人拉来干活的。”

石墙最右下角，在星咒的末尾，还有一行比别处小得多的字。星泠凑过去，一个一个念出来。那不是程序，那是伊塔尔写给后来人的话：

> 你们能读懂它、编译它、让它跑起来，我很高兴。
> 但这台机器还可以更快：**先别急着往下刻**，让它在一种中间的语言里多停一会儿。
> 那些中间语言里，藏着让同一个魔法只用一半魔力的办法。
> 我没能等到那一步。你们赶得上。

星泠把这句话抄进笔记，合上本子。

“他说的那个‘中间的语言’是什么？”

“‘先把意思摊开、再决定刻成什么样’。”星泠说，“我们这台机器太急了——一边读一边就刻。第五章，我们给它加一层**中间表示**，看看能不能让它算得更省。”

两个人往门口走。锁死洞门的那套机关本来就靠封印的能量压着——封印一重启，销子自己退了回去。石门在他们手底下让开一条缝。

门外是真的外面的光。

台阶一层一层往上。岩舟走在前面，火把已经不需要了。

---

### 第四章到此结束

从第一章的 `li x1, 1` 到这一关的 42，你走过的路是：

**寄存器 → 控制流 → 内存 → 星咒 → 词法 → 语法 → 语义 → 代码生成 → 一整个能编译、能运行、能救人的编译器。**

这台机器是你自己写的。墙上那段星咒没有变过，能读懂它的东西，是你从第一条 `li` 开始一行一行搭出来的。

**新篇章**：让它在“中间表示”里多停一会儿——常量折叠、死代码删除、循环展开、寄存器分配。同一个魔法，一半的魔力消耗。
