## 3.9 完整表达式求值

两道门都开了，后面是一间很小的厅。

厅中央只有一块石板，石板上刻着一个方口，旁边一行小字，笔迹和别处不一样：

**此处吞算式。正负皆收。**

岩舟把手按在方口上，试着送进去：

```
-3+5
```

石板上的光晃了一下，什么也没吐出来。

"它不是错了。"星泠蹲下来看石板的边缘，"它是**卡住了**——它在等一个数，结果看到的是负号。上一关的因子只认两样东西：一串数字、或者一个左括号。负号不在里面。"

"那我们加一个。"

"加一个，但有讲究。"她把手在石板上划出四种情况：

```
-3+5      → 2
2*-3      → -6      ← 负号躲在乘号后面
-(1+2)*3  → -9      ← 负号管着一整个括号
--3       → 3       ← 负号可以叠
```

"这四种都要对，说明负号**必须放在最紧的那一层**。"

---

### 负号为什么住在因子层

"回想一下三层管道：加减最松，乘除更紧，因子最紧。"星泠说，"`2*-3` 里，`*` 右边需要一个因子——如果负号不是因子的一部分，乘除层吃到 `-` 就不知道该怎么办了。"

"所以因子的定义再加一条："

```
因子 := '-' 因子          ← 新增：负号后面还是一个完整的因子
      | 一串数字
      | '(' 算式 ')'
```

"注意右边写的是'因子'而不是'一串数字'。"她强调，"这就允许了 `--3`：第一个 `-` 之后又是一个因子，那个因子又是一个 `-` 开头的因子……一直到看见 `3`，然后一层一层取相反数回来。"

"取相反数怎么写？"

"`sub a0, x0, a0`。"星泠说，"`x0` 永远是 0，所以这叫'用 0 减掉它'。没有专门的取负指令，也不需要。"

### 一台完整的机器

"现在把三层摆在一起看——"

```
算式 := 项 (('+' | '-') 项)*          ← 只认加减
项   := 因子 (('*' | '/') 因子)*      ← 只认乘除
因子 := '-' 因子                      ← 只认负号
      | 一串数字                      ← 只认数字
      | '(' 算式 ')'                  ← 只认括号，然后把活儿交回最上面
```

"看最后一行。"星泠用笔尖点了点，"它把活儿交回**最上面那一层**，而不是交回自己。这就是为什么括号能'重置'整个优先级——括号里的一切，从最松的加减重新开始。"

"这三层加起来三十来行汇编。"岩舟说。

"这就是**递归下降**。"星泠把刻笔收起来，"从今天起，你写过的任何一条'看得懂的算式'，都可以拆成这三层。第四章你要写的那个编译器，表达式部分就是它。区别只是：那时候你不是'算它'，而是'把它翻译成星之印'。"

```riscv
{
  "level": "3-9",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [5],
    "suggested": {
      "5": "jal ra, expression",
      "6": "jal ra, print_int"
    }
  }
}
---
# 目标：求值一个完整的算式——支持 + - * /、括号、以及单目负号（-3+5、2*-3 都要对）。
#
# 在 3-8 的三层结构上只加一条规则：
#   因子 := '-' 因子 | 一串数字 | '(' 算式 ')'
#   负号后面调的还是 factor 自己（不是"一串数字"），所以 --3 也能算。
#   取相反数就是 sub a0, x0, a0。
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000

main:
        li      a4, INPUT
        li      a5, DISPLAY
        nop                             # ← 从这里开始写（三层 + 负号）
        li      a0, 0
        li      a7, 0
        ecall
```

岩舟重新送进去 `((2-5)*4+8)/-2`。这次石板没有犹豫：`2`。

他又试了 `--3`，石板回 `3`。

"成了。"星泠说，"现在这台机器能算任何一条算式。但它只会算**一条**。"

（下一关：遗迹的记录不是这么用的——它要的是**写好的数**，不是算式。）
