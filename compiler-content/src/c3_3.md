## 3.3 整数扫描

第二道刻痕对上之后，穹顶上的刻痕开始自己往中间收。

岩舟仰着头看了一会儿："它在**拼**东西。"

"它在拼数。"星泠说，"而且这次不是一个个字符了——它在往石台上**排队**。"

石台背上的缝里，光水开始一段一段地流：先是三个紧挨着的字符，停一下；再是四个字符，停一下；再是一大片，停一下。每一段之间有一个很短的空档。

"这些空档是什么？"

"空格。"星泠说，"伊塔尔换了口味：这次给的不是'一串字符'，是**若干个用空格分开的整数**。你的活儿是把它们一个个读进来，加在一起，把总和报给它。"

岩舟数了数："那还不是一样读？"

"**不一样。**"星泠把方板翻到新的一页，"前面两关你读一个字符处理一个字符；从这一关起，你要**把若干个字符拼成一个数**。这是翻译机里最难、也最常用的一步——**扫描**（scanning）。"

她在方板上写了三个数：

```
12   345   -7
```

"这三个数在输入里长什么样？"她自问自答，把引号一个个加上去：

```
'1' '2' ' ' '3' '4' '5' ' ' '-' '7'
```

"九个字符，三个数。**没有哪个字符单独告诉你是几**——`'3'` 不只是 3，它后面还跟着 `'4'` 和 `'5'`，合起来才是 345。所以拼数有一条铁律："

> **值 = 值 × 10 + 这一位**

"读一位就乘一次十。"星泠说，"`'3'` 进来，值还是 3；`'4'` 进来，先把 3 变成 30，再加 4 得 34；`'5'` 进来，先把 34 变成 340，再加 5 得 345。**这就是'十'这个字的位置感。**"

岩舟接了一句："那 `'-'` 呢？"

"负号不是数的一部分。"她说，"它是**符号**。看到 `'-'`，你先把'最后要取负'这件事记下来，接着照常拼数字，拼完了再整体取负。`neg` 一条 `sub` 就能做到：`0 - x`。"

---

**现在必须解决的麻烦**：这一关有**两个**新的麻烦，第一个比第二个更阴。

第一个是拼数，刚才讲过了。

第二个是：**别把下一个数的东西吃掉。**

"输入是 `'3' ' ' '4'`。"星泠把三个字符摆开，"你读完 `'3'`，怎么知道这个数到头了？——因为下一个是空格。但你**不能把空格留在肚子里不管**：你得靠它知道'3'结束了。可你又不能把它当成'4'的一部分。"

她给出这一关的标准写法：

1. **跳过分隔符**：空格（32）、换行（10）、回车（13），一直读到不是分隔符为止；
2. **看有没有负号**（字符 45）：有就先记下符号，再读一位；
3. **逐位拼**：只要读到的字符在 `'0'`（48）到 `'9'`（57）之间，就 `值 = 值 × 10 + (字符 - 48)`，然后读下一位；
4. **读到非数字就收手**——但**不把它吃掉**。它可能是下一个数的开头。下一次进"读一个整数"的时候，第一步恰恰就是再读一个字符，两个循环刚好接上。

```
输入：      3  -45  7
读到：      '3' ' ' '-' '4' '5' ' ' '7'  → 0(结束)
第 1 个数：  3      （'3' 拼好，收手时读到 ' '，它交给下一轮的第一步用）
第 2 个数：     -45
第 3 个数：           7
```

"把这一整套写成一个**子程序**。"星泠说，"`jal x1, read_int` 跳过去，`jalr x0, 0(x1)` 跳回来，读到的数放在 `x10` 里。骨架里已经给了你 x20 = 输入端口、x21 = 显示端口，还有主循环的形状。"

```riscv
{
  "level": "3-3",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 3,
    "readonlySuffix": 2,
    "suggested": {
      "4": "写一个 read_int 子程序：跳过分隔符 → 看有没有负号 → 逐位拼成数值，结果放 x10",
      "5": "循环调用 read_int，把读到的数加到 x18，读到 0 就跳出循环"
    },
    "highlight": [4]
  }
}
---
li x20, 0xF0000004
li x21, 0xF0000000
addi x18, x0, 0
# ↓ 下面从这里开始写：
#   1. 写一个"读一个整数"的子程序 read_int：先跳过分隔符（空格 32、换行 10、回车 13），
#      再看开头有没有负号（字符 45），然后逐位拼：值 = 值 * 10 + (字符 - 48)；
#      读到不是数字的字符就收手 —— 但**不要把它吃掉**，它可能是下一个数的开头。
#      跳过去用 jal x1, read_int，跳回来用 jalr x0, 0(x1)，读到的数放在 x10 里。
#   2. 在循环里反复调用 read_int：读回 0（队列空了）就跳出循环，
#      否则把 x10 加到 x18 上，继续读下一个。
#   3. 循环结束后：把总和 x18 写进 0x2000，再用 a7 = 2 打印出来。
li x10, 0
li x17, 0
ecall
```

两个容易踩的坑：

- **拼数的顺序**：一定是"先乘 10，再加这一位"。反过来（先加再乘）会让 `12` 变成 `(0+1)*10 = 10` 再 `(10+2)*10 = 120`——多出一位。
- **读到非数字别丢**。如果收手时把那个字符扔了，下一个数的第一位就没了：`3 45` 会被读成 `3` 和 `5`。

总和报上去的那一刻，石台里传出一声很长的回声，像有什么东西被拧开了很久。

岩舟呼了口气："总算只是个加法。"

"下一条刻痕不是加法。"星泠盯着穹顶，"它在**判词**——什么样的东西算一个'词'，什么样的不算。"
