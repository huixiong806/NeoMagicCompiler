## 1.3 减法，以及两格之间怎么搬家

第二块方板亮了。这一次亮的不是数字，是两行并排的刻痕，像一对秤盘。

星泠读了一遍，眉头动了一下。

"闸要两样东西。第一样是 x1 减 x2，结果放进 x3。"她指着左边那行，"第二样更麻烦——它要 x1 和 x2 里的数**互相交换**。x1 里原本的数去 x2，x2 里原本的数去 x1。"

岩舟看了看方板，又看了看自己两只手。"交换……那我先把 x1 抄到别处，再把 x2 抄进 x1，最后把抄下来的那份放回 x2。三步。"

"三步是对的，"星泠说，"但你已经先占掉一个寄存器了。而且方板只留了这几格给你写，中间一格也不能浪费。"

"你总有别的办法。"

"减法就够。"她取出一支新刻笔，"`sub x3, x1, x2` 是 x1 减 x2。至于交换——先让 x1 变成'两数之和'，再用减法和它自己的和去还原："

```text
add x1, x1, x2   # x1 现在是 原x1 + 原x2
sub x2, x1, x2   # 减掉原x2，x2 拿到 原x1
sub x1, x1, x2   # 再减掉刚拿到的原x1，x1 拿到 原x2
```

"和减去其中一份，剩下的就是另一份。"星泠把刻笔递过去，"加法能造出一份和，减法能从和里把两份拆开——所以两个寄存器之间的搬运，不需要第三个格子。"

岩舟接过刻笔，在那块秤盘似的方板上比划了一下位置。

"先算差，再交换。顺序别弄反了：一旦开始交换，x1 和 x2 里的数就不是原来的数了。"

```riscv
{
  "level": "1-3",
  "language": "asm",
  "constraints": {
    "readonlySuffix": 1
  }
}
---
# 开关被闸封住，x1、x2 里的数由闸自己灌进来
# 任务一：x3 = x1 - x2
# 任务二：把 x1 和 x2 的值互换（不能用别的寄存器存副本）

ecall
```

如果你先交换再算差，`x3` 会变成原来那个差的相反数——闸会告诉你它不满意。

跟着`add`和`sub`一起亮起来的，还有旁边一小段从没见过的符号：一个斜杠，前后各挂一个数。星泠盯着它看了很久，才开口：“商……和余数。这扇门想让我们先把一个数拆开。”
