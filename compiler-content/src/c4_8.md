## 4.8 代码生成：赋值与变量

篆刻面吐出第一段星之语的时候，岩舟盯着看了很久。

"`li a0, 1`……这个我认。可它只认数字。"他敲了敲方板，"星咒里最普通的那句 `int x = 3;`，它怎么刻？"

星泠翻过方板，把下一行星咒推上去：

```
int x = 3; x = x + 4;
```

"上一关我们把表达式**算完就丢**——因为常量算完就是个常量。"她指着方板背面那块空白，"从这一句开始不一样了：`x` 的名字要**留下来**。它得有个地方待着，而且那个地方要能再被读到。"

"记忆晶阵。"

"记忆晶阵。"星泠在方板边缘写下结论，"**变量是要住在记忆里的东西。**"

---

**这一关的语法**（在上一关的表达式上加了语句）：

```
程序 := 语句*
语句 := int 名字 = 表达式 ;     （声明 + 初值，名字是单个字母 a–z）
      | 名字 = 表达式 ;         （赋值）
      | 表达式 ;                （表达式语句）
```

**这一关要求的输出**：一段完整的星之语程序，其中

- `.data` 段里给每个**声明过**的变量留一个格子；
- `main:` 之后是语句的代码，最后 `ret`（跟上一关一样，不要 `ecall`）；
- 执行到最后，`a0` 里放着**最后一条语句的值**。

`int x = 3; x = x + 4;` 应该被编成（这段是参考解**逐字节**吐出来的，判定拿它按行比）：

```
.data
x: .word 0
.text
main:
li a0, 3
la a1, x
sw a0, 0(a1)
la a1, x
lw a0, 0(a1)
addi sp, sp, -4
sw a0, 0(sp)
li a0, 4
lw a1, 0(sp)
addi sp, sp, 4
add a0, a1, a0
la a1, x
sw a0, 0(a1)
ret
```

注意这里**没有注释行**：判定是逐行比，你多吐一行 `# int x = 3;` 就算错。指令一律不缩进，一行一条。

### 三件事，各管一段

**一、变量要先"报到"，数据段才能写。** 数据段必须在代码段**前面**吐出来（`.data` 在 `.text` 之前），可是"有哪些变量"要读完整个程序才知道。所以流程变成：

1. 先把源码读进 `src`；
2. **预扫一遍**：只找 `int 名字`，把名字记进 `decls`（26 个字节，第 `字母-'a'` 个是 1）；
3. 吐 `.data`，再把 `decls` 里打勾的字母按顺序写出来（`x: .word 0`）；
4. 吐 `.text` / `main:`；
5. **正式编译一遍**语句；
6. 吐 `ret`，整块送到显示端口。

这就是**两遍扫描**：第一遍收集"有什么"，第二遍才生成。

**二、读变量、写变量，各有两条固定写法。** 变量的值住在记忆晶阵里，`la` 把地址取到 `a1`，再用 `lw` / `sw`：

| 动作 | 吐出来的指令 |
|------|--------------|
| 读 `x`（在表达式里） | `la a1, x` + `lw a0, 0(a1)` |
| 写 `x`（`x = …`） | `la a1, x` + `sw a0, 0(a1)` |

上一关的表达式生成器一个字都不用改：变量读到 `a0` 以后，就和"一个常量的值"一样，随便参与后面的运算。

**三、每条语句都要把"值"留在 `a0`。** 这是本关唯一新增的约定，也是判定看的东西：

- `int x = 3;` 的值是 `3`（初值）；
- `x = x + 4;` 的值是**被赋进去的那个值**（`7`）——注意 `sw` 只写内存、不动 `a0`，所以先算出来的值还在 `a0` 里，不用重读；
- 所以 `int x = 3; x = x + 4;` 跑完，`main` 返回的就是 `7`。

### 顺手的小工具

新骨架里已经给你两样东西，省得每次都自己拼字符串：

- `emit_char`：把 `a0` 里的**一个字符**接到 `out` 末尾（吐变量名 `x` 正好用它）；
- `peek` / `adv` / `skip_ws` / `match`：把"看一个字符、吃掉一个字符、跳空白、吃掉指定字符"包成了小函数，判语句类型时非常顺手。

判"这句是声明还是赋值"可以看得很土：先跳到第一个有效字符，如果是 `i` 而且后面接着 `nt`，就是声明；否则如果它是字母、跳过空白后跟着 `=`，就是赋值。

```riscv
{
  "level": "4-8",
  "language": "asm",
  "constraints": {
    "suggested": {
      "56": "把 gen_stub_stmts 换成你自己写的 gen_stmts（一条语句一条语句地编）",
      "297": "这一块换成 gen_stmt：int 声明 / 名字=赋值 / 表达式语句，三种各一条路"
    }
  }
}
---
# ── 4-8 篆刻机：赋值与变量 → 星之语 ───────────────────────────────
# 输入：星咒源码；输出：星之语文本（都要经过 MMIO）
# 生成程序必须：.data 列出变量、.text 里 main: → 语句 → ret，
#               结束时 a0 里是"最后一条语句的值"
# 支持：int x = 表达式; / x = 表达式; / 表达式;
.data
src:        .space 1024
out:        .space 8192
tinstr:     .space 16
decls:      .space 32
cur:        .word 0
wc:         .word 0
str_data:   .asciz ".data\n"
str_text:   .asciz ".text\nmain:\n"
str_word0:  .asciz ": .word 0\n"
str_la:     .asciz "la a1, "
str_lw:     .asciz "lw a0, 0(a1)\n"
str_sw:     .asciz "sw a0, 0(a1)\n"
str_li:     .asciz "li a0, "
str_nl:     .asciz "\n"
str_push:   .asciz "addi sp, sp, -4\nsw a0, 0(sp)\n"
str_pop:    .asciz "lw a1, 0(sp)\naddi sp, sp, 4\n"
str_add:    .asciz "add a0, a1, a0\n"
str_sub:    .asciz "sub a0, a1, a0\n"
str_mul:    .asciz "mul a0, a1, a0\n"
str_div:    .asciz "div a0, a1, a0\n"
str_ret:    .asciz "ret\n"

.text
compile_entry:
    # 1) 把输入读进 src（读到 0 表示输入结束）
    la   a1, src
    li   a2, 0xF0000004
read_loop:
    lw   a0, 0(a2)
    beqz a0, read_done
    sb   a0, 0(a1)
    addi a1, a1, 1
    j    read_loop
read_done:
    sb   x0, 0(a1)

    # 2) 预扫：填 decls（哪些变量被声明过）
    jal  ra, prescan_decls

    # 3) 吐数据段：".data"，再把声明过的变量写成 "x: .word 0"
    la   a0, str_data
    jal  ra, emit_str
    jal  ra, emit_data_seg

    # 4) 【你要写的】吐 ".text" 与 "main:"（la + jal 两行照上面抄）
    la   a0, str_text
    jal  ra, emit_str

    # 5) 【你要写的】接上 gen_stmts：把源码里的语句都编出来
    jal  ra, gen_stub_stmts

    # 6) 吐收尾
    la   a0, str_ret
    jal  ra, emit_str

    # 7) 把 out 整块送到显示端口
    la   s0, out
    li   s1, 0xF0000000
emit_out_loop:
    lbu  a0, 0(s0)
    beqz a0, emit_out_done
    sw   a0, 0(s1)
    addi s0, s0, 1
    j    emit_out_loop
emit_out_done:
    li   a0, 0
    li   a7, 0
    ecall

# ── reset_lex：词法游标归零，并把第一个字符读进 wc ──────────────
reset_lex:
    la   t0, cur
    sw   x0, 0(t0)
    la   t1, src
    lbu  t2, 0(t1)
    la   t1, wc
    sb   t2, 0(t1)
    ret

# ── prescan_decls：只找 `int 字母`，把字母记进 decls ─────────────
#   这一遍不动词法游标（直接拿指针扫 src），扫完才 reset_lex。
prescan_decls:
    la   s3, src
    li   s5, 0                   # s5 = 源码长度
prescan_len:
    add  t0, s3, s5
    lbu  t1, 0(t0)
    beqz t1, prescan_loop
    addi s5, s5, 1
    j    prescan_len
prescan_loop:
    lbu  t0, 0(s3)
    beqz t0, prescan_done
    li   t1, 105                 # 'i'
    bne  t0, t1, prescan_next
    addi t0, s3, 3
    bgeu t0, s5, prescan_next
    lbu  t1, 1(s3)
    li   t2, 110                 # 'n'
    bne  t1, t2, prescan_next
    lbu  t1, 2(s3)
    li   t2, 116                 # 't'
    bne  t1, t2, prescan_next
    lbu  t1, 3(s3)               # int 后面必须是空白
    li   t0, 32
    beq  t1, t0, prescan_mark
    li   t0, 10
    beq  t1, t0, prescan_mark
    j    prescan_next
prescan_mark:
    lbu  t1, 4(s3)               # 变量名（单个字母 a–z）
    li   t0, 97
    blt  t1, t0, prescan_next
    li   t0, 123
    bge  t1, t0, prescan_next
    addi t1, t1, -97
    la   t0, decls
    add  t0, t0, t1
    li   t1, 1
    sb   t1, 0(t0)
    addi s3, s3, 4
    j    prescan_loop
prescan_next:
    addi s3, s3, 1
    j    prescan_loop
prescan_done:
    j    reset_lex

# ── emit_data_seg：按字母顺序吐出声明过的变量 ──────────────────
emit_data_seg:
    addi sp, sp, -4
    sw   ra, 0(sp)
    li   s2, 97                  # 'a'
emit_data_loop:
    li   t0, 123
    bge  s2, t0, emit_data_done
    la   t1, decls
    addi t2, s2, -97
    add  t1, t1, t2
    lbu  t1, 0(t1)
    beqz t1, emit_data_next
    addi a0, s2, 0
    jal  ra, emit_char
    la   a0, str_word0
    jal  ra, emit_str
emit_data_next:
    addi s2, s2, 1
    j    emit_data_loop
emit_data_done:
    lw   ra, 0(sp)
    addi sp, sp, 4
    ret

# ── emit_char：把 a0 里的一个字符接到 out 末尾 ──────────────────
emit_char:
    la   t0, out
emit_char_skip:
    lbu  t1, 0(t0)
    beqz t1, emit_char_put
    addi t0, t0, 1
    j    emit_char_skip
emit_char_put:
    sb   a0, 0(t0)
    addi t0, t0, 1
    sb   x0, 0(t0)
    ret

# ── emit_str：把 a0 指向的字符串接到 out 末尾 ───────────────────
emit_str:
    la   t0, out
emit_str_skip:
    lbu  t1, 0(t0)
    beqz t1, emit_str_copy
    addi t0, t0, 1
    j    emit_str_skip
emit_str_copy:
    lbu  t1, 0(a0)
    beqz t1, emit_str_done
    sb   t1, 0(t0)
    addi a0, a0, 1
    addi t0, t0, 1
    j    emit_str_copy
emit_str_done:
    sb   x0, 0(t0)
    ret

# ── emit_num：把 a0 里的非负整数按十进制接到 out 末尾 ────────────
emit_num:
    la   t0, out
emit_num_skip:
    lbu  t1, 0(t0)
    beqz t1, emit_num_start
    addi t0, t0, 1
    j    emit_num_skip
emit_num_start:
    la   t1, tinstr
    addi t2, t1, 16
    sb   x0, 0(t2)
    addi t2, t2, -1
    li   t3, 10
    bnez a0, emit_num_digits
    li   t4, 48
    sb   t4, 0(t2)
    addi t2, t2, -1
    j    emit_num_copy
emit_num_digits:
    remu t4, a0, t3
    addi t4, t4, 48
    sb   t4, 0(t2)
    addi t2, t2, -1
    divu a0, a0, t3
    bnez a0, emit_num_digits
emit_num_copy:
    addi t2, t2, 1
emit_num_copy_loop:
    lbu  t4, 0(t2)
    beqz t4, emit_num_done
    sb   t4, 0(t0)
    addi t0, t0, 1
    addi t2, t2, 1
    j    emit_num_copy_loop
emit_num_done:
    sb   x0, 0(t0)
    ret

# ── 词法小工具：peek 看当前字符，adv 吃掉它 ────────────────────
peek:
    lw   a0, wc
    ret

adv:
    la   t0, cur
    lw   t1, 0(t0)
    addi t1, t1, 1
    sw   t1, 0(t0)
    la   t2, src
    add  t2, t2, t1
    lbu  t3, 0(t2)
    la   t4, wc
    sb   t3, 0(t4)
    ret

is_ws:                           # a0 里的字符是空白吗？
    li   t0, 32
    beq  a0, t0, is_ws_yes
    li   t0, 10
    beq  a0, t0, is_ws_yes
    li   t0, 13
    beq  a0, t0, is_ws_yes
    li   t0, 9
    beq  a0, t0, is_ws_yes
    li   a0, 0
    ret
is_ws_yes:
    li   a0, 1
    ret

skip_ws:
    addi sp, sp, -4
    sw   ra, 0(sp)
skip_ws_loop:
    jal  ra, peek
    jal  ra, is_ws
    beqz a0, skip_ws_done
    jal  ra, adv
    j    skip_ws_loop
skip_ws_done:
    lw   ra, 0(sp)
    addi sp, sp, 4
    ret

match:                           # 吃到 a0 里的字符返回 1，否则返回 0
    addi sp, sp, -8
    sw   ra, 0(sp)
    sw   a0, 4(sp)
    jal  ra, peek
    lw   t0, 4(sp)
    bne  a0, t0, match_no
    jal  ra, adv
    li   a0, 1
    j    match_done
match_no:
    li   a0, 0
match_done:
    lw   ra, 0(sp)
    addi sp, sp, 8
    ret

# ── gen_stub_stmts：占位实现，只会吐一行注释并跳过整个源码 ────────
#   把 `jal ra, gen_stub_stmts` 换成 `jal ra, gen_stmts`，再写 gen_stmt。
gen_stub_stmts:
    la   t0, src
    la   t1, cur
    lw   t2, 0(t1)
    add  t0, t0, t2
    li   t3, 0
    sb   t3, 0(t0)               # 把游标位置截断 → 后面什么都不编
    la   t1, wc
    sb   x0, 0(t1)
    ret
```

骨架里只有 **`gen_stmts` 这一块是空的**（预扫、数据段、`emit_*`、词法小工具都给你了）：

1. `gen_stmts`：把语句一条一条看过去，到源码末尾（或 `}`）就停；
2. `gen_stmt`：三种语句各一条路——
   - 当前位置是 `int`（`peek` 看到 `i`，再看后面两个字节是不是 `nt`）→ 声明：吃名字、吃 `=`、`gen_expr` 得初值、吃 `;`、`la`+`sw` 写回内存；
   - 当前位置是字母、**跳过空白后**跟着 `=` → 赋值：吃名字、吃 `=`、`gen_expr`、吃 `;`、`la`+`sw` 写回内存；
   - 其它 → 表达式语句：`gen_expr` + 吃 `;`。
3. 表达式生成器（`gen_expr` / `gen_term` / `gen_unary`）直接照上一关的样子搬过来，只加一条：`gen_unary` 遇到字母时，吐 `la a1, x` + `lw a0, 0(a1)`。

一个容易漏的细节：**`sw` 之后 `a0` 里的值还在**，所以"语句的值"不用再读一遍内存——`int x = 3;` 的值就是刚才算出来的 `3`。

判定只看**显示端口吐出来的文本**（按行比对：去掉每行首尾空白、丢掉空行，逐行一致才算过）。所以吐出来的每一行都要**一模一样**——缩进无所谓，多一行少一行都不行。

岩舟把 `int x = 3; x = x + 4;` 推上去，方板上刻出来的第一段里有 `x: .word 0`。

"它在晶阵里给 x 划了个格子。"

"对。"星泠说，"而且它还知道 **x 现在装的是 7**。"
