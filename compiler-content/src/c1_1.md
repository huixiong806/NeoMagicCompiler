## 1.1 从 1+1 开始

遗迹门后的空气涌出来，你皮肤上那阵发紧的感觉还没散。

岩舟把手按在门后的石壁上，那里嵌着一块半透明的方板，像被冻住的湖面。方板中间浮着两行黯淡的刻痕，都不亮。

"门是开了，"他用力擦了擦方板边缘，掌心沾下一层灰，"可这条路后面还有三道闸。闸要吃星之语。"

星泠把那块方板从壁槽里取下来，反过来——背面嵌着一块巴掌大的**魔导核心**。外壳上三十二个凹槽排成两列，绝大多数空着。

"这些凹槽叫**寄存器**，编号 x0 到 x31。"她把核心托在掌心里，"魔导引擎只认它们。数放在里面才能算，刻痕只是把数搬来搬去的话。"

"那现在里面有什么？"

"什么都没有。两行刻痕空着，因为还没有人告诉它该算什么。"

岩舟盯着那块方板看了三秒，把凿子往腰带上一插："所以它跟我一样，得先听人把话说明白。"

星泠没接他的话，把一个数字推到第一格，又一个数字推进第二格。两格都亮起来，都是 `1`。

"先试最小的：x1 和 x2 里各有一个 1。"她说，"把两个格子的数相加，结果放进 x3。"

```riscv
# 把 x1 与 x2 相加，结果写入 x3
add x3, x1, x2
ecall
```

加法指令写起来是这样的：

```text
add 目标寄存器, 源寄存器1, 源寄存器2
```

`add x3, x1, x2` 的意思是：把 x1 和 x2 里的数相加，结果存进 x3。这一关执行完，x3 里应该正好是 `2`。

最后一行 `ecall` 是固定的收尾，它负责让魔导引擎停下；你在它上面写指令就好。

按**运行**先看一眼寄存器面板——三格里突然出现的数字，就是这条遗迹第一个愿意回话的证据。而第三格里那个 2，只解决了一道加法：闸上的算式不会永远只有一个加号。
