## 3.1 读字符流

第三章：简单的魔法翻译机

---

遗迹更深处是一间没有门的厅。岩舟用手里的光石照了一圈，照到三面墙上密密麻麻的刻痕——不是符文，是**字**。是某种文字记录。

"伊塔尔写字了。"他说。

"而且他不止写字。"星泠把方板对准厅中央。

正中央的石台上蹲着一台东西：比人矮，像一只缩起来的兽。它身上没有摇杆、没有齿轮，只有背上一道细长的缝，和侧面一个方口。缝里正有东西在动——一层薄薄的、像水一样的光，从左往右流。

"它自己会动？"

"不。"星泠把手伸进那道缝里，光水从她指缝里穿过去，"**它只是在被读。**它肚子里排着两行东西：一行是**字符**，一行是**数**。这两行永远不一样长——字符排得满满当当，数只有那么几个。"

她指向石台正面刻的一行字：**此处吞字，读一走一**。

"这就是**字符流**。"她说，"不是一整块石头、一个打包好的数，而是**一个接一个来的单个字符**。每读走一个，队列就短一格。伊塔尔把这台机器留在这里，是为了教后来的人一件事：**翻译的第一步，是把'一串字符'看成一个一个字符。**"

岩舟把手按在石台侧面的方口上。方口里传出一声很轻的'嗒'。

"这个方口是**输入端口**，地址 `0xF0000004`。"星泠在他手边敲了敲方板，"读它的办法跟我们读记忆晶阵里的数**一模一样**：`lw`。

```asm
li  x1, 0xF0000004    # x1 固定放输入端口的地址
lw  x5, 0(x1)         # 从队列头取走一个字符，它现在在 x5 里
```

"取走的字符就没了，不会回来——所以'读两次同一个字符'这种事不存在。"

"那读到什么时候算完？"

"读回 `0` 就算完。"星泠说，"注意：这不是让你去输入里找一个编号为 0 的字符，而是**队列空了的信号**。伊塔尔特意选了 0 当结束标记，因为真正要读的字符都在 1 到 255 之间。"

她翻开方板背面，那是**显示端口**：

```asm
li  x10, 'A'          # 想送出去的字符放 a0（x10）
li  x11, 1            # a7（x11）= 1：告诉引擎"我要输出一个字符"
ecall
```

"字符也可以直接用单引号写，`'0'` 就是 48，`'\n'` 就是 10，比记编码省事。"

---

**现在必须解决的麻烦**：这台机器只认"字符个数"。

石台正面的那行字下面还有一行更小的字：**过路者，量其长以启之**。岩舟把手往缝里一放，光水的流速明显变了——机器在等一个数，等到的数不对，它就不肯再往下走。

"它要的是**这一串字符有多长**。"星泠说，"连换行也算一个字符——换行也是从缝里过来的字符，凭什么不算。只有那个 `0` 不算，它不是字符，是'没了'。"

你手上的方板里有一段骨架代码，它现在只会把整串字符**白白读光**（读完了，什么都不做就退出）。你要做的是：一边读一边数，读完把个数说出来。

1. 骨架里已经把输入端口地址放进了 x1；
2. 把 `read_loop` 的循环写成"读一个字符 → 是 0 就跳出 → 否则计数器加一"；
3. 数完把个数存进 `0x2000`（机器要看这个数）；
4. 用 `li a7, 2` 让引擎把这个数按十进制打出来——**这是你自己把数字变成字符的一次实践**，引擎替你做了，但你要知道它做的是"把每一位拆出来、各加 48"这件事。

```riscv
{
  "level": "3-1",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 2,
    "suggested": { "3": "lw x5, 0(x1)；读到 0 就该跳出循环" },
    "highlight": [8]
  }
}
---
li x1, 0xF0000004
addi x8, x0, 0
read_loop:
lw x5, 0(x1)
beq x5, x0, done_read
j read_loop
done_read:
# ↓ 下面从这里开始写：把计数器写进 0x2000，再把这个数打印出来
li x10, 0
li x11, 0
ecall
```

两个容易踩的坑：

- **`0` 不是字符，是"没了"**。忘了判断它，循环就会一直读下去，读回一串 0，计数器一直涨到指令数上限——判定会告诉你"执行太久"。
- **循环里必须真的往队列里读**。如果 `read_loop` 里没有 `lw`，它会变成一个原地打转的死循环：`beq` 拿的是上一次那个字符，永远同一个答案。

机器在计数对上之后安静下来，背上的缝松了一格，光水从中间裂开，露出第二道刻痕。

星泠看了那行刻痕一眼，脸色有点古怪。

"第二道要的不是个数。"她说，"它把**每种字符分开数**：数字几个、字母几个、剩下的几个。伊塔尔在教我们**分类**。"
