## 1.12 让引擎停一下

门后的房间很低，岩舟得低着头走。房间中央又是一排刻度，和上一关一样，从 `0x1000` 起。

但这一次，方板的边缘先亮了。

星泠把它举到眼前，方板侧面浮出一行小字：**本机关读数有限，共 500 格**。

"闸给它限了数。"她说，"如果循环写错了，引擎会在 500 格之前用完自己，然后停在半路——我们什么都看不到，只看到它停了。"

岩舟蹲下去数刻度，数到第五个就不数了。"那我还是照上一关写？读出、加进总和、挪指针、计数加一。"

"照写可以。但这道门要的不只是总和。"星泠把方板翻过来，背面是一整片密密麻麻的格子，每个格子里都跳着两位十六进制数，"它要我们**看清过程**：第一次转圈的时候，计数器是多少、指针指着哪一格、总和涨到了多少。光看最后的结果，我们不知道它是自己转的圈，还是瞎撞的。"

她在方板边上敲了三下，那片格子放大成了一整块面板。"这一关我教你一条新刻痕："

```text
ebreak        # 断点：引擎走到这里会停住，等你按"继续"
```

"`ebreak` 不改变任何寄存器，它只做一件事——**让读数条停住**。停住的时候，调试面板会把此刻三十二个寄存器和整片记忆晶阵都摊开给你看。"

"所以我要把它放在循环体里。"

"放在循环体里，它每次转圈都会停一次。"星泠说，"第一次转圈的时候，你看一眼 `x5` 是不是 1、`x6` 是不是 0x1004、`x10` 是不是等于刚读出来的第一个数——这三样对上了，循环就是按你想的在走。对不上，你立刻知道是哪一步错了。"

```riscv
{
  "level": "1-12",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "suggested": { "2": "addi x10, x0, 0", "3": "addi x5, x0, 1" }
  }
}
---
li x6, 0x1000
# x1 里是 n，x6 指着 0x1000
# 任务一：和上一关一样，求前 n 个字的和，结果放进 x10
# 任务二：在循环体里放一条 ebreak，让第一次转圈时能停下来观察

# 循环体写在下面（记得在行尾加上冒号做路标）

ecall
```

**用调试面板的顺序**：先按运行让引擎转起来，它在 `ebreak` 处停下之后，面板会亮起寄存器表和记忆晶阵；看完了再按继续，它就会往下一圈走。这一关引擎只肯走 500 格，所以别指望它自己走完全程——你得学会在它停下的地方读它。

星泠把方板塞回岩舟手里的时候，他的手还在抖。

"这一关你写。"她说，"下一关开始，我要动更狠的东西——我们要让引擎**离开主线**，去别的地方干一趟活，再回来。"
