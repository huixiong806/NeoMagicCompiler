## 1.14 只有一个 x1，而它随时会被盖掉

石室深处的门后，是一间更小的房间。

房间中央立着一块用整石凿出来的方台，台上刻着两句话：

```
f(x) = square(square(x))
```

岩舟读完，回头看了一眼上一关那根柱子："这不就是按两下。"

"是。"星泠说，"但要**按得回来**。"

她蹲下去看方台的底座，底座上有一圈浅浅的划痕，划痕中间嵌着一块小小的凹槽——明显是给人放东西的。

"上一关我们只跳出去**一层**：主线叫了一趟子程序，子程序干完就回来。"她说，"现在要两层：主线叫 `f`，`f` 自己还要叫一次 `square`。问题出在这里——"

她拿刻笔在灰上画了两格。

"`jal` 只认 `x1` 这一个格子。主线叫 `f` 的时候，x1 里记的是'回到主线'；`f` 叫 `square` 的时候，`jal` **把这个格子整个盖掉**，换成'回到 f'。等 `square` 干完跳回来，`f` 想再回去，可它已经忘了主线在哪儿了。"

岩舟把那两格看了很久。"那我们是丢了自己回家的路。"

"丢在了一个地方。"星泠用刻笔点着方台底座那个凹槽，"下面这句话是这一关的重点：**x1 只是一个普通寄存器**。它能被盖掉，就意味着它也能被**存起来**。存的不是别处——是**栈**。"

她把手按在方台上：

"栈是一块专门用来暂存东西的记忆空间，它的规矩很特别：**先放进去的后拿出来**。它有一个指针，叫 `sp`，也就是 x2。规矩只有两条："

```text
addi sp, sp, -4    # 先给自己挪出 4 个字节的空位
sw   x1, 0(sp)     # 把 x1 存进刚挪出来的那格（压栈）
lw   x1, 0(sp)     # 把 x1 取回来（出栈）
addi sp, sp, 4     # 把空位还回去
```

"调用之前压下去，回来之后再捞上来。"她说，"你甚至可以两层、三层、十层——栈够深，路就不会丢。**方台要的就是这一手**。"

```riscv
{
  "level": "1-14",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 3,
    "readonlySuffix": 5,
    "suggested": { "4": "jal x1, f", "5": "addi x10, x6, 0", "7": "addi sp, sp, -4", "8": "sw x1, 0(sp)" }
  }
}
---
# 0x1000 那一格里放着参数（这三行是闸钉死的：读地址、读参数、调用 f）
addi x6, x0, 0x1000
lw x6, 0(x6)
jal x1, f
# 任务：f 返回之后把 x6 里的结果搬进 x10，然后在 f 里面写两层调用

f:
# 在 f 里：先把 x1 压栈，再连着调两次 square，
#          最后把 x1 从栈里捞回来、还回空位，照着它回主线

# ↓ 下面四行是闸钉死的 square 子程序（它只认 x6）
square:
mul x6, x6, x6
jalr x0, 0(x1)
ecall
```

写成这个顺序（参数已经在 x6 里——`square` 认的就是 x6，而 x1 必须空出来记返回地址）：

1. `jal x1, f` 已经在上面了；f 返回后用 `addi x10, x6, 0` 把结果搬进 a0；
2. 在 `f:` 底下：`addi sp, sp, -4` 挪出空位、`sw x1, 0(sp)` 把 x1 压栈；
3. `jal x1, square` 调第一趟——回来之后 x1 里是"回到 f"；
4. 再 `jal x1, square` 调第二趟（x6 已经被平方过一次，所以这次是四次方）；
5. `lw x1, 0(sp)` 把出发位置捞回来、`addi sp, sp, 4` 还回空位；
6. `jalr x0, 0(x1)` 回主线——**注意这里用的是从栈里捞回来的 x1，不是第二趟留下的那个**。

**为什么非要压栈？** 第 3 步的 `jal` 把 x1 盖成了"回到 f"，第 4 步的 `jal` 又盖一次。等你想要回家的时候，x1 里已经不是出发位置了——照着它跳，只会跳回 f 自己，f 再叫一次 square，square 再把你送回 f，引擎就在这条线上绕圈到把读数额度用完。没有栈，你就丢了自己回家的路。

方台上那圈划痕在岩舟压完第一次栈之后，从起点亮到了终点，像有人把丢掉的脚印一格一格接了回去。

星泠没有笑。她盯着方台底下新露出的一行小字，很久没说话。

"这上面写的不是公式。"她终于开口，"是一句问候。'如果你看到这里，说明你已经会用栈了。——伊塔尔'"
