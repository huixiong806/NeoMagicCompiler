## 2.5 换掉门轴上的两块配重

厅的后墙是一扇双开石门。门轴两侧各嵌着一块配重石，门上写着：

```
左右配重不得相同。若不满足，交换两块配重石的能量读数。
```

岩舟伸手摸了摸左边的石头，又摸了摸右边的：“这两块都是镶死在石头里的，搬不动。读数怎么换？”

星泠把手里的魔导核心递过去：“你不用搬石头。石头在记忆晶阵里有自己的地址——**地址就是门牌号**。你把两个门牌号告诉引擎，让引擎自己去那两个位置上把数调换。”

“……所以我不传数，我传门牌号？”

“对。这叫**指针**——一个专门用来存地址的量，写作 `int*`。”

屏幕上跳出新的目标：

```
本关目标：void solve(int* a, int* b)
  a、b 是两块配重石的地址
  把 *a 和 *b 上的数调换（原地交换，不需要返回值）
```

“`*` 有两种用法，别混了。”星泠在沙地上画了两下，“在**声明**里，`int* a` 表示‘a 是一个地址’；在**表达式**里，`*a` 表示‘地址 a 上现在装着什么数’。声明时是名词，用时是动词。”

岩舟盯着那个星号看了会儿：“……行，我记成‘星星开头的是门牌号，星星夹在中间的是门背后的东西’。”

“可以。”星泠难得没纠正他。

**注意**：这一关不需要 `return`，但你必须真的改动地址上的内容。测试会在运行结束后检查记忆晶阵里这两个位置的值，所以只交换自己函数里两个局部变量是不算的。

```riscv
{
  "level": "2-5",
  "language": "c"
}
---
// 2-5 指针：交换 *a 与 *b（写着同一地址时不要破坏它）
void solve(int* a, int* b) {
    int t = *a;
    *a = *b;
    *b = t;
}
```
