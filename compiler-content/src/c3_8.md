## 3.8 括号递归

轴对上齿的声音一响，门开了——但门后面不是路，是**又一道门**。

同样的方板，同样的方口，同样的"此处吞算式"。岩舟把手里的算式送进去：

```
(1+2)*3
```

门里顿了一下，吐出来 `7`。

"错得挺有道理。"星泠说，"它不管你写的括号，只管从前往后扫：1+2=3，吃到 `)` 不认识就丢掉，再 3*3……等一下，它算出 7，说明它连 `(` 都不认识。"

岩舟试着又送了一个 `2*3+4`，这次对了：`10`。再送 `(2+3)*4`，又错了。

"看出规律了吗？"星泠指着方板，"**括号一出现，我们上一关那两条管道就不够用了**。"

---

### 一层套一层

"上一关你画的是两节管道。现在想一想：括号里的东西，是什么？"

"……是一个算式？"

"对。`(1+2)*3` 里的 `(1+2)`，它自己就是一条完整的算式——**同样的结构，小一号**。"

她在方板上把图重画了一遍，把最后一节展开：

```
算式 := 项 (('+' | '-') 项)*
项   := 因子 (('*' | '/') 因子)*
因子 := 一串数字
      | '(' 算式 ')'        ← 因子也可以是「整个算式，装在括号里」
```

岩舟看了一会儿："因子那一层的定义里，又出现了'算式'——这不就是绕回去了吗？"

"绕回去，才是这一关全部的秘密。"星泠说，"**因子看到 `(` 的时候，去调一次算式自己**。里面的那趟走完，返回来一个数，那就是因子。"

### 引擎是怎么做到"又进一层"的

"别把它想玄了。"她在方板上画了一叠小方块，"引擎手里只有一样东西：`sp`。"

```
   sp ──▶ ┌──────────┐  ← 最外面那层算式（正在等它的第一个项）
          │  ra, a2   │
          ├──────────┤  ← 项层
          │  ra, a1   │
          ├──────────┤  ← 因子层（刚吃掉那个 '('）
          │  ra, a3   │  ← 它要调算式了：先把 ra 压进来
          ├──────────┤
          │  ra, a2   │  ← 里面那层算式，接着是它的项、它的因子……
          └──────────┘
```

"每进一层，`sp` 往下走一格，把 `ra` 和自己要用的累加器压进去；这一层返回来的时候，`sp` 回到原处，`ra` 也回来了。**上一层被压在下面，一寸都没被动过。**"

"所以 `((2+3)*(1+1))` 这种括号套括号，对你来说不需要任何新代码——同一段代码又往下走了两层而已。"

"括号不配对呢？"岩舟问。

"因子收右括号的时候，读到的如果不是 `)`，就把它放回去、装作没事。"星泠说，"本关的输入都是配好对的，但你的程序不该因为少一个括号就把引擎撞坏。"

```riscv
{
  "level": "3-8",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [5],
    "suggested": {
      "5": "jal ra, expression",
      "6": "jal ra, print_int"
    }
  }
}
---
# 目标：算式里现在会出现括号，如 (1+2)*3、((2+3)*(1+1))。算出值并输出。
#
# 在 3-7 的两层结构上加最后一层：
#   因子 := 一串数字 | '(' 算式 ')'
#   因子看到 '(' 时，直接 jal ra, expression —— 又进了一次最松的那一层。
#   写代码的时候记住：每一层进来先压 ra（和本层的累加器），返回前再取回去。
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000

main:
        li      a4, INPUT
        li      a5, DISPLAY
        nop                             # ← 从这里开始写你的三层求值器
        li      a0, 0
        li      a7, 0
        ecall
```

**这一关最值得盯住的一个数：`sp`。** 调试面板里它一开始是 `0xF000`；每进一层它就往下走 8；每返回一层就走回来。如果你看到它一路往下不回头，说明有哪一层忘记写返回了。

岩舟把 `(1+2)*3` 送进去。门里先是安静了一小会儿——比他预计的长，像是有谁在里面又开了一道门——然后吐出来 `9`。

"它进去了。"星泠说。
