## 1.7 只会直着走的引擎

石柱上那句话读起来简单，做起来卡住了。

岩舟绕着柱子走了半圈，把它从上到下摸了一遍，没找到可以拧的接口。"它说'若两数相同'。可这门比我老实——我做事会看情况，它不会。它只是一条一条往下刻，刻到哪条走哪条。"

"这句话就是它的短板，也是它的长板。"星泠站在柱子正面，"魔导引擎只会**直着走**。第一条刻痕、第二条、第三条……一条不落。它从来不问'这个数是不是 0'，因为问问题需要**选择**。"

"那门上写的话算什么？"

"算你要教它的事。"她取出刻笔，在柱子底部的凹槽上比了个位置，"星之语里有**分支**指令：它先比两个寄存器，比中了才跳到别的地方去，比不中就当它不存在、继续往下走。"

```text
beq x1, x2, 标签    # 如果 x1 == x2，跳到标签那一行
bne x1, x2, 标签    # 如果 x1 != x2，跳到标签那一行
```

"标签就是你自己起的路标，写的时候以冒号结尾，像 `same:` 这样。跳过去之后，引擎从标签那一行继续直着走。"

岩舟在柱子下面的灰上画了两条岔路，又用凿子尖划掉一条。"所以要先假装'它们是不同的'，跳到写 0 的地方；如果比出来其实一样，就跳到写 1 的地方。"

"顺序你定。"星泠把刻笔交给他，"x3 里最后放 `1` 还是 `0`，取决于闸给的两个数。这一关的测例会给你相等的、不相等的、和两个都是 0 的情况。**两个都是 0 也算相等**——这是最容易漏掉的一格。"

```riscv
{
  "level": "1-7",
  "language": "asm",
  "constraints": {
    "readonlySuffix": 1,
    "suggested": { "1": "bne x1, x2, not_same" }
  }
}
---
# x1、x2 里是闸给的两个数
# 任务：相等就把 1 放进 x3，不相等就把 0 放进 x3

# 标签写在这里，行尾要有冒号

ecall
```

分支指令后面跟的标签，可以写在它在代码里的任何位置——**往前跳、往后跳都可以**。跳出去的地方叫什么名字不重要，重要的是你跳之前想清楚"什么情况下该跳"。

柱子上的字在岩舟刻完第一条分支之后发生了变化。那行字的下面，慢慢浮出第二句：

**若甲小于乙，则取乙；否则取甲。**
