## 1.6 一排格子，三块牌子

石阶往下走了一段，墙面变得规整起来。

一排刻度整整齐齐地排开，从 `0x1000` 起，每隔四个字节一个凹坑，一共三个。每个凹坑上方都悬着一块小小的空牌子，只有第一个凹坑旁边有字：`1`。

"闸要三块牌子。"星泠把方板贴在那面墙上，"`0x1000` 挂 `1`，`0x1004` 挂 `2`，`0x1008` 挂 `3`。"

岩舟把刻笔往第一个凹坑里按了按，那坑轻轻吸住了笔尖。"三个地址，写三遍？"

"写三遍，但地址可以只算一次。"星泠用手指从第一个凹坑滑到第三个，"`0x1004` 是 `0x1000` 往后**四个字节**，也就是后**一个字**。所以只要 x1 里装着 `0x1000`，你可以用同一个 x1 配不同的偏移量："

```text
sw x2, 0(x1)    # 写进 0x1000 + 0
sw x3, 4(x1)    # 写进 0x1000 + 4，也就是 0x1004
sw x4, 8(x1)    # 写进 0x1000 + 8，也就是 0x1008
```

"一个地址寄存器，配三个偏移。"她说，"还有一个问题：1、2、3 得先住进寄存器，`sw` 只会把**寄存器里的数**搬出去，它不认直接写进去的常数。"

"那就先刻三行把他们送进去。"岩舟已经动手了，"`li` 就是把常数塞进寄存器的写法，对吧？"

"对。`li x2, 1` 之后，x2 里就是 1。要注意寄存器不能重复占——三个数同时要活着，就得占三个格子。"

```riscv
{
  "level": "1-6",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "suggested": { "2": "li x2, 1", "3": "li x3, 2", "4": "li x4, 3" }
  }
}
---
li x1, 0x1000
# 把 1、2、3 分别写进 0x1000、0x1004、0x1008




ecall
```

`li` 是伪指令：星之语其实没有一条叫 `li` 的指令，它会被拆成两条真正的指令刻进方板。你写起来是一行，引擎看到的是一对——这件事以后学到函数的时候会很关键。

三块牌子升起来的时候，墙整面都在震。岩舟下意识往后退了半步，脚后跟在石阶上磕了一下。

"别慌。"星泠把手按在墙上，等震动静下来，"门开了。"

门后不是通路。是一个正方形的房间，房间中央立着一根石柱，石柱上刻着一句话，字迹很深，像是被人反复描过：

**若两数相同，则放 1；否则放 0。**
