## 2.13 藏书厅里的那个编号

藏书厅比前面所有厅加起来都大。几百卷卷轴安安稳稳躺在架子上，每一卷侧面都刻着一个编号，从左到右**由小到大**。

岩舟从最左边开始一卷一卷看。

“停。”星泠说，“你在干什么？”

“找 77 号啊。”

“这里有几百卷。你打算一卷一卷摸过去？”

岩舟回头看了看这条望不到头的架子：“……不然呢？”

星泠把卷轴摊在最近的桌上：“排好序的东西，你不该一个个找。你该**每次砍掉一半**。”

她在沙地上画了一条线，然后在正中间点了一下：“看中间那一卷。如果它的编号比 77 大，那 77 一定在**左边那一半**里——因为右边全都比中间更大。右边这一半，连同中间那卷，全部扔掉。反过来也一样。一次砍一半，几百卷只要看几次。”

岩舟盯着那条线看了半天：“……我刚才是不是白摸了二十卷。”

“十九卷。”星泠说，“你从 1 号摸到 19 号。”

屏幕上跳出新的目标：

```
本关目标：int solve(int* a, int n, int target)
  在升序数组 a（n 个元素）里找 target 的下标
  找到就返回下标，找不到返回 -1
参数 a 是数组起始地址，n 是元素个数，target 是要找的编号
```

“那什么时候停？”

“两个可能。”星泠说，“要么你正好撞上 `target`——返回当前下标；要么左右边界交错，说明这一半已经空了——那就是**没有这卷卷轴**，返回 -1。别担心找不到，测试里专门有找不到的情况，还有正好在**头一卷**和**最后一卷**的情况。”

---

**你要写的东西**

```c
int solve(int* a, int n, int target) { ... }
```

在**升序**数组 `a[0..n-1]` 中查找 `target`，返回下标；不存在返回 `-1`。`n` 可能是 0。

经典写法：

```c
int lo = 0;
int hi = n - 1;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == target) {
        return mid;
    } else if (a[mid] < target) {
        lo = mid + 1;
    } else {
        hi = mid - 1;
    }
}
return -1;
```

`(lo + hi) / 2` 在这里用整数除法就行——它会自动向下取整，正是我们要的"中间那卷"。

```riscv
// 2-13 二分查找：升序数组里找 target 的下标，找不到返回 -1
int solve(int* a, int n, int target) {
    int lo = 0;
    int hi = n - 1;
    while (lo <= hi) {
        int mid = (lo + hi) / 2;
        if (a[mid] == target) {
            return mid;
        } else if (a[mid] < target) {
            lo = mid + 1;
        } else {
            hi = mid - 1;
        }
    }
    return -1;
}
```
