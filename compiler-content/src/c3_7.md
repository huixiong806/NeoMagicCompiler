## 3.7 乘除优先级

方板暗下去之后，岩舟正想收起来，那行小字又浮出一行。

**此门吞算式。**

"不只是数。"星泠凑近看，"它要的是一整条算式——`2+3*4` 这样的。"

岩舟在方板上划拉了两下，把 `2+3*4` 送进去。门里传回来一个数：`20`。

"……二十？"

"它现在是**从左往右**硬算的。"星泠说，"先 2+3=5，再 5*4=20。可我们认的算法不是这样——**先乘除，后加减**：先 3*4=12，再 2+12=14。"

"那谁说了算？"

"算的人说了算。"她把刻笔递给岩舟，"这是遗迹里第一台真正要'读懂一句话'的机关。你写的程序怎么切它，它就是什么。切错了，答案就是 20。"

---

### 两条流水线，不是一条

她先在方板上画了两节管道。

```
2 + 3 * 4 + 5
└──┬──────┘ └┬┘
   │         └── 这一节的名字叫「项」：它只管乘除
   └──────────── 这一节的名字叫「算式」：它只管加减
```

"一个算式，其实是**一串项**用加减号连起来的：`2 + 3*4 + 5` 就是三个项。而一个项，是**一串因子**用乘除号连起来的：`3*4` 就是两个因子。"

```
算式 := 项 (('+' | '-') 项)*
项   := 因子 (('*' | '/') 因子)*
因子 := 一串数字
```

"照这个规矩走一遍 `2+3*4+5`：算式层先取第一个项，得到 `2`；看到 `+`，就再取一个项——而项层会把 `3*4` 一次性吃完，交回 `12`；算式层得到 `14`；看到 `+`，再取一个项 `5`，得到 `19`。"

"注意这里有个**很妙的地方**："她在 `+` 上画了个圈，"算式层看到 `+` 的时候，它**不知道**后面跟着的是 `3` 还是 `3*4`。它也不想知道——它只是喊一声'给我一个项'，项层自己会一路吃到乘除号结束。层级一分，优先级就自然出来了，一行 `if` 都不用写。"

### 偷看一个字符

"实现上只有一个新麻烦：**你得先看见下一个字符，才知道要不要继续**。"

"读到 `3` 之后，你接着读到的是 `*` 还是 `+`？"星泠说，"读到 `+` 就该换层了，可 `+` 被你看掉了——不给它留个位置，上一层就再也看不到它。所以每个循环都这么写：

1. 从输入里读一个字符（这一步叫**偷看**，lookahead）；
2. 是我这一层的运算符？吃掉它，继续算；
3. 不是？**原样放回去**，然后返回。

程序用一个很土但很好用的办法实现'放回去'：`a6` 指向一个 16 字节的小缓冲区，放回去就是往回退一格。`get_char` 先看缓冲区里有没有剩货，没有才真的去读输入端口。"

### 寄存器怎么分

"两层各用各的累加器，就不会打架："

| 层 | 累加器 | 说明 |
|----|--------|------|
| 算式层（加减） | `a2` | 存"算到这里为止的和" |
| 项层（乘除） | `a1` | 存"这个项乘到这里为止的积" |
| 因子层 | `a3` | 只负责把一串数字拼成一个数 |

"每一层开头把 `ra` 和它要用的那个累加器压栈（`sp` 往下走），返回前再取回来——这样一层套一层也不会互相盖掉。返回值统一放在 `a0`。"

```riscv
{
  "level": "3-7",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [5],
    "suggested": {
      "5": "jal ra, expression",
      "6": "jal ra, print_int"
    }
  }
}
---
# 目标：读一条只有数字和 + - * / 的算式（行尾是换行），算出它的值并输出。
#
# 骨架现在只做了「把输入读完」这件事。你要把它变成一台会算的机器：
#   1. 用 a6 管一个"放回缓冲区"（.data 里的 pend_buf），实现 get_char / unget_char
#   2. 写两层：expression（加减）→ term（乘除）→ factor（一串数字）
#   3. 每层循环都先偷看一个字符：是自己这层的运算符就吃掉继续，否则放回去再返回
#   4. 输出用 print_int（可以递归：先打高位、再打低位）
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000

main:
        li      a4, INPUT               # a4 = 输入端口：读一个字符就少一个，读到 0 = 结束
        li      a5, DISPLAY             # a5 = 显示端口：往这里写一个字符就是输出一个字符
        nop                             # ← 从这里开始写你的两级求值器
        li      a0, 0
        li      a7, 0
        ecall
```

`li a0, 0` 那两行是收尾（关掉程序），别删。中间那一段空着的地方，就是整台机关。

两个提醒：

- **别把 `+` 看漏了**。算式层读到 `+` 之后必须先把它吃掉，再去要下一个项；忘了吃，就会在原地打转（指令数超限会直接判失败）。
- **数字可能是多位的**。`34` 要拼成 34：每读一位就 `值 = 值 * 10 + 这一位`；读到第一个不是数字的字符，把它放回去，作为一个数结束的信号。

方板上的 `20` 还在闪。岩舟把刻笔按下去的时候，门里先响了一声很轻的、像是**某根轴终于对上齿**的声音。
