## 1.4 把一个数拆开

那道斜杠后面写着两个数。

星泠把方板翻过来，让岩舟看背面新浮出来的一层纹路——一层叠一层的同心圆，圆心有一小段被磨得发白的刻痕，像是被反复刻过又被反复擦掉。

"这是采掘台的记数器。"她说，"它把这次的矿石量记成一个数，但闸不接受整块。闸要两样：这块矿能装几个整箱——**商**；装完之后剩多少散料——**余数**。"

岩舟把腰上的箱子提了提。箱子只有一层，装不下什么。

"箱子和散料。"他重复了一遍，"听着像我往背包里塞东西。"

"数学上说，就是这样。"星泠在方板的三个凹槽上分别点了一下，"x1 里是被拆的数，x2 里是每一箱的容量。要拆出商和余数，星之语有三条指令："

```text
div x3, x1, x2   # 商：x1 ÷ x2 的整数部分
rem x4, x1, x2   # 余数：除完之后剩下的那点
mul x5, x3, x2   # 乘法：把商乘回容量，可以验算
```

"这一关闸只要商和余数：x1 是 17，x2 是 5，商放进 x3，余数放进 x4。"

岩舟拿刻笔在方板边缘试着写了一个 `div`，那道光跟着他的笔尖走，像是被牵着。"17 除以 5，箱子里塞得下 3 组，剩 2 组没人要。"他抬头，"所以 3 和 2。"

"对。`rem` 出来的余数永远比分箱的容量小——这是闸后面要用的性质，先记住。"

```riscv
# x1 = 17，x2 = 5
# 任务：商放进 x3，余数放进 x4

ecall
```

余数与负数会在测例里出现：`rem` 的余数跟着被除数的符号走，被除数是负的，余数也是负的。你可以拿 `mul` 反乘一遍验算：`x3 * x2 + x4` 应该正好回到 `x1`。

闸门第二次转开的时候，岩舟先把手伸了进去——里面不是通路，是一段石阶，往下走三步，就撞上一块平整的墙面。墙上钉着一排小小的徽记，每一个下面都压着一个数字。

星泠伸手按在墙面中央："这些数字不在寄存器里。它们住在**记忆晶阵**里。"
