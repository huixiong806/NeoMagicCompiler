## 4.7 代码生成：表达式

翻译机被星泠接到方板上以后，第一次吐出的是**词**，第二次吐出的是**树**，第三次吐出的是**一张纸**——纸上写着"这句话的意思"。

岩舟盯着那张纸看了半天。"我还是不能拿它去点灯。"

"当然不能。"星泠把手按在方板背面，"这三步走的都是**看**的活。伊塔尔留的最后一层不是看，是**写**。"

她翻过方板，背面是一块空白的篆刻面，摸上去有极细的凹槽，像一张等着被刻的纸。

"从这一关起，你写的不是翻译机了。"她说，"你要写的是一台**篆刻机**。它读进去星咒，吐出来的必须是**星之语本身**——一行一行，刻好了，能直接装进魔导引擎里跑。"

岩舟明白了为什么上一关的判定那么松。"所以从这儿开始，输出的**样子**要一模一样？"

"对。因为你吐出来的东西是要被**别的**汇编器读的，不是给人夸的。"

---

**这一关的输入**（只有常量、`+ - * /` 和括号）：

```
1+2*3
```

**这一关要求的输出**：一段完整、能被汇编器接受的星之语程序，它必须

- 定义一个叫 `main` 的符号；
- 执行到末尾时，把表达式的值放进 `a0`；
- 用 `ret` 返回（**不要**在自己生成的程序里 `ecall` 退出——外面的人会 `jalr` 进你的 `main`，然后读 `a0`）。

`1+2*3` 应该被编成（这段是参考解**逐字节**吐出来的，判定拿它按行比）：

```
.text
main:
li a0, 1
addi sp, sp, -4
sw a0, 0(sp)
li a0, 2
addi sp, sp, -4
sw a0, 0(sp)
li a0, 3
lw a1, 0(sp)
addi sp, sp, 4
mul a0, a1, a0
lw a1, 0(sp)
addi sp, sp, 4
add a0, a1, a0
ret
```

一行都不能多、不能少；指令不缩进、不带注释。

### 这套"左值压栈"是怎么想出来的

先看一条最朴素的规矩：**每个子表达式编完以后，它的值都在 `a0` 里**。

那么 `1+2` 该编成什么？左边 `1` 进 `a0`；接着要编右边 `2`——可右边一开始编，`a0` 就被写掉了。所以先把左值**存起来**：

```
li a0, 1          # 左边的值
addi sp, sp, -4   # 把它存进记忆晶阵（栈）
sw a0, 0(sp)
li a0, 2          # 右边算进 a0
lw a1, 0(sp)      # 取回左边
addi sp, sp, 4
add a0, a1, a0    # 结果回 a0：a1 是左、a0 是右
```

**为什么存栈、不存另一个寄存器？** 现在右边只是个常量，放 `a1` 也行；可到 4-10，右边可能是一次**函数调用**，调用回来会把 `a0`、`a1` 一起冲掉。放在栈（记忆晶阵）上谁也碰不到——这就是后面每一关都在用的那两行。

整棵表达式树**后序**走一遍：每个二元结点吐"压栈 / 算右 / 弹回 / 运算"这几行，叶子只吐一条 `li a0, N`。
注意 `2*3` 先算，是因为 `mul` 那一行在 `add` 那一行**上面**——**后序**就是"先算孩子，再算父亲"。
还有一条死规矩：弹回来以后 **`a1` 里是左边、`a0` 里是右边**，所以减法写 `sub a0, a1, a0`（左减右）、除法写 `div a0, a1, a0`——写反了值就错了。

### 生成器长什么样

你手上已经有了：

- `src`：源码字符数组，读输入时写进去，末尾补一个 `0`；
- `out`：输出缓冲，你往这里"拼接"要吐出去的文本，最后整块送到显示端口；
- `cur`：源码游标；`wc`：已经读出来、还没处理的字符；
- `emit_str`：把 a0 指向的字符串接到 `out` 末尾；`emit_num`：把 a0 里的十进制数字接上去。

剩下的就是把上一关那套"看"的代码，改成一边看、一边吐：

| 函数 | 看什么 | 吐什么 |
|------|--------|--------|
| `gen_expr` | `term (('+' \| '-') term)*` | 左孩子编完 → 压栈两行 → 右孩子 → 弹回两行 → 一行 `add` / `sub` |
| `gen_term` | `unary (('*' \| '/') unary)*` | 同上，最后吐 `mul` / `div` |
| `gen_unary` | `'-' unary` / `'(' expr ')'` / 数字 | 数字吐 `li a0, N`；括号只是"让里面的先算"，不吐指令 |

三个函数都要遵守同一条约定：**返回时当前结果留在 `a0`**。

`gen_expr` 里最容易绕晕的一点是：**"压栈"这句话是吐给未来那段程序看的，不是给你的编译器执行的**。
你的编译器只做一件事——把该吐的文本按顺序接进 `out`：

```
addi sp, sp, -4
sw   ra, 0(sp)          # 递归要保住自己的返回地址
jal  ra, gen_term       # 先编左边（它吐完，生成的代码里左值就在 a0 里）
gen_expr_loop:
jal  ra, skip_ws        # 跳过空白
jal  ra, peek           # 看下一个字符是不是 '+' / '-'
...
la   a0, str_push       # 吐两行："addi sp, sp, -4" 和 "sw a0, 0(sp)"
jal  ra, emit_str
jal  ra, getc           # 吃掉运算符
jal  ra, gen_term       # 再编右边
la   a0, str_pop        # 吐两行："lw a1, 0(sp)" 和 "addi sp, sp, 4"
jal  ra, emit_str
la   a0, str_add        # 吐一行："add a0, a1, a0"
jal  ra, emit_str
j    gen_expr_loop
lw   ra, 0(sp)
addi sp, sp, 4
ret
```

（你的编译器**不需要**知道表达式的值是多少：它只按规矩吐文本；生成出来的程序自己会在运行时把值算进 `a0`。
所以 `str_push` / `str_pop` 这两个字符串要在 `.data` 里先定义好，模板就是一整段多行文本。）

### 一个容易踩的坑

`li` 要你自己吐出来：数字子表达式吐的是**两行**——一行 `li a0, ` 加数字，再加换行。`emit_num` 只负责数字部分，`"li a0, "` 和 `"\n"` 这两截要你自己拼（在 `.data` 里定义好 `.asciz "li a0, "` 之类的字符串最省事）。

数字最多几位就写多少位，**不要去猜**：`emit_num` 已经会算十进制了。

```riscv
{
  "level": "4-7",
  "language": "asm",
  "constraints": {
    "suggested": {
      "37": "把这条 jal 的目标换成你自己写的 gen_expr（它必须把结果留在 a0）",
      "64": "要吐出去的那几行文本（压栈、弹栈、li a0, ）都当成 .asciz 放进 .data，再用 la 取地址"
    }
  }
}
---
# ── 4-7 篆刻机：常量表达式 → 星之语 ─────────────────────────────
# 输入：星咒源码，从 0xF0000004 逐字符读，读到 0 表示结束
# 输出：星之语文本，逐字符写到 0xF0000000
# 生成的程序必须定义 main、把结果放在 a0、用 ret 返回
#
# 约定：a0 = 当前结果，a1 = 右操作数暂存（生成出来的代码里也这么用）
.data
src:      .space 1024
out:      .space 8192
tinstr:   .space 16                   # emit_num 用的小缓冲
cur:      .word 0
wc:       .word 0
str_head: .asciz ".text\nmain:\n"     # 生成程序的开头
str_li:   .asciz "li "
str_a0nl: .asciz "a0\n"
str_ret:  .asciz "ret\n"

.text
compile_entry:
    # 1) 把输入字符流读进 src（读到 0 结束）
    la   a1, src
    li   a2, 0xF0000004
read_loop:
    lw   a0, 0(a2)
    beqz a0, read_done
    sb   a0, 0(a1)
    addi a1, a1, 1
    j    read_loop
read_done:
    sb   x0, 0(a1)

    # 2) 吐出固定开头
    la   a0, str_head
    jal  ra, emit_str

    # 3) 【你要写的】编译表达式：__gen_expr 要把结果留在 a0
    jal  ra, gen_stub

    # 4) 吐出收尾
    la   a0, str_ret
    jal  ra, emit_str

    # 5) 把 out 整块送到显示端口
    la   s0, out
    li   s1, 0xF0000000
emit_out_loop:
    lbu  a0, 0(s0)
    beqz a0, emit_out_done
    sw   a0, 0(s1)
    addi s0, s0, 1
    j    emit_out_loop
emit_out_done:
    li   a0, 0
    li   a7, 0
    ecall

# ── gen_stub：只认"一个数字"的占位实现，把它换成真正的 gen_expr ──
gen_stub:
    addi sp, sp, -8
    sw   ra, 0(sp)
    jal  ra, getc            # a0 = 第一个有效字符
    addi a0, a0, -48         # 字符 '3' → 3（只处理一位数字）
    sw   a0, 4(sp)           # 借本函数的栈格子把值存一下
    la   a0, str_li
    jal  ra, emit_str
    lw   a0, 4(sp)           # 取回数字
    jal  ra, emit_num        # 只拼数字本体
    la   a0, str_a0nl        # 再拼 "a0\n"
    jal  ra, emit_str
    addi a0, x0, 0
    lw   ra, 0(sp)
    addi sp, sp, 8
    ret

# ── emit_str：把 a0 指向的字符串接到 out 末尾 ────────────────────
emit_str:
    la   t0, out
emit_str_skip:
    lbu  t1, 0(t0)
    beqz t1, emit_str_copy
    addi t0, t0, 1
    j    emit_str_skip
emit_str_copy:
    lbu  t1, 0(a0)
    beqz t1, emit_str_done
    sb   t1, 0(t0)
    addi a0, a0, 1
    addi t0, t0, 1
    j    emit_str_copy
emit_str_done:
    sb   x0, 0(t0)
    ret

# ── emit_num：把 a0 里的非负整数按十进制接到 out 末尾 ─────────────
emit_num:
    la   t0, out
emit_num_skip:
    lbu  t1, 0(t0)
    beqz t1, emit_num_ready
    addi t0, t0, 1
    j    emit_num_skip
emit_num_ready:
    la   t1, tinstr
    addi t2, t1, 16          # 小缓冲末尾，从后往前填
    sb   x0, 0(t2)
    addi t2, t2, -1
    li   t3, 10
    bnez a0, emit_num_digit
    li   t4, 48              # 值是 0 也要写一个 '0'
    sb   t4, 0(t2)
    addi t2, t2, -1
    j    emit_num_copy
emit_num_digit:
    remu t4, a0, t3
    addi t4, t4, 48
    sb   t4, 0(t2)
    addi t2, t2, -1
    divu a0, a0, t3
    bnez a0, emit_num_digit
emit_num_copy:
    addi t2, t2, 1
emit_num_copy_loop:
    lbu  t4, 0(t2)
    beqz t4, emit_num_end
    sb   t4, 0(t0)
    addi t0, t0, 1
    addi t2, t2, 1
    j    emit_num_copy_loop
emit_num_end:
    sb   x0, 0(t0)
    ret

# ── getc：返回下一个有效字符到 a0，并把它**吃掉**（跳过空格/换行）──
#   源码到头时返回 0（不再前进）。
getc:
    lw   a0, wc
getc_check:
    li   t0, 32
    beq  a0, t0, getc_skip
    li   t0, 10
    beq  a0, t0, getc_skip
    li   t0, 13
    beq  a0, t0, getc_skip
    beqz a0, getc_done
    # 吃掉当前字符：游标 +1，wc 更新成下一个字符；a0 里留着返回值
    la   t1, cur
    lw   t2, 0(t1)
    addi t2, t2, 1
    sw   t2, 0(t1)
    la   t1, src
    add  t1, t1, t2
    lbu  t3, 0(t1)
    la   t4, wc
    sw   t3, 0(t4)
getc_done:
    ret
getc_skip:
    la   t1, cur
    lw   t2, 0(t1)
    addi t2, t2, 1
    sw   t2, 0(t1)
    la   t1, src
    add  t1, t1, t2
    lbu  t3, 0(t1)
    la   t4, wc
    sw   t3, 0(t4)
    addi a0, t3, 0
    j    getc_check
```

骨架里的 `gen_stub` **只能编一个数字**，而且把数字拼在 `a0` 后面拼错了位置——跑一遍 `1+2*3` 就能看到它吐出来的东西有多不对。把 `gen_stub` 换成 `gen_expr` / `gen_term` / `gen_unary` 三个函数，就对了。

程序里的收尾和 `emit_*` 是脚手架，随你怎么改；判定只看**显示端口吐出来的文本**（按行比对：去掉每行首尾空白、丢掉空行，逐行完全一致）。

方板背面第一行被刻出来的时候，岩舟凑过去看：`li a0, 1`。

"这就是星之语。"

"这就是星之语。"星泠说，"你刚才是**写**出来的，不是背出来的。"
