## 3.11 简单脚本

方板上的字是刻进去的，一笔一笔，很深：

```
let x = 3; print x+1;
```

岩舟念了一遍："让 x 变成 3；打印 x 加 1。"

方板没有反应。他把 `3+1` 送进旁边的方口，读数屏上跳出 `4`。

"机器会算。"星泠说，"但它**读不懂这句话**。你刚才做的是把句子翻译成算式，再喂给它——可方板上写的是句子，不是算式。"

她把手指按在那行刻字上："`let`、`print`、分号——这是**咒文**。遗迹里的人用这种写法留下一小段一小段的'做法'。这一关，你要写的不是求值器，是**读咒文的机器**。"

---

### 从"一个算式"到"一串语句"

"前几关你的程序只做一件事：把整个输入当成一条算式，算完就打。现在输入变成了一串**语句**，每一条都要单独处理："

```
程序    := 语句*
语句    := 'let' 名字 '=' 算式     ← 把值存进变量
         | 'print' 算式             ← 把值打出来
         | 算式                     ← 光算不打印（第四章里会是别的语句）
```

"读法是：反复地问'下一条语句是什么'。看到 `l` 开头，就是 `let`；看到 `p` 开头，就是 `print`；都不是，那就是一条光秃秃的算式。"

"`l` 开头怎么区分 `let` 和别的？"

"咒文里只有 `let` 和 `print` 这两个词开头用 `l`、`p`。"星泠说，"所以实际做法很直接：读到 `l`，就把后面两个字符 `e`、`t` 吃掉，然后读名字；读到 `p`，确认后三个字符是 `r`、`i`、`n`、`t`。"

岩舟皱眉："那要是有人写了个叫 `print` 的变量呢？"

"这一关不会。"星泠说，"真想做得更稳，就得先切出完整的词（第四章的**词法分析**专门干这个）。现在用'看开头几个字符'就够——但你要记住：这是偷懒，词汇边界真撞上时它会给你难堪。"

### 变量住哪儿

"你说过整块魔法阵里没有'变量'。"

"没有。有的是**格子**。"星泠在方板上画了一条线：

```
0x2000  ┌────┬────┬────┬────┬─────┬────┐
        │ a  │ b  │ c  │ d  │ ... │ z  │    ← 每个格子 4 字节
        └────┴────┴────┴────┴─────┴────┘
```

"我们约定：变量 `a` 住在 `0x2000 + 0*4`，`b` 住在 `0x2000 + 1*4`……`x` 住在 `0x2000 + 23*4`。名字换算成地址只要三步：**

```
地址 = 0x2000 + (字母 - 'a') * 4
```

"这样求值层就完全不用知道'变量'是什么——它只需要一个地址，`lw` 一下就有值。`let` 做的事就是：算出右值，往这个地址 `sw` 进去。"

"一个字母够吗？"

"够。"星泠说，"记住这是**刻意选的最小可行方案**：真做编译器时你会需要一张能装任意名字的表，那个东西在第四章。"

### 这关真正新的一层

"把三层求值器原样保留，只在它外面包一层语句循环。"

```
        ┌─ 语句层：读 let / print / 光算式，一直读到输入结束
        │
        └─▶ 算式层 → 项层 → 因子层      （3-9 那台机器，一行都不用改）
              因子层多认一种：小写字母 → 变量
```

"唯一要小心的是**分隔符**。"星泠说，"语句之间是分号，行尾是换行。你的求值器只认数字、括号和运算符，所以它读到 `;` 或者换行时会把它**放回缓冲区**、然后返回——正好回到语句层手上。"

"那空的分号、空的行呢？"

"语句层开头先做一个'跳过空白'的小动作：把空格、制表符、换行、分号统统跳掉，一直跳到有意义的第一个字符。跳完如果看到 `0`，说明输入真的结束了。"

```riscv
{
  "level": "3-11",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 1,
    "highlight": [6],
    "suggested": {
      "6": "jal ra, skip_filler",
      "7": "beqz a0, prog_end",
      "8": "li t0, 'l'",
      "9": "beq a0, t0, try_let"
    }
  }
}
---
# 目标：读一段小脚本并执行它。语句有：
#   let x = 算式       把结果存进变量 x（变量 a..z，存在 0x2000 起，一个字母 4 字节）
#   print 算式         把结果打出来，后面跟一个换行
# 语句之间可以用分号分隔，也可以直接用换行。
#
# 结构：最外面一层是"语句循环"，里面调用 3-9 那套三层求值器（原样保留即可）。
#   语句层开头先跳过空格/换行/分号（写成一个 skip_filler），读到 0 就结束程序。
#   看到 'l' 就当 let、'p' 就当 print，都不是就把字符放回去当算式处理。
        .text
        .equ INPUT, 0xF0000004
        .equ DISPLAY, 0xF0000000
        .equ VARS, 0x2000

main:
        li      a4, INPUT
        li      a5, DISPLAY
        nop                             # ← 从这里开始写语句层 + 复用三层求值器
        li      a0, 0
        li      a7, 0
        ecall
```

岩舟把方板上那行刻字一字不差地送进去——`let x = 3; print x+1;`——读数屏跳出 `4`。

他试着多写了一句：`print x*10;`。屏上跟着跳出 `30`。

"它记住了。"他说。

"它记住的是 `x` 那个格子里的 30 吗？"

"……不。"岩舟反应过来，"是 `0x2000 + 23*4` 那个格子里的 3。"

星泠点头："**变量就是地址**。你今天第一次不用'人话'来解释变量了。"

她把方板翻了个面。背面还有字，不止一行。
