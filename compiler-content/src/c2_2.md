## 2.2 让核心自己做选择

第二块石台藏在一道被熔岩封过的门口。岩舟用火属性魔法把封口的岩皮烧开一条缝，两人挤了进去。

台上同样立着两枚感应石，但这一回，只有一枚的读数会被写进输出晶石——**哪一枚读数更大，就送哪一枚**。

“这个我知道，”岩舟伸手去量石头上的读数，“我看一眼，大的那块搬过去。”

“你能看一眼，是因为你看得懂数字。”星泠把卷轴按在台上，“魔导引擎看不懂。它只会照着星之印一条一条执行，所以你必须把‘比较’和‘挑一个’这两件事，也写成它认得的句子。”

卷轴上第二句刻痕亮起来。星泠念出声：

```
若 甲 大于 乙，则 取 甲
否则 取 乙
```

岩舟挑了挑眉：“这不就是白话吗。”

“对。但魔导引擎会把它翻译成一组分支指令——比较、条件跳转、两个不同的去处。你在第一章亲手摆过那组星之印，现在只要说一句人话。”

屏幕亮起新的目标：

```
本关目标：int solve(int a, int b) 返回两者中较大的那个
若两者相等，返回其中任意一个都可以
```

岩舟忽然想到什么，回头看了一眼身后的走廊：“……要是两个读数一样大呢？”

“那两枚石头本来就是一回事。”星泠说，“返回哪个都对。测例里也这么写。”

---

**你要写的东西**

```c
int solve(int a, int b) { ... }
```

返回 `a` 与 `b` 中较大的那个（相等时返回哪个都算对）。

星咒里的分支写法：

- `if (条件) { ... } else { ... }`
- 比较运算符：`>` `<` `>=` `<=` `==` `!=`
- 也可以写成一行表达式：`return a > b ? a : b;`（三目运算符，效果一样）

**注意**：比较大小时别忘了负数。`-8` 比 `-3` 小，机器和你的直觉在这件事上是一致的。

```riscv
{
  "level": "2-2",
  "language": "c"
}
---
// 2-2 分支：返回 a、b 中较大的那个
int solve(int a, int b) {
    if (a > b) {
        return a;
    } else {
        return b;
    }
}
```
