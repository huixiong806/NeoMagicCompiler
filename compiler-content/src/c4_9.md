## 4.9 代码生成：分支与循环

方板上的篆刻面第一次吐出"往回跳"的字样时，岩舟下意识往后躲了一下。

"它自己回去重刻了。"

"这就是程序比公式强的地方。"星泠把手指按在那段回溯的刻痕上，"一句 `x = x + 4;` 只是**一次**动作；`while (x < 3) { … }` 是**一整套**动作的重复——它不是靠魔法重复的，是靠一条 `j` 跳回去，外加一条"什么时候别再跳了"的出口。"

"所以我们需要**名字**。"

"对。要往回跳，就得给某个位置起个名字，跳转指令才有地方可指。"她写下两个字，"**标签**。"

---

**这一关的语法**（在上一关的基础上加两条语句）：

```
程序 := 语句*
语句 := int 名字 = 表达式 ;
      | 名字 = 表达式 ;
      | if (条件) { 语句* }
      | if (条件) { 语句* } else { 语句* }
      | while (条件) { 语句* }
      | { 语句* }
      | 表达式 ;
条件 := (名字 | 常量)  < | <= | > | >= | == | !=  (名字 | 常量)
```

**这一关要求的输出**：还是 `.data` + `.text` + `main:` + `ret` 那套，只是中间多了标签。判定用的标签名统一定为 **`L` + 编号**（`L1`、`L2`、`L3`…），按**你需要的顺序**发号，从 1 开始。

`int x = 0; while (x < 3) { x = x + 1; }` 应该被编成：

```
.data
x: .word 0
.text
main:
li a0, 0
la a1, x
sw a0, 0(a1)
L1:
la a1, x
lw a0, 0(a1)
addi sp, sp, -4
sw a0, 0(sp)
li a0, 3
lw a1, 0(sp)
addi sp, sp, 4
slt a0, a1, a0
beqz a0, L2
la a1, x
lw a0, 0(a1)
addi sp, sp, -4
sw a0, 0(sp)
li a0, 1
lw a1, 0(sp)
addi sp, sp, 4
add a0, a1, a0
la a1, x
sw a0, 0(a1)
j L1
L2:
ret
```

（这不是"形状示意"，是参考解**逐字节**吐出来的文本 —— 判定拿它按行比。你照着吐，一行都不能多、不能少。）

### 三种形状，照抄就行

**`if`（没有 `else`）**——"条件假就跳过这一段"：

```
<条件>                 ← 结束时 a0 = 1（真）或 0（假）
beqz a0, L假
<then 里的语句>
L假:
```

（没有 `else` 时就**不要**多吐 `j L结束` 和第二个标签：判定按行比，多一行就是错。）

**有 `else` 的 `if`**：

```
<条件>
beqz a0, L假
<then 里的语句>
j L结束
L假:
<else 里的语句>
L结束:
```

**`while`**——"条件假就出去，否则干完活再跳回来"：

```
L条件:
<条件>
beqz a0, L出
<body 里的语句>
j L条件
L出:
```

**条件**——用和 4-7 的二元运算**同一条**规矩：左边算进 a0、压栈；右边算进 a0；弹回 a1。
弹完以后 **a1 里是左、a0 里是右**，所以：

| 条件 | 弹完之后吐的比较指令 |
|------|----------------------|
| `a < b` | **`slt a0, a1, a0`**（左 < 右） |
| `a > b` | **`slt a0, a0, a1`**（右 < 左，也就是 左 > 右） |
| `a <= b` | `slt a0, a0, a1` 再 **`seqz a0, a0`**（把"右 < 左"取反） |
| `a >= b` | `slt a0, a1, a0` 再 **`seqz a0, a0`**（把"左 < 右"取反） |
| `a == b` | `sub a0, a1, a0` 再 **`seqz a0, a0`** |
| `a != b` | `sub a0, a1, a0` 再 **`snez a0, a0`** |

`slt` 只会算"小于"，所以 `>` / `>=` 要把两个操作数的位置**换过来**——这是本关最容易写反的一行。
压栈/弹栈那两行和 4-7、4-8 一字不差；**不要**另发明"左值常驻 a0、右值常驻 a1"的第二套写法：
4-10 起右边可能是一次函数调用，会把 a0 冲掉（那正是 4-10 要讲的麻烦）。

源码里没写比较符时（`while (x)` 这种），表达式自己的值就是条件：非 0 即真，不用再吐额外指令。

### 新工具：标签发号器

上一关的骨架里已经有 `decls`（变量登记）和 `emit_*`（拼字符串）。这一关再加一个**发号器**：

```
labelno:   .word 0      # 已经发出去几个编号
new_label: labelno 加 1，返回新编号（第一次发出来的是 1）
emit_label: 把编号吐成 `L<编号>:`
```

`L假`、`L出`、`L条件` 就靠它——**先发号，再按需要吐标签**，编号自然就是 `L1`、`L2`…

岩舟把最后一段接上，按下运行。方板上吐出来的不再是直线，而是一段**会拐弯**的刻痕：跳到 `L1`，比一下，再回来。

"它在自己数。"他说。

"它在按你写的规则数。"星泠纠正他，"你只写了两次：一次是'加一'，一次是'还没到三就回去'。剩下的次数是它自己走出来的。"
