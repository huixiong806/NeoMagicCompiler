## 2.3 一句刻痕，一百次相加

凹室深处有一口深井，井壁上挂着成串的能量刻点，从 1 一直排到井底。旁边一块牌子上写着：

```
把井壁上全部的刻点加起来，总数就是这一层的通行许可。
```

岩舟探头往下看了一眼，脸色变了：“这得有好几十个……不对，看着更多。”

第一章里他们干过这件事：在星之语里用 `blt` 跳回上面，一圈一圈地加。星泠当时在旁边数过，一个 100 个刻点的井，光"往回跳"这一件事就要写十几行星之印。

“这次不这么干。”她展开卷轴，指着第三句刻痕开头的那个记号——一个首尾相接的小环。

“环？”岩舟说，“一直转？”

“**循环**。”星泠说，“你只说一次‘把下一个刻点加进总数，然后看下一个’，剩下多少圈，引擎自己决定。上面那个记号的意思是‘当条件还成立时，就再来一次’。”

屏幕上跳出新的目标：

```
本关目标：int solve(int n) 返回 1 + 2 + ... + n
若 n <= 0，返回 0（井是空的，通行许可为 0）
```

“井底那口是什么？”岩舟问。

“n 等于 0 或者负数。井壁上没有刻点的时候，别去加，也别去取。”星泠把核心放稳，“这是循环最容易出事的地方——条件写反了，它会一直转下去，把魔力耗干。”

---

**你要写的东西**

```c
int solve(int n) { ... }
```

返回 `1 + 2 + ... + n`；`n` 小于等于 0 时返回 `0`。

星咒里的循环有两种写法：

- `while (条件) { ... }` —— 先判断，再执行；
- `for (初始化; 条件; 步进) { ... }` —— 三件事写在一行里；
- 循环里想提前出来，可以 `break;`（跳出整个循环）或 `continue;`（跳到下一轮）。

典型的累加写法是把结果先设成 `0`，然后拿一个计数器从 `1` 走到 `n`，每轮把它加进结果里。

```riscv
{
  "level": "2-3",
  "language": "c"
}
---
// 2-3 循环：返回 1 + 2 + ... + n
int solve(int n) {
    int sum = 0;
    int i = 1;
    while (i <= n) {
        sum = sum + i;
        i = i + 1;
    }
    return sum;
}
```
