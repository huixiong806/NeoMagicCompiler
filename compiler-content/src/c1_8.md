## 1.8 不是问"一不一样"，而是问"谁更大"

第二句刻痕亮起来的时候，岩舟正在喝水。他把水囊塞上，走过来读了一遍。

"甲小于乙就取乙，否则取甲。"他咂了下嘴，"这不就是挑大的那个。第一句话还只是问'一不一样'，这句开始要**比大小**了。"

"`beq` 和 `bne` 只能回答'相等'或'不相等'。"星泠说，"它们没法回答'谁更大'——一个数比另一个数小，这个信息在减法里，不在相等里。星之语为此另有一对分支指令："

```text
blt x1, x2, 标签    # 如果 x1 小于 x2（less than），跳过去
bge x1, x2, 标签    # 如果 x1 大于或等于 x2（greater equal），跳过去
```

"`blt` 是带符号的比较：负数会被当成真正的负数，`-5` 确实小于 `3`。"

岩舟把这句话默念了两遍，抬头："那我先假设'取 x1'，再问一句'x1 真的比 x2 小吗'。要是小，我就跳去把 x2 抄进 x3；不然就直接把 x1 抄进 x3。"

"这就是分支最常见的用法：**先猜一个，再问一句把它推翻**。"星泠点了点柱子，"记得柱子上那句后半截——'否则取甲'。两个数相等的时候，甲和乙一样大，取谁都行，但你必须取一个，不能两个都取、也不能不取。"

```riscv
{
  "level": "1-8",
  "language": "asm",
  "constraints": {
    "readonlySuffix": 1,
    "suggested": { "1": "blt x1, x2, take_x2" }
  }
}
---
# x1、x2 里是闸给的两个数
# 任务：把较大的那个（相等时随便取一个，但要取到）放进 x3

# 标签写在这里，行尾要有冒号

ecall
```

别忘了"抄"也要占一行：`addi x3, x1, 0` 的效果就是把 x1 原样写进 x3（加 0 不改变数）。它比 `add x3, x1, x0` 更省事——这一关里可以用这个技巧。

柱子震了一下，第二句刻痕下面浮出第三行字。岩舟凑近了看，脸色变了：

**此处正路埋着一枚反转印。踩中它的人，会带着错误的数走向下一个房间。**
