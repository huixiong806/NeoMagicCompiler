## 4.10 代码生成：函数调用

篆刻机吐出来的纸已经摞了一小叠。星泠把它们在地上排开，一行行看过去：先是一条算式的星之语，再是带变量的，再是带 `if` / `while` 标签的。四张纸拼在一起，几乎就是一段完整的程序了。

“差不多到顶了。”岩舟拿火把照了照，“再往下还有什么？”

星泠没答话。她把最后一张纸翻过来，背面还有字。

那不是一段片段。那是一份**完整的记录**：

```c
int seal_pulse() { return 7; }
int main() { return seal_pulse() + 1; }
```

“伊塔尔写下的不是一条算式，也不是一串语句。”星泠说，“他写的是**好几个小法术**：每个有自己的名字，一个法术里可以点名让另一个去干活。”

岩舟盯着那两行，慢慢皱起眉：“那我们的机器认不出来。它只会把一整段东西顺着刻下来——可 `main` 要是点了 `seal_pulse` 的名字，纸上刻的字得**跳到别处**去，干完活再回来。”

“你已经刻过这两条印痕了。”星泠把手电挪到洞壁上，“第一章：`jal x1, 名字` 会把‘回来的地址’写进 `ra`；`jalr x0, 0(x1)` 顺着 `ra` 跳回去。一个函数，就是**别处的一段纸**。”

“可 `ra` 只有一个。”岩舟忽然停住，“要是 `main` 里点了 `seal_pulse`，那 `main` 自己该回到哪儿去？`ra` 早被盖掉了。”

“这就是今天要解决的那个麻烦。”星泠说，“一句话：**谁调用别人，谁就得自己护住 `ra`。**”

---

### 这一关的输入

一个或多个函数定义，最后必须有一个 `main`，每个函数都是**无参**的：

```c
int 名字() { return 表达式; }
```

`表达式` 里可以有：整数、`-` 负号、括号、用 `+ - * / %` 连起来的式子，以及**对别的函数的调用** `名字()`。

本关**不涉及变量**（`int x = ...` 下一关再说），所以生成的代码里不会出现 `.data`。

### 这一关的输出：一段真的能汇编的星之语

判定会把你的输出**按行**和标准答案比：每行首尾空白与空行都忽略，其余必须逐字符一致。所以要照着下面的规矩吐：

1. **第一行**是 `.text`，整份输出只吐一次；
2. 每个函数一个标签：函数名加一个 `:`，顺序和源码里的顺序一致；
3. 每个函数由三段组成：
   - **序言**：`addi sp, sp, -16`、`sw ra, 12(sp)`（给 `ra` 腾地方、把 `ra` 存进去）；
   - **函数体**：`return 表达式;` 生成的东西；
   - **收尾**：先一个结束标签 `L1:`（编号见下），再三行 `lw ra, 12(sp)`、`addi sp, sp, 16`、`ret`；
4. **结束标签的编号**：从 1 开始，按函数出现的顺序发（第一个函数 `L1`，第二个 `L2`，……）；
5. `return 表达式;` 分两步：先把表达式的值算进 `a0`，再 `j L<本函数的结束标签>`；
6. 一个数字：`li a0, 数字`；
7. 一元负号：`sub a0, x0, a0`；
8. 二元运算 `左 op 右`：
   - 左边算进 `a0`；
   - **压栈**：`addi sp, sp, -4`、`sw a0, 0(sp)`；
   - 右边算进 `a0`；
   - **弹回 `a1`**：`lw a1, 0(sp)`、`addi sp, sp, 4`；
   - 运算本身：`add a0, a1, a0`（减法 `sub`、乘法 `mul`、除法 `div`、取模 `rem`）；
9. 函数调用：`jal ra, 函数名`；
10. `main` **不要**用 `ecall` 退出——它跟别的函数一样，`ret` 就算完（返回地址是外面的人给它的）。

**第 8 条为什么要压栈？** 因为右边可能是一次调用，而调用会把 `a0` 冲掉。左边的值放在寄存器里迟早会丢，放在栈上（记忆晶阵里）谁也碰不到——这正是你自己的函数把 `ra` 存进栈的同一个道理。

### 两个例子（照这个来）

输入 `int main() { return 42; }` 应该编成：

```asm
.text
main:
addi sp, sp, -16
sw ra, 12(sp)
li a0, 42
j L1
L1:
lw ra, 12(sp)
addi sp, sp, 16
ret
```

输入

```c
int f() { return 7; }
int main() { return f() + 1; }
```

应该编成：

```asm
.text
f:
addi sp, sp, -16
sw ra, 12(sp)
li a0, 7
j L1
L1:
lw ra, 12(sp)
addi sp, sp, 16
ret
main:
addi sp, sp, -16
sw ra, 12(sp)
jal ra, f
addi sp, sp, -4
sw a0, 0(sp)
li a0, 1
lw a1, 0(sp)
addi sp, sp, 4
add a0, a1, a0
j L2
L2:
lw ra, 12(sp)
addi sp, sp, 16
ret
```

看 `main` 的序言：它一进门就把自己的 `ra` 存进 `12(sp)`。这样后面 `jal ra, f` 把 `ra` 盖掉也无所谓——收尾那段会把 `ra` 取回来，`ret` 才能回到该回的地方。**这一关真正教的就是这两行。**

### 判定会喂给你的例子

- `int main() { return 42; }`
- `int f() { return 7; }` 加 `int main() { return f() + 1; }`
- 三个函数、两次调用：`int a() { return 3; }`、`int b() { return 4; }`、`int main() { return a() * b() - a(); }`
- 一个函数里调用两次别人：`int g() { return 5; }`、`int f() { return g() + g(); }`、`int main() { return f() * 2; }`
- 空输入：什么都不用吐（输出里一行的内容都没有才算对）
- 大数字：`int f() { return 2147483647; }`，你的 `emit_num` 得能把它完整吐出来

源码里的空格、换行、缩进随便写（判定喂进来的例子里故意有很乱的空格），你的词法分析要跳过它们。

> 指令白名单这一关是**全开**的（`availableOps` 为空）：你已经在第一到第三章学完了星之语，现在该把它们全都拿出来用了。

```riscv
{
  "level": "4-10",
  "language": "asm"
}
---
# ── 4-10 起点：把输入读完，只吐一个固定的开头 ─────────────────────
# 输入：星咒源码，从 0xF0000004 逐字符读，读到 0 表示结束
# 输出：星之语文本，逐字符写到 0xF0000000
#
# 现在它只会吐一行 ".text"：骨架是通的（输入进得来、输出出得去），
# 但函数标签、序言、return、调用序列都还没有。
.data
hdr:  .asciz ".text\n"

.text
li   t1, 0xF0000004
read_loop:
lw   t2, 0(t1)          # 把源码读完（读回 0 就是结束）
beqz t2, put_hdr
j    read_loop

put_hdr:
la   t3, hdr
emit_loop:
lbu  a0, 0(t3)
beqz a0, done
li   a7, 1
ecall
addi t3, t3, 1
j    emit_loop

done:
li   a0, 0
li   a7, 0
ecall
```
