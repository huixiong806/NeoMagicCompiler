## 2.14 综合：能量配比

藏书厅最里面的那扇小门只有半人高，门上刻着一整段话。星泠跪在门前看了很久。

```
把预算能量分给配方上的每一种元素。
每种元素至少要 1 单位，最多不能超过它在配方上的总量。
从第 0 种元素开始，依次尽量多分；分到一种满了，再分下一种。
若最后恰好把预算分完，门开；若还剩着，或连每样 1 单位都给不起，门不开。
```

“这不是算一个数。”星泠慢慢站起来，“这是在**做一个决定**——门要的回答是 `1` 或者 `0`。”

岩舟读了一遍：“老规矩：先每种给 1 单位当**底价**，再从第一种开始往上加，加满一种再下一种。加完了钱还有剩，就不行。”

“就是这样。”星泠说，“配方有几个元素、预算有多少，都是别的法师填进来的。伊塔尔只写**规则**：谁拿到这张卷轴，填什么数都算得对。”

屏幕上跳出本章最后一个目标：

```
本关目标：int solve(int* recipe, int n, int budget)
  recipe 是配方数组的起始地址，recipe[i] 是第 i 种元素的配比上限
  n 是元素种数（可能为 0），budget 是可用预算能量
  能配平返回 1，不能配平返回 0
```

星泠把规则又拆细了一遍，好让岩舟不必猜：

1. **底价**：每种元素先分 1 单位。若 `budget < n`（连底价都不够），返回 `0`；
2. **剩余**：`rest = budget - n`；
3. **依次尽量多分**：从第 0 种开始，第 `i` 种最多还能再加 `recipe[i]` 单位（它已经拿到 1 单位底价，所以上限是 `recipe[i] + 1`）。`rest` 够就全加上并减掉；不够就把剩下的全给它，`rest` 归 0；
4. **判定**：全部处理完后 `rest == 0` 返回 `1`，否则返回 `0`（多出来的能量没地方去，就是不平衡）。

---

**你要写的东西**

```c
int solve(int* recipe, int n, int budget) { ... }
```

按上面的四条规则返回 `1` 或 `0`。

- `recipe` 是**地址**，用 `recipe[i]` 访问第 `i` 种配比上限（`recipe[i] >= 1`）；
- `n` 可能为 0：`budget == 0` 时返回 `1`，否则返回 `0`（照上面的规则算自然会得到这个结果）。

小提示：整个过程只需要一次 `for` 循环和一个 `rest` 变量。

```riscv
{
  "level": "2-14",
  "language": "c"
}
---
// 2-14 综合：能量配比 —— 能配平返回 1，否则返回 0
// 规则：每种元素至少 1 单位；从第 0 种开始依次尽量多分（不超过 recipe[i]）；
//       最后恰好分完 budget 返回 1，剩下没分完或连底价都不够返回 0
int solve(int* recipe, int n, int budget) {
    int i;
    int rest;

    if (budget < n) {
        return 0;
    }

    rest = budget - n;
    for (i = 0; i < n; i = i + 1) {
        int cap = recipe[i] - 1;
        if (rest >= cap) {
            rest = rest - cap;
        } else {
            rest = 0;
        }
    }

    if (rest == 0) {
        return 1;
    }
    return 0;
}
```

门开了。门后是一条向上的石阶——不是往下，是**往上**。灯火顺着台阶一层层减弱，最上面有一点很淡的、不属于火光的白光。

“这一层结束了。”星泠把魔导核心收进怀里，“上面是什么，我不知道。但伊塔尔把高阶语写在这里，说明上头还留着他没说完的话。”
