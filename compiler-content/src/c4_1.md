## 4.1 把咒文切成词

石阶的尽头是一间圆厅，四面墙都是刻满星咒的石板。

岩舟把方板贴上去，石板上那行字亮了半秒，又灭了。

"它**认得**这行字。"星泠说，"但认不全。"

她把方板翻过来给他看：那行字在她手里被切成了一段一段——`int`、`space`、`sum`，每段单独躺在一个格子里，像被人拿刀顺着词缝划开。

"魔导引擎不读句子，它读**词**。伊塔尔留下的那台老核心更极端：它连'词'都没有，只有一个个字符。所以一个编译器要做的第一件事，就是把一串没有间隔的字符，重新切成有意义的**最小片段**——这一步叫**词法分析**（lexing），切出来的每一段叫一个 **token**。"

"听着像分词。"岩舟说。

"就是分词，但规则更死。"星泠在石板边缘写下几条规矩，"人不确定'魔法师'是一个词还是两个词，编译器不许不确定。我们这套被封印的编译器，token 只有这几种："

**要输出的 token 种类（这一关只要这些）**

| 写法 | 意思 | 例 |
|------|------|-----|
| `KW:名字` | 关键字，VALUE 用原文 | `KW:if`、`KW:while`、`KW:int`、`KW:void`、`KW:else`、`KW:return` |
| `ID:名字` | 标识符（名字） | `ID:sum`、`ID:main` |
| `NUM:数值` | 整数，**数值统一用十进制**写 | 源码 `42` → `NUM:42` |
| `OP:符号` | 运算符与括号、分号、逗号 | `OP:+`、`OP:==`、`OP:(`、`OP:;`、`OP:<=` |

关键字就六个：`if` `else` `while` `return` `int` `void`。除此之外，只要是字母开头的一串字母，都是 `ID`。

符号里有两字符的：`==` `!=` `<=` `>=` `&&` `||`（`<<` 和 `>>` 也按两个字符算）。其余的单字符符号：`+` `-` `*` `/` `=` `<` `>` `(` `)` `{` `}` `;` `,`。

**空白（空格、制表、换行）直接跳过**，不产生任何 token——所以缩进怎么排版都不会影响结果。

"要**输出**什么？"

"把切出来的 token 一行一个，印到显示端口上。"星泠说，"像这样："

```
int sum = 42;
```

要印出三行：

```
KW:int
ID:sum
OP:=
NUM:42
OP:;
```

"注意 `KW:int` 里的 `int` 就是原文，`NUM:42` 里的 `42` 是**数值**——如果是十六进制的 `0x2A`，这一关先不管（下一关再说），这一关只认十进制。"

岩舟已经在方板上敲了："我大概知道了。读一个字符 → 看它是什么 → 吐一个 token。就三句话。"

"是四句。"星泠说，"你还漏了一句最麻烦的：**回看**。"

她指着 `<=` 里的那个 `<`：

"读到 `<` 的时候，你**还不能**决定这是 `OP:<` 还是 `OP:<=`——你得再看一眼下一个字符。可如果下一个字符是 `b`，那这个 `b` 是**下一个 token 的开头**，你不能把它吃掉。所以引擎里得留一个'回看缓冲'：多看的那个字符先放在手边，下一次读字符时先还给你。同理，读到 `int` 的 `i` 时你不知道这个词到哪结束，得一直读到不是字母为止——那个'停下来的字符'也必须还回去。"

"另外，读字符用 `lbu`。"她在方板上写下一行，"它读的就是**一个字节**。这台引擎的输入端口其实 `lw` 也只消费一个字符，但 `lw` 读的那四个字节里只有第一个是真的、后三个是填的零——你若写 `lw`，读到的值是对的，可'读一个字节'这件事就写错了。读一个字符，就用 `lbu`。"

```riscv
{
  "level": "4-1",
  "language": "asm",
  "constraints": {
    "suggested": {
      "10": "jal x1, next_token   # 读一个 token 并输出一行",
      "11": "beq x10, x0, done     # 返回 0 = 输入结束"
    }
  }
}
---
# 4-1 把星咒源码切成 token，一行一个 KIND:VALUE
#
# 输入：星咒源码文本，从 0xF0000004 逐字符读（用 lbu：它读一个字节。本引擎里 lw 也只消费一个
#       字符，但读到的后三个字节是零，语义不对），读到 0 表示结束
# 输出：显示端口 0xF0000000，一行一个 token
#   KW:名字  ID:名字  NUM:十进制数值  OP:符号
#   关键字只有六个：if else while return int void
#   空白（空格 9、制表 9、换行 10）直接跳过，不产生 token
#   遇到不认识的字符：输出 ERR:那个字符，然后结束
#
# 已经替你开好的东西：
#   sp 指向 0x3000（栈往下长）
#   s0 里是输入端口地址；getc 会用 s0 读字符，并把结果放进 x10
#   getc / ungetc 是一对：getc 先看"回看缓冲"里有没有多看的字符，没有才去读端口
#   print_int 把 x10 里的非负整数按十进制印出来
#   kwtab 里 6 个槽已经填好六个关键字字符串的地址（0/4/8/12/16/20 字节处）
#   buffer 是给你存一整个词的缓冲区（0 结尾）

    .equ INPORT,  0xF0000004
    .equ DISPLAY, 0xF0000000

    .text
main:
    li   sp, 0x3000
    li   s0, INPORT
    li   t0, kwtab
    la   t1, kw0
    sw   t1, 0(t0)
    la   t1, kw1
    sw   t1, 4(t0)
    la   t1, kw2
    sw   t1, 8(t0)
    la   t1, kw3
    sw   t1, 12(t0)
    la   t1, kw4
    sw   t1, 16(t0)
    la   t1, kw5
    sw   t1, 20(t0)
# ↓ 从这里开始是你的活：
#   1) 先把下面两个空壳填满：
#        skip_ws    —— 反复 getc，是空白就丢掉继续，不是空白就 ungetc 还回去
#        next_token —— 调用 skip_ws，然后 getc 拿到第一个字符，按它分类：
#                        字母 → 读完整词，和 kwtab 里 6 个关键字比：中了输出 KW:，没中输出 ID:
#                        数字 → 一位一位拼成数值（值 = 值 * 10 + 这一位），输出 NUM:
#                        符号 → 先 getc 多看一个字符：是 '=' 或和自己相同（&& ||）就是两字符
#                               运算符，否则把多看的那个 ungetc 还回去；
#                               不认识的字符输出 ERR: 并返回 1
#                        0    → 输入结束，返回 0
#                      每个 token 输出完记得补一个换行
#   2) 再把主循环的注释去掉，让它反复调用 next_token
# main_loop:
#     jal  x1, next_token
#     beq  x10, x0, done
#     j    main_loop

skip_ws:
    jalr x0, 0(x1)

next_token:
    addi x10, x0, 0
    jalr x0, 0(x1)

done:
    li   a0, 0
    li   a7, 0
    ecall

# ── 读一个字符：x10 = 字符（0 = 输入结束）──
getc:
    la   t0, lookahead
    lbu  t1, 0(t0)
    beq  t1, x0, getc_fetch
    sb   x0, 0(t0)
    addi x10, t1, 0
    jalr x0, 0(x1)
getc_fetch:
    lbu  x10, 0(s0)
    jalr x0, 0(x1)

# ── 把 x10 里的字符还回回看缓冲 ──
ungetc:
    la   t0, lookahead
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 把 x10 里的非负整数按十进制印出来 ──
print_int:
    li   t0, 10
    blt  x10, t0, pi_last
    addi sp, sp, -8
    sw   x1, 0(sp)
    sw   x10, 4(sp)
    div  x10, x10, t0
    jal  x1, print_int
    li   t0, 10
    lw   x10, 4(sp)
    rem  x10, x10, t0
    lw   x1, 0(sp)
    addi sp, sp, 8
pi_last:
    addi x10, x10, 48
    li   t0, DISPLAY
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 数据 ──
    .data
s_colon:
    .asciz ":"
s_kw:
    .asciz "KW"
s_id:
    .asciz "ID"
s_num:
    .asciz "NUM"
s_op:
    .asciz "OP"
s_err:
    .asciz "ERR"
kw0:
    .asciz "if"
kw1:
    .asciz "else"
kw2:
    .asciz "while"
kw3:
    .asciz "return"
kw4:
    .asciz "int"
kw5:
    .asciz "void"
kwtab:
    .word 0, 0, 0, 0, 0, 0
o_slot:
    .word 0
buffer:
    .space 4096
lookahead:
    .word 0
```

三个坑先放在这里，踩了别慌：

- **`lw` 不是"读一个字符"的意思**。它读四个字节（这台引擎的输入端口只会给出第一个，其余是零），
  所以想读一个字符就老老实实写 `lbu`。它读错了不会报错，只会让你在别处对不上。
- **多看的那一眼必须能还回去**。`<=`、`==`、`&&` 都靠它；还错了就会出现"少一个 token"或"多一个怪 token"。
- **关键字要整词比**。读到 `i` 就输出 `KW:if` 是不行的——`int` 和 `if` 前一个字母一样。先把整个词读进 `buffer`，再拿着它跟 `kwtab` 里六个串逐个比。

调试面板在这一关特别好用：**输入队列是一次性的**，读走的字符不会回来。如果输出的 token 比预期少一大截，八成是你把不该吃的字符吃掉了——在循环里放一条 `ebreak`，停下来看队列还剩几个字符。

做完这一关，你就有了半个前端。下一个麻烦：石板上还有 `0x2A`、`'A'`、`"hello"` 这种东西——数字不止一种写法，还有被引号包住的字符和字符串。
