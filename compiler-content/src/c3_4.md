## 3.4 状态机

总和对上的时候，石台里传出一声很长的回声。岩舟正想说话，穹顶上的刻痕忽然换了一种写法。

不再是"一层一层"的刻痕了。它们变成了**一排字**：

```
abc  x9  a1b2c3  9x  x_y
```

"这次不是数了。"星泠说，"这次是**词**。"

她指着那一排字的左侧，那里刻着一行小字：

> **词：一串连续的字母和数字。以字母开头的是合法咒文词。**

岩舟把它读了两遍："所以 `abc` 算，`a1b2c3` 算；`9x` 不算，因为开头是数字。"

"对。还有一个更细的规矩——**凡是既不是字母、也不是数字的字符，都是分隔符**。"星泠在方板上把这条写粗了一点，"空格、逗号、问号、换行，当然还有下划线，全都一样，都只是把词切开而已。所以 `x_y` 不是'一个被弄坏的词'，它是**两个**合法的词：`x` 和 `y`。"

"那我认出来不就完了？每个词拿眼睛看一遍。"

"**看一遍是可以的。**"星泠说，"难的是让机器看一遍——而且**不许回头**。"

---

### 这一关真正要学的东西

她把方板翻到新的一页，画了三个格子。

"你读字符的时候，永远只有一个字在手上。你已经读过的那些字，**不能回头再看**。所以你不能等读完整串再判断——你必须**一边读一边记住"我读到哪了"**。"

她在三个格子下面写下一行：

```
我现在站在哪里？
```

"这就是**状态**（state）。它不是数据，是**处境**。这一关只有三种处境："

1. **还没进词**（或者刚读完一个词）——下一个字符如果是个普通字符，它就是**这个词的第一个字符**；
2. **已经站在一个词的第一个字符上**——这时候你要做一件特别的事：判断它**是不是字母**。是字母，这个词就**有资格**；是数字，这个词从第一个字符起就**废了**；
3. **已经过了第一个字符**——这时候你只关心一件事：后面进来的字符**有没有把这个词弄坏**。字母和数字都安全，别的东西（下划线、标点……）会让它**作废**——而且它同时**就是分隔符**，这个词到这里就结束了，后面那个字母**不许接上来重新开始**。

"注意第 2 条。"星泠敲了敲方板，"**同一个字符，站在不同处境下含义完全不同。**你读到 `'5'`：如果它在一个词的中间，那没事；如果它是这个词的头一个字，那这个词就废了。"

岩舟盯着那三个格子看了很久："所以状态机就是……把'我刚才在干嘛'记下来？"

"对。**状态机就是把'处境'变成一个数存起来。**"她说，"而且你会发现一件事：你只需要记住**三个开关**——"

| 寄存器 | 意思 |
|--------|------|
| `x8` | 1 = 已经进词了（首字符处理过了，后面的字符走"后续字符"这条路） |
| `x9` | 1 = 这个词**目前合法**（首字符是字母），只看后面还有没有捣乱的 |
| `x12` | 1 = 这个词**已经废了**（遇到过一个不是字母数字的字符） |

"三个开关都是 0 的时候，就是'我在两个词之间'。"

"等一等。"岩舟指着第三个开关，"**这个为什么也要单独记？** 废了不就是废了，`x9` 清 0 不就完了？"

星泠把方板转过来，写了一个他刚才没想到的例子：

```
a9_x
```

"`a9` 是合法的，走到 `_` 的时候它被结算掉了，`x9` 清 0。"她说，"现在下一个字符是 `x`——按你的说法，你会问：'我已经进词了吗？' 进过了。'这个词还合法吗？' 不合法了。于是你**什么都不做**，让 `x` 白白过去——"

"那不是正好吗？"

"可如果 `x8` 也顺手清掉了呢？那 `x` 就会被当成**一个新词的首字符**，凭空多数出一个来。"她把刻笔点在第三个开关上，"所以这两个问题必须分开：**'我在不在词里'** 和 **'这个词还有没有救'**。废掉的词要一直废到**真正的分隔符**出现为止。"

"这也太朴素了。"

"编译器的词法分析器就是这么朴素。"星泠说，"它里面有一张表写着'在状态几遇到字符几，转到状态几'。我们这一关用手写的判断代替那张表——**思路是一样的**。"

---

**现在必须解决的麻烦**：穹顶上的那排字正在往下掉，字一掉完，机器就要答案。

你要做的是：**数出这一串输入里有多少个合法词**。

判断时有三个地方最容易错，星泠把它们先摆出来了：

- **收尾**。一个词"结束"有两种方式：遇到分隔符（空格、标点、下划线），或者**输入正好在词中间读完**。后一种更阴：`ab` 只有两个字符，没有分隔符，它照样是一个合法词——所以读回 `0`（输入结束）的时候，也要走一次"收尾"。
- **收尾之后要复位**。数完一个词，所有开关必须回到 0，否则下一个词会被上一个词的结论连累。
- **不是字母也不是数字的，一律是分隔符**。这条要说死：`x_y` 里的下划线**不是**"把词弄坏"，它是把 `x_y` 切成 `x` 和 `y` 两个字——**两个都合法**。机器不认识"下划线不合法"这种说法，它只认识"这是不是字母数字"。

`solutions` 里的参考答案把它写成了一个循环加一组判断；骨架里已经把主循环的形状给了你：

```riscv
{
  "level": "3-4",
  "language": "asm",
  "constraints": {
    "readonlyPrefix": 1,
    "readonlySuffix": 2,
    "suggested": {
      "5": "li x6, 48 / blt x5, x6, 分隔符：先认出'不是字母也不是数字'的情况",
      "14": "首字符是字母 → x9 置 1；这个词被弄坏 → x12 置 1"
    },
    "highlight": [8]
  }
}
---
li x1, 0xF0000004
li x21, 0xF0000000
addi x8, x0, 0
addi x9, x0, 0
addi x12, x0, 0
addi x18, x0, 0
loop:
lw x5, 0(x1)
beq x5, x0, finish
# ↓ 下面从这里开始写：
#   1. 先判断 x5 是不是"普通字符"（字母或数字）；不是就当场按分隔符处理
#   2. 是普通字符：x8 = 0 → 它是这个词的首字符（字母 → x9 = 1；数字 → 什么都不做）
#                 x8 = 1 → 它是后续字符（还合法的话，字母数字都安全，别的把它弄坏：
#                          x9 = 0 并且 x12 = 1）
#   3. 分隔符：x9 = 1 就把 x18 加一，然后把 x8 / x9 / x12 三个开关都清 0
j loop
finish:
# 输入正好停在一个词中间：这里也要收尾一次（别忘了 x9 = 1 才加一）
li x9, 0x2000
sw x18, 0(x9)
addi x10, x18, 0
li x17, 2
ecall
li x10, 0
li x17, 0
ecall
```

两个容易踩的坑：

- **初值别抄错**：`x8`（进没进词）、`x9`（合不合法）、`x12`（废没废）**都要从 0 开始**。如果习惯性把某个寄存器"先设成 1"，就会出现"第一个字符还没读，词已经算合法了"这种错。
- **`'9'` 和 `'A'` 之间那道空档**：`blt x5, x6, 标签` 只能问"比谁小"。要表达"在 65 到 90 之间"，你得先问下界、再问上界——问漏一次，`@` 就会被当成字母。

答案对上的一瞬间，那排字从穹顶上掉了下来，落到石台上，一个字符一个字符地沉进石面里，像被吸回去一样。

"它在收题目。"星泠说，"下一道不是词了——是**结构**。"

岩舟把手插进石台侧面的方口，摸到一串硬邦邦的东西，像一排小小的挂钩。
