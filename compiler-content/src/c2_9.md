## 2.9 每块石头都带着两个读数

门后是一间符文储藏室。

架子上的符文石和之前见过的不一样：每一块都同时刻着**两个**数字——上排是这块石头蕴含的能量强度，下排是它的份数。旁边一块牌子上写着：

```
总能量 = 能量强度 × 份数，逐个相加。
```

岩舟伸手就想去分两部分记：“强度一排，份数一排，那我用两个数组……”

“不行。”星泠拦住他，“它们不是两排东西，它们是**同一块石头的两件事**。你把它们拆成两个数组，以后加一种读数，就要再加一个数组，越写越乱。”

“那怎么记？”

“卷轴这一句刻痕借用了古人的办法。”星泠指着卷轴上的一小段，“他们先**定义一种新的东西**，说清楚它由哪几样组成——这里，一个符文由 `power` 和 `count` 两个整数组成，取名叫 `rune`。有了这个名字，一整块石头就是一个 `rune`；一整排石头，就是**一排 `rune`**。”

“那取出来的时候——”

“下标照样能用。只是取出来的不再是一个数，而是一整块石头，你要再往里点一下才能拿到它的能量强度：`r->power`，或者 `(*r).power`。”

屏幕上跳出新的目标：

```
本关目标：定义 struct rune { int power; int count; };
          int solve(struct rune* r, int n) 返回 n 块符文的总能量
          （每块贡献 power × count，全部相加）
```

“**注意**，”星泠补了一句，“`r` 还是**地址**，是架子上第一块石头的门牌号。测试会先把整排符文摆在记忆晶阵里，再把地址交给你；某块石头的份数可能是 0，那种石头一块能量都不贡献。”

---

**你要写的东西**

```c
struct rune { int power; int count; };

int solve(struct rune* r, int n) { ... }
```

- `struct rune` 就是**结构体**：它把 `power` 和 `count` 两个整数捆成一件东西，占两个 `int` 的宽度（8 字节）。
- `r` 是结构体数组的首**地址**；第 `i` 块石头是 `r[i]`，取它的成员写 `r[i].power`、`r[i].count`（用指针写法就是 `(*(r + i)).power`，简写成 `r[i].power`）。
- 返回全部 `power × count` 之和。空数组（`n = 0`）返回 `0`。

**参数怎么传**：测试把结构体数组按顺序铺在记忆晶阵里，参数 `r` 给的是它的地址（十进制写在 `args` 里，比如 `8192` 就是 `0x2000`）。

```riscv
{
  "level": "2-9",

---
// 2-9 结构体：返回符文数组的总能量（每块贡献 power * count）
struct rune {
    int power;
    int count;
};

int solve(struct rune* r, int n) {
    int total = 0;
    int i;
    for (i = 0; i < n; i = i + 1) {
        total += r[i].power * r[i].count;
    }
    return total;
}
```
