## 4.11 综合：编译并运行

方板背面刻出来的印痕沿着铜线一路走进洞壁。星泠跪在线的末端，把最后一截按上触点。

“接上了。”她说，“从这一关起，这台机器吐出来的东西不再是纸——是**直接进魔导引擎的印痕**。”

岩舟把手放在触点上，指尖有点发麻：“所以它能跑了？”

“能跑，但我不打算拿封印去试。”星泠从怀里摸出一张自己画的草稿，“伊塔尔那份记录一旦跑错，我们连错在哪都不知道。先拿一段我自己写的程序**试刀**——答案我知道，机器算不出来就是机器的错。”

她把草稿递过去：

```c
int twice() { return 2; }
int main() {
  int s = 0;
  int i = 1;
  while (i <= 5) {
    s = s + i * twice();
    i = i + 1;
  }
  return s;
}
```

“这是 2×1 + 2×2 + 2×3 + 2×4 + 2×5。”岩舟心算了一下，“等于 30。”

“对。`30` 就是试刀的标准。”星泠说，“注意这段草稿把前面几层都用上了：**变量**、**赋值**、**循环**、**比较**、**调用**、**乘加**。哪一层错了，30 都不会是 30。”

---

### 这一关怎么判：真的跑

前面几关是“把你吐出来的文本和标准答案比一行”。这一关不一样：

1. 判定器把上面那段草稿**当作字符流**，从 `0xF0000004` 喂进你的编译器（读到 `0` 就是源码结束）；
2. 把你的**输出文本**交给真正的星之语汇编器；
3. 汇编成功后，它找到 `main` 这个符号，`jalr` 跳进去，等它 `ret`；
4. 最后看 `a0` 里是不是 **30**。

也就是说：**你的编译器必须能编译整段程序，而且编译出来的东西必须真的跑出 30。**

输出里必须做到的三件事：

- 定义 `main` 这个符号（判定器就是靠它找入口的）；
- `main` 用 `ret` 结束，**不要**在生成的目标代码里写 `ecall`（外面的引导代码会在 `main` 返回之后自己收尾）；
- 整份输出能被汇编器接受（标签别重名、跳转别越界、变量声明写完整）。

### 喂进去的那段草稿用了哪些语法

只用了 4-7 ~ 4-10 教过的那一小套，一条都没多：

| 语法 | 出现在哪 |
|------|----------|
| 函数定义 `int 名字() { … }` | `twice`、`main` |
| 局部变量声明（带初值）`int 名字 = 表达式;` | `int s = 0;`、`int i = 1;` |
| 赋值 `名字 = 表达式;` | `s = s + i * twice();`、`i = i + 1;` |
| `while (表达式) 语句` | 整段循环 |
| `return 表达式;` | 两处 |
| `+` `*` 的优先级 | `s + i * twice()` |
| 比较 `< <= > >= == !=` | `i <= 5` |
| 无参调用 `名字()` | `twice()` |
| `if` | **这一段没有**（终章那段有，建议顺手写上） |

没有参数、没有递归、没有数组、没有指针。

### 可以沿用前面那一套

- 变量照 4-8 的写法：`.data` 里 `名字: .word 0`，用的时候 `la a1, 名字`，再 `lw a0, 0(a1)` / `sw a0, 0(a1)`；
- 分支循环照 4-9 的写法：标签 `L<数字>` + `beqz a0, L<数字>` + `j L<数字>`；
- 函数照 4-10 的写法：函数名当标签、序言里 `sw ra, 12(sp)`、收尾里 `lw ra, 12(sp)`。

**这一关判定不看文本**：寄存器怎么用、标签怎么编号、`.data` 放在开头还是结尾，都随你（判定只关心跑出来的 `a0`）。参考解的处理是“一边读一边吐”的单遍编译器，所以它把变量声明补在**最后**——只有整个程序读完，才知道一共出现过哪些变量。

> 提醒一句：判定只喂这一段程序，所以理论上你可以把它的目标代码**写死**印出来。别那么干——终章会喂一段**不一样**的程序，写死的机器在那里一定停。

### 小提示

- `maxInstructions` 给得很大（50 万条）：读源码、查表、吐文本都要花指令，别怕慢；
- 草稿里的换行和缩进都要能跳过（判定喂进来的文本是带换行的）；
- 读到 `0` 就是源码结束，编译器自己正常收尾（`a7=0` 的 `ecall`）。

```riscv
{
  "level": "4-11",
  "language": "asm"
}
---
# ── 4-11 起点：先把管道接通 ─────────────────────────────────────
# 1) 把源码从 0xF0000004 读完（读到 0 为止）——先不管它写了什么
# 2) 吐一个固定的"空壳程序"：它定义了 main、用 ret 结束，
#    所以汇编器和模拟器都收得下 —— 只是它永远返回 0。
#    跑一次提交，判定会告诉你：main 的返回值应为 30，实际 0。
.data
stub: .asciz ".text\nmain:\nli a0, 0\nret\n"

.text
li   t1, 0xF0000004
read_loop:
lw   t2, 0(t1)
beqz t2, put
j    read_loop

put:
la   t3, stub
put_loop:
lbu  a0, 0(t3)
beqz a0, done
li   a7, 1
ecall
addi t3, t3, 1
j    put_loop

done:
li   a0, 0
li   a7, 0
ecall
```

触点下面的引擎响了一声，很短，像有人吹熄了一根蜡烛。

岩舟盯着印痕的末端看了很久：“它动了。”

“它认出 `main` 了。”星泠把手抽回来，指尖在抖，“几百年没人念过的名字，它认出来了。”

她站起来，望向厅最里面那面石墙。墙上刻着一整段星咒——不是片段，不是草稿，是一份**完整的记录**，从第一行最后一个字刻到最后一行，字迹比她见过的任何东西都老。

“那就是封印程序？”

“那就是伊塔尔留在墙上的东西。”星泠说，“他这辈子最后写下的那段——‘让核心再安静几百年’的那段。”

岩舟咽了口唾沫：“我们的机器，真的能编译它？”

“能。”星泠说，“因为我们手里这台机器，是你从第一条 `li` 开始一行一行搭出来的。”

**下一关**：把墙上那段星咒喂进去——编译它、跑它，把封印重启。
