## 4.3 排队，而不是算

石板背面那行算式不长：

```
(1+2)*3
```

但旁边那四个字很重：**先算谁**。

"《星咒初阶》里写着'先乘除、后加减，有括号先算括号'。"岩舟说，"它连这个都不知道？"

"它**知道**，但它不是那样工作的。"星泠说，"伊塔尔那台核心没有'优先级'这个部件。它只有一条规则：**从上往下、从左往右**。所以聪明的做法不是让它学会优先级，而是**把优先级变成顺序**——把式子重新排成一台只会顺着走的机器也能算的样子。"

她在方板上写下两行：

```
中缀（人写的）   1 + 2 * 3
后缀（机器要的） 1 2 3 * +
```

"后缀式，也叫 **RPN**（逆波兰式）。它没有括号、没有优先级，读到第几个数就往前两个数上一次运算——`1 2 3 * +` 的意思是：先算 `2*3`，再算 `1+6`。"

"那怎么把中缀变成后缀？"

"**排队。**"星泠说，"数字不用等，直接走出去。运算符要**排队**——但队伍不是先来先出，而是'**谁急谁先走**'。"

这就是**调度场算法**（shunting yard）。规则只有五条：

1. 读到**数字**→ 立刻输出。数字永远不用排队。
2. 读到**运算符**→ 先看队尾（栈顶）那个运算符：只要它的'急迫程度'**不低于**自己，就让它先出去；等前面没人是自己的对手了，自己再排进去。
3. 读到 **`(`** → 直接排队。它不输出，它只是一道**挡板**：队伍里排在它后面的运算符，不许越过它去比急迫程度。
4. 读到 **`)`** → 一直让队尾的人出去，直到撞上那道挡板；挡板本身**丢掉**，不输出。
5. 输入读完 → 队伍里剩下的人**从后往前**全部出去。

"急迫程度就是优先级：`*` `/` 是 2，`+` `-` 是 1。"

**这一关的输出格式**（数字和上一关一样，括号和别的符号这一关不出现）：

| 读到的东西 | 输出 |
|------------|------|
| 数字 | `NUM:值`（十进制） |
| `+` `-` `*` `/` | `OP:+` 这样的形式 |
| `(` `)` | **什么都不输出**，它们只影响顺序 |

拿 `(1+2)*3` 走一遍：

| 读到 | 输出到哪儿了 | 队伍（栈，右边是队尾） |
|------|--------------|------------------------|
| `(` | — | `(` |
| `1` | `NUM:1` | `(` |
| `+` | | `( +` |
| `2` | `NUM:2` | `( +` |
| `)` | | 撞到挡板：`+` 出去 → 输出 `OP:+`，挡板丢掉 |
| `*` | | `*` |
| `3` | `NUM:3` | `*` |
| 结束 | | 弹出 `*` → 输出 `OP:*` |

一共五行：`NUM:1`、`NUM:2`、`OP:+`、`NUM:3`、`OP:*`。

"队伍存在哪儿？"岩舟问。

"**栈**。"星泠说，"回到第一章那个'往上堆'的东西——把队伍存成往地址小的方向长的一串字节，队尾就是栈顶。你已经有 `sp` 了，但这一关建议**再拿一个寄存器当运算符栈的指针**：`sp` 要留着存返回地址，两个栈混用迟早出事。"

她在方板上写了两行地址：

```
运算符栈的顶   0x1800   ← s3 从这里开始，每压一个就减 1
运算符栈的底   0x1000   ← s5 记住它；s3 一旦 <= 底，就说明栈空了
```

"底这个数字不是拿来访问的，是拿来**比**的。"她说，"第一章你学过：想判断'走到了这一排的边上'，不必真的去读那块地，拿个假地址比一比就行。`bge s5, s3` —— 底跑到栈顶上面去了，就是空的。"

```riscv
{
  "level": "4-3",
  "language": "asm",
  "constraints": {
    "suggested": {
      "16": "jal x1, read_number   # 数字：立刻输出 NUM:值",
      "17": "jal x1, emit_op       # 运算符：先弹后压"
    }
  }
}
---
# 4-3 中缀 → 后缀（RPN）：一行一个 token
#
# 输入：只有数字和 + - * / ( ) 的表达式，从 0xF0000004 逐字符读（0 = 结束）
# 输出：数字 → NUM:值（十进制）；运算符 → OP:符号；括号**不输出**（只影响顺序）
#   例：1+2*3 → NUM:1 / NUM:2 / NUM:3 / OP:* / OP:+
#
# 已经替你开好的东西：
#   sp 指向 0x3000（存返回地址用）
#   s3 是运算符栈的栈顶指针，从 0x1800 **往下**长；s5 是栈底 0x1000
#      「栈空了吗」的判据就是 `bge s5, s3`（拿假地址当哨兵，第一章学过）
#   getc / ungetc：读一个字符 / 把多看的那一个还回去（数字多位时要靠它）
#   putch：把 x10 里的字符送到显示端口；newline：输出一个换行
#   print_int：把 x10 里的非负整数按十进制印出来
#   inport 里存好了输入端口地址；s_num / s_op 两个串（"NUM" / "OP"）已备好

    .equ INPORT,  0xF0000004
    .equ DISPLAY, 0xF0000000

    .text
main:
    li   sp, 0x3000
    li   s3, 0x1800            # 运算符栈的栈顶指针
    li   s5, 0x1000            # 运算符栈的栈底（哨兵）
    li   t0, INPORT
    la   t1, inport
    sw   t0, 0(t1)
# ↓ 从这里开始是你的活：
#   主循环读一个字符，按五种情况分派：
#     空白（空格 32 / 制表 9 / 换行 10）→ 跳过
#     0                                 → 输入结束：把栈里剩下的全弹出来输出，然后收工
#     '('                               → 压栈（不输出）
#     ')'                               → 一直弹出并输出，直到弹到 '('；那个 '(' 丢掉
#     运算符（+ - * /）                 → 调用 prec 拿优先级：只要栈顶优先级不低于自己就弹出，
#                                          撞到 '(' 或栈空（bge s5, s3）就停，然后把自己压进去
#     数字（'0'-'9'）                    → 读完整个数，输出 NUM:值
#   两个现成的小工具已经写好了：
#     prec      —— x10 里放运算符，x11 得到优先级（'*' '/' 是 2，'+' '-' 是 1）
#     emit_op   —— x10 里放运算符，输出 `OP:符号` 并换行
#   read_number（读多位数字并输出 NUM:值）留给你写 —— 它是这个程序里最像上一关的一段
#   写完把它接到上面第 6 行的位置：主循环里遇到数字就 jal 它

done:
    li   a0, 0
    li   a7, 0
    ecall

# ── 运算符优先级：x10 → x11 ──
prec:
    li   t0, 42                # '*'
    beq  x10, t0, prec2
    li   t0, 47                # '/'
    beq  x10, t0, prec2
    addi x11, x0, 1
    jalr x0, 0(x1)
prec2:
    addi x11, x0, 2
    jalr x0, 0(x1)

# ── 输出 `OP:符号` 并换行：x10 = 运算符 ──
emit_op:
    addi sp, sp, -8
    sw   x1, 0(sp)
    sw   x10, 4(sp)
    li   t0, DISPLAY
    la   t1, s_op
    lbu  t2, 0(t1)
    sb   t2, 0(t0)
    lbu  t2, 1(t1)
    sb   t2, 0(t0)
    lbu  t2, 2(t1)
    sb   t2, 0(t0)
    li   t2, 58                # ':'
    sb   t2, 0(t0)
    lw   t2, 4(sp)
    sb   t2, 0(t0)
    li   t2, 10                # 换行
    sb   t2, 0(t0)
    lw   x1, 0(sp)
    addi sp, sp, 8
    jalr x0, 0(x1)

# ── 输出一个字符（x10）──
putch:
    li   t0, DISPLAY
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 输出换行 ──
newline:
    li   t0, DISPLAY
    li   t1, 10
    sb   t1, 0(t0)
    jalr x0, 0(x1)

# ── 把 x10 里的非负整数按十进制印出来 ──
print_int:
    li   t0, 10
    blt  x10, t0, pi_last
    addi sp, sp, -8
    sw   x1, 0(sp)
    sw   x10, 4(sp)
    div  x10, x10, t0
    jal  x1, print_int
    li   t0, 10
    lw   x10, 4(sp)
    rem  x10, x10, t0
    lw   x1, 0(sp)
    addi sp, sp, 8
pi_last:
    addi x10, x10, 48
    li   t0, DISPLAY
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 读一个字符：x10 = 字符（0 = 输入结束）──
getc:
    la   t0, lookahead
    lbu  t1, 0(t0)
    beq  t1, x0, getc_fetch
    sb   x0, 0(t0)
    addi x10, t1, 0
    jalr x0, 0(x1)
getc_fetch:
    la   t0, inport
    lw   t0, 0(t0)
    lbu  x10, 0(t0)
    jalr x0, 0(x1)

# ── 把 x10 里的字符还回回看缓冲 ──
ungetc:
    la   t0, lookahead
    sb   x10, 0(t0)
    jalr x0, 0(x1)

# ── 数据 ──
    .data
s_num:
    .asciz "NUM"
s_op:
    .asciz "OP"
ostk_bottom:
    .space 512
inport:
    .word 0
lookahead:
    .word 0
```

两个坑：

- **挡板不能越过**。比优先级的时候，如果栈顶是 `(`，**立刻停手**——说明这道括号还没有闭合，外面的运算符没资格越过它。少了这一句，`(2+3*4)*(1+1)` 这种式子会把两个括号里的东西算混。
- **相等也要弹**。`1-2-3` 里第二个 `-` 的优先级**不低于**栈顶那个 `-`，所以栈顶必须让位——否则输出会变成 `1 2 3 - -`（结果一样，但顺序不是从左到右了；`1-2-3` 恰好对，`12/3/2` 就会算出 8 而不是 2）。

后面四关里，这台"排队机"会一路长成真正的编译器：先给表达式建一棵树，再看括号里的名字有没有声明过，最后真的**吐出星之语**——到那时，你写的东西才可以拿去给魔导引擎跑。

而这一关结束时，岩舟盯着那五行输出看了很久，忽然说："我好像明白编译器为什么叫编译器了。它什么都不算，它只是**换个顺序**。"
