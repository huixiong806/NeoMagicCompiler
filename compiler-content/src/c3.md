# 第三章：简单的魔法翻译机

遗迹的第二层没有机关，只有一台还在自己转的旧机器——**翻译机**。它不认星之印，只认写在纸带上的字。

星泠把纸带递进输入口，机器一个字符一个字符地"读"。她说了本章最重要的一句话：

> 读到的东西本来是**一串字符**，可你要的是**一个数**。中间这段路，就是编译器一生都在走的路。

本章要做的，是让魔导核心学会"读进来的是字、算出来的是意思"：先会数、再会分类，然后一路走到能读懂 `let x = 3; print x+1;` 这种话。这一章不写编译器，但每一关都是在为它铺路。

（提示：程序从**输入端口**读字符，读到 `0` 就是纸带读完了；算出来的东西写进**显示端口**，岩舟就能看见。）
