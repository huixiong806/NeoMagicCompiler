## 1. 目标机器规格：RV32IM 模拟器

底层硬件模拟器复用现有的 `crates/riscv-simulator`，采用标准 **RV32IM** 32 位定长指令集、小端序、指令与数据同址。

### 1.1 指令集与伪指令

| 类别 | 指令 |
|------|------|
| R 型算术逻辑 | `add` `sub` `sll` `slt` `sltu` `xor` `srl` `sra` `or` `and` |
| R 型乘除 | `mul` `div` `divu` `rem` `remu` |
| I 型算术逻辑 | `addi` `slti` `sltiu` `xori` `ori` `andi` `slli` `srli` `srai` |
| 访存 | `lb` `lh` `lw` `lbu` `lhu` / `sb` `sh` `sw` |
| 分支与跳转 | `beq` `bne` `blt` `bge` `bltu` `bgeu` / `jal` `jalr` `lui` `auipc` |
| 系统与扩展 | `fence` `ebreak` `ecall` `slp`（周期等待指令） |

汇编器支持的常用伪指令（按关卡白名单逐步开放）：
`li` `la` `mv` `not` `neg` `nop` `j` `jr` `ret` `call` `beqz` `bnez` `blez` `bgez` `bltz` `bgtz` `bgt` `ble` `bgtu` `bleu` `seqz` `snez`。

### 1.2 寄存器与调用约定

32 个 32 位通用寄存器（`x0`–`x31`），`x0` 恒为 0。支持数字名与标准 ABI 别名：

| 寄存器 | ABI 别名 | 约定用途 |
|--------|---------|---------|
| `x0` | `zero` | 恒为 0 |
| `x1` | `ra` | 返回地址 |
| `x2` | `sp` | 栈指针（默认初值 `0x0000_F000`，向下增长） |
| `x3` | `gp` | 全局/静态数据基址 |
| `x5`–`x7`, `x28`–`x31` | `t0`–`t6` | 临时寄存器（调用者保存） |
| `x8`–`x9`, `x18`–`x27` | `s0/fp`–`s11` | 保存寄存器（被调者保存；`s0` 兼作帧指针） |
| `x10`–`x17` | `a0`–`a7` | 函数参数（前 6 个 `a0`–`a5` 用于 C 子集调用约定）、返回值（`a0`）、系统调用号（`a7`） |

### 1.3 内存布局与 MMIO

| 地址区间 | 用途 |
|---------|------|
| `0x0000_0000`–`0x0000_FFFF` | 64 KiB RAM（稀疏实现，未写入读回 0） |
| `0x0000_0800` | 函数模式运行时的引导桩位置（避开常用数据区） |
| `0x0000_4000` | `starlang` 编译产物的默认数据段起点（`DATA_BASE`） |
| `0x0000_F000` | 默认栈顶（`STACK_TOP`，向下增长） |
| `0xF000_0000` | **输出端口（只写）**：写入低 8 位输出一个字符 |
| `0xF000_0004` | **输入端口（只读 FIFO）**：每次读取消费 1 个字符，队列空返回 0 |
| `0xF000_0008` | **周期计数器（只读）**：返回当前已消耗周期数 |

### 1.4 系统调用（`ecall`，调用号在 `a7` / `x17`）

| `a7` | 语义 | 说明 |
|------|------|------|
| `0` / `5` | 退出程序 | 退出码取 `a0`，唯一会触发 `PauseReason::Exit` 的系统调用 |
| `1` | 输出字符 | 将 `a0` 低 8 位写入输出端口 |
| `2` | 输出整数 | 以十进制文本输出有符号整数 `a0` |
| `3` | 读取字符 | 从输入端口读 1 字节到 `a0`（空则 0） |
| `4` | 读取整数 | 跳过空白读取一个十进制整数到 `a0` |
| `99` | 查询周期 | 当前已消耗周期数写入 `a0` |

## 2. C 子集语言规格（第 2 章学习语言 & 第 4 章编译器源语言）

第 2 章玩家在网页中编写该 C 子集（由 `crates/starlang` 编译为 RISC-V 汇编并支持对照查看）；第 4 章玩家用**本地标准 C** 编写编译器，将同一套 C 子集编译成 RISC-V 汇编，形成首尾闭环。

| 类别 | 支持范围 |
|------|---------|
| 基础与复合类型 | `int`（32 位有符号）、`char`、`void`、一级指针（`int*`/`char*`）、一维数组、`struct` |
| 作用域与声明 | 全局变量与数组、函数定义与声明、局部变量、块作用域 |
| 运算符 | 算术 `+ - * / %`、比较 `== != < <= > >=`、逻辑 `&& \|\| !`、位运算 `& \| ^ ~ << >>`、复合赋值、前后缀 `++ --`、三目 `?:`、下标 `[]`、取址/解引用 `& *`、成员访问 `. ->`、强制转换、 `sizeof` |
| 控制流 | `if / else`、`while`、`do-while`、`for`、`break`、`continue`、`return` |
| 函数 | 最多 6 个参数（`a0`–`a5`），支持递归 |
| 字面量与注释 | 十进制、`0x` 十六进制、字符与转义、字符串字面量、`//` 与 `/* */` |
| 内建运行时函数 | `putchar(c)`、`getchar()`、`print_int(n)`、`print_str(char* s)`、`exit(code)` |

不支持特性（会给出清晰中文提示）：浮点、`unsigned` 宽度语义差异、多维数组、函数指针、结构体按值传参/返回、可变参数、预处理器（`#include`/`#define`）、`switch`/`goto`。

## 3. 第 3 章迷你虚拟装置规格（BotVM 草案）

为了让零基础玩家在进入真正的 RISC-V 编译器之前，先用最小心智负担跑通一次「词法 → 语法 → 指令生成 → 运行看结果」的完整闭环，第 3 章引入一台极简的 **2D 网格虚拟装置（BotVM）**。

### 3.1 装置底层指令集（共 8 条）

玩家用本地 C 程序把人类可读的“装置脚本”翻译成如下文本指令流，网页端直接加载并在 2D 网格沙盘中播放执行动画：

| 指令 | 含义 |
|------|------|
| `MOVE` | 向当前朝向前进 1 格（撞墙报错） |
| `LEFT` / `RIGHT` | 原地左转 / 右转 90 度 |
| `PICK` / `DROP` | 拾取当前格物品 / 放下手中物品 |
| `PUSH <n>` | 将整数 `n` 压入装置内部计数栈（供循环/条件扩展关使用） |
| `JMP <label>` | 无条件跳转到标签 |
| `JNZ <label>` | 栈顶计数减 1，若不为 0 则跳转到标签（用于翻译 `repeat` 循环） |

### 3.2 源语言示例（迷你脚本）

```text
// 第 3 章后期关卡示例：宏展开 + 循环 + 条件
repeat 3 {
    move;
    pick;
}
right;
move;
drop;
```

**教学价值**：它只有 8 条指令，玩家一眼就能看懂自己翻译出的指令流对不对；并且网页动画会一步步演示小机器人怎么走，比纯数字的“表达式计算器”直观得多，同时已经完整覆盖了 **Token 切分、递归下降解析、AST/块结构、标签生成与循环展开/跳转**。

## 5. Judge 判定体系

判定统一收口在 `crates/neomagic-core`，所有模式（WASM 在线 / 本地 Bridge）共用同一套判定标准：

| 判定类型 | 适用场景 | 判定逻辑 |
|---------|---------|---------|
| `static` | 第 1~2 章基础关 | 逐测例比对期望寄存器、内存、返回值、输出流与退出码 |
| `output` | 词法/AST 等文本产物关 | 按行规范化比对标准输出（忽略多余空行与首尾空白） |
| `bot_sim` | 第 3 章迷你装置关 | 将玩家程序输出的 BotVM 指令流交给虚拟装置模拟器执行，校验最终地图状态与步数 |
| `compile_and_run` | 第 4 章代码生成关 | 把玩家编译器输出的 RISC-V 汇编交给 `riscv-assembler` + `riscv-simulator` 真实运行，校验最终返回值/输出/内存 |
| `scripted` | 随机化压力测试关 | Rust 内置随机生成测例并对比参考实现（如 `sort_check`、`expr_check`） |
