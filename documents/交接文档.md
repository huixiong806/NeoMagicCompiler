## 1. 三十秒速览

- **项目**：Neo Magic Compiler（远端 Gitee：`orangebird/neo-magic-compiler`）
- **当前分支**：`no_story`（**不要动 `master`**）
- **核心转型决定**：
  1. **暂时去剧情**：不写世界观与剧情对话，使用真实计算机术语 + 视觉隐喻，专注打磨核心玩法与零基础教学闭环。
  2. **放弃 Tauri + mdBook，全面转向 Web 应用**：现代前端承载交互式动画教学与独立 Playground。
  3. **双执行模式**：前两章通过 **`nmc-wasm`** 纯网页零安装运行；后两章通过本地轻量桥接服务 **`nmc-bridge`** 自动识别本地 C 语言项目，实现**本地 IDE 写代码 + 网页端一键构建/测试/可视化调试**。
  4. **重做第 3、4 章**：不再用汇编硬写编译器，改为用真实本地 C 工程依次完成「迷你装置翻译器（BotVM）」与「完整 C 子集 → RISC-V 编译器」。

## 3. 工作方式与协作纪律

1. **重大设计与架构决定先与项目发起人确认**：凡存在两种以上合理方案（如前端框架选型、BotVM 具体交互细节、第 4 章是否引入多文件链接），先列选项与代价讨论，不擅自拍板。
2. **先闭环、后扩量**：不要一口气写完几十关再做界面；必须先跑通一个**最小完整闭环**（例如 Phase 1 先做通 3~5 关的动画教学 + Playground + 存档），人工试玩满意后再批量生产关卡。
3. **质量底线不变**：任何关卡必须通过 `selfcheck` 与一致性检查；前后端 DTO 变动必须同步更新契约测试。
4. **Windows 开发避坑**：
   - 严禁用 PowerShell `Set-Content` / `Out-File` 写含中文文件；
   - `.cargo/config.toml` 离线构建防卡死；
   - 每次提交前检查 `git status --short`，禁止提交临时探针文件。
