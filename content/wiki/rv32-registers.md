# RV32IM 寄存器速查

RISC-V 32 位 CPU 内部有 **32 个通用寄存器**（编号 `x0`–`x31`），每个可存放一个 32 位整数。为了避免混淆用途，标准 ABI 为它们起了直观的别名：

| ABI 别名 | 编号 | 角色与约定 |
|---------|------|-----------|
| `zero` | `x0` | **恒为 0**，任何写入都会被硬件忽略 |
| `ra` | `x1` | 返回地址（调用子程序时自动写入，**不要当普通临时槽**） |
| `sp` | `x2` | 栈指针（默认初值 `0xF000`，向低地址增长） |
| `t0`–`t2` | `x5`–`x7` | **临时寄存器**（第 1 章计算主力，放心读写） |
| `t3`–`t6` | `x28`–`x31` | **临时寄存器**（更多草稿槽） |
| `a0`–`a7` | `x10`–`x17` | 函数参数与返回值；`a7` 兼作 `ecall` 系统调用号 |
| `s0`–`s11` | `x8`–`x9`, `x18`–`x27` | 保存寄存器（跨函数调用需由被调者保存恢复） |

## 常见误区
- 寄存器赋值是**覆盖写**：写入新值后旧值立刻消失，交换两数前需先暂存。
- 32 位有符号整数范围是 `-2,147,483,648` ~ `2,147,483,647`，超出后会按 $2^{32}$ 自动回绕。
