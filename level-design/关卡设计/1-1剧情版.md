# 1.1 基础计算
# 1.1.1 1+1
## 引言
在魔导核心里面，有三十二个小格子，每个格子都有自己的编号，从 x0、x1、x2……一直排到 x31。

这些格子是干嘛用的呢？简单来说，每个小格子都可以存放一些魔力点，通过不同的排列方式表示出一个数。具体是怎么排的，我们先不管，{player.name}只需要知道——格子里存的是数值就行。

好，那么现在，我已经提前在 x1 和 x2 这两个格子里各放了一个“1”。接下来我们要把它俩加起来，算一个1+1。

要让它俩相加，得用到魔导核心提供的一种能力，叫做“加法指令”。

这条指令写出来长这样：add rd, rs1, rs2。
这里的 rd、rs1 和 rs2，就是在告诉你“这里要填哪个格子的编号”。

最后的 rs1 和 rs2，是你用来放“要加的数”的两个格子；
最前面的 rd，是用来放“加出来的结果”的目标格子。

举个例子，如果写 add x3, x1, x2，就是把 x1 和 x2 里的数加起来，结果存到 x3 里。

代入我们的数字：x1 里是 1，x2 里也是 1，那么执行完这条指令之后，x3 里就会是1+1的结果，也就是2。

好了，这条指令就能完成 1+1=2。你现在就来试着执行它吧。

## 后记

恭喜你成功执行了第一条指令，计算出了1+1=2。

顺便提一下：刚才你用来存放数字的那些小格子，正式的名字叫作“寄存器”。以后我们就用这个正式名称了。
